# 海信冰箱包装线六工位 AI 视觉检测方案 · PPT 演示策划

> 用途：把客户版方案重新编排成"打动客户的演示叙事"，含逐页排版、配图清单、AI 生图提示词。
> 目标听众：首次接触我司产品的客户（决策层 + 技术层）
> 建议页数：22 页　比例：16:9　时长：15–20 分钟

---

## 一、整体设计规范（先定调，全篇统一）

### 1.1 演示叙事主线（重新整理的思路）

```
共鸣痛点 → 描绘愿景 → 亮出总方案 → 讲透怎么做 → 秀核心亮点(重头戏)
        → 落地保障(配置/实施/服务) → 价值收口 → 行动呼吁
```
节奏要点：前 3 页抓人（痛点+价值），中段（亮点）是重头戏多停留，后段（配置/服务）快过给信心，结尾强收口。

### 1.2 视觉规范

| 项 | 规范 |
|---|---|
| 整体风格 | 深色科技工业风（区别于传统白底方案，更显高端、AI 感） |
| 主背景 | 深蓝黑渐变 `#0A1428 → #0E1E3C` |
| 主高亮色 | 科技青蓝 `#19C6FF` / 电光蓝 `#2D7FF9` |
| 辅助色 | 警示橙 `#FF8A3D`（NG/告警）、健康绿 `#27E0A0`（OK/合格） |
| 正文字色 | 纯白 `#FFFFFF` / 浅灰 `#B8C4D8` |
| 中文字体 | 标题：思源黑体 Bold / 阿里巴巴普惠体 Heavy；正文：思源黑体 Regular |
| 英文/数字 | Montserrat / Rajdhani（科技感数字） |
| 字号 | 大标题 40–54pt；页标题 28–32pt；正文 18–22pt；注释 12–14pt |
| 统一元素 | 左上角小 LOGO + 页脚页码 + 细青蓝分隔线；关键数字用大号高亮 |

### 1.3 版式系统（全篇复用 6 种版式）

- **V1 封面式**：全屏背景图 + 居中大标题
- **V2 左文右图**：左 40% 文案要点，右 60% 配图/示意
- **V3 全图叠字**：整页背景图 + 左下/右下叠加标题与一句话
- **V4 三栏/卡片**：3–4 个等宽卡片并排（讲并列要点）
- **V5 流程时序**：横向/纵向流程箭头 + 节点图标
- **V6 数据看板**：大数字 KPI + 图表/示意

## 五、制作建议

1. **工具**：PPT/WPS 演示 或 Figma/Canva；图表用 PPT 原生或 ECharts 截图。
2. **文字别交给 AI 生图**：所有中文标题/数据后期在 PPT 里用文本框叠加，AI 图只做背景/示意（避免中文乱码）。
3. **配图比例**：统一 16:9 生成，铺底图留安全边距给文字。
4. **一致性**：全篇沿用第一节配色与字体；每页同位置放页标题与页码。
5. **动画克制**：以淡入、路径流动为主，避免花哨切换；重头戏页（P6/P12/P14/P16/P17）可多花动画。
6. **演示节奏**：痛点页慢、亮点页停留久、配置页快过、价值页收口有力。
7. **指标口径**：统一 `准确率 ≥98%、误判率 ≤2%`（全篇一致）。
