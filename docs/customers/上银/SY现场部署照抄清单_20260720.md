## ② 项目（名字必须 = MES 规格，例如 `SYS1`；有几个规格建几个项目）

**基础**：任务类型=检测；逻辑模式=**自定义**；基于=**顺序**；混合=**tracking**；结算=**最后一步**。

**步骤表**（9 条，未列的时间参数留默认）：

| 步骤 | 启用 | 阈值 | 最少帧 | 严格顺序 | 其他 |
|---|---|---|---|---|---|
| 托盘 | ✅ | 50 | — | — | 容器锚点，进周期 |
| 箱子 | ❌ 停用 | 50 | — | — | |
| 贴标 | ✅ | 50 | — | ✅ | |
| 套内袋 | ✅ | 50 | — | ✅ | |
| 滑块 | ✅ | 50 | — | — | 计数用 |
| 放油嘴包 | ✅ | **40** | — | ✅ | |
| 封箱 | ✅ | 50 | — | — | **消失延迟 3s** |
| 放工单 | ✅ | 50 | — | — | 序列外检测步骤（尾箱 gate 探测用） |
| 放托盘 | ✅ | **40** | **2** | — | **最短出现 0.3s / 消失确认 0.8s** |

**自定义序列**（判定顺序）：贴标 → 套内袋 → 放油嘴包 → 封箱。

**容器装箱（托盘计数）**——项目页"物品校验·托盘装箱"卡：

| 项 | 值 |
|---|---|
| 容器标签 | 托盘 |
| 计数口径 | 滑块总数（累加进箱物品总数）items_total |
| 每箱目标 | **96** |
| 进箱确认方式 | **仅"标签动作确认"**（勾"标签动作确认"，**不勾**"消失满帧确认"） |
| 动作标签 | 放托盘 |
| 消失确认帧 | 20（不勾满帧时不生效，留着即可） |
| 容器 IoU 匹配 | 0.3 |

> ⚠️ 千万别把"消失满帧 + 动作确认"两个都勾（OR 会把同一盘确认两次，96 会数成 192，仿真里踩过）。

**事件表**（异常映射要用到这三个 id，别改顺序）：

| id | 名称 | 动作 | 提醒 |
|---|---|---|---|
| 1 | 合格(OK) | 合格总数+1、总产量+1 | 普通 |
| 2 | 不良(NG) | 不良总数+1、总产量+1 | NG |
| 3 | 包装异常-需人工确认 | 异常总数+1 | 错误 + **需人工确认** |

**计数器**：合格总数 / 不良总数 / 总产量 / **异常总数**（事件 3 要用，别漏建）。

## ③ 包装箱结算（系统设置 → 显示设置 → 包装箱结算）

新建配置 → 点 **「上银SY预设」** 一键导入（v3.42.1 起已含全部业务项），之后**只需手动配 3 项**：

1. **工位**：绑定检测工位（单机 = 工位 0）
2. **扫码器**：选现场那把 USB 键盘扫码枪
3. **拉单连接**：选 MES 工单拉取那条连接

预设导入后核对一遍（应与下表一致）：

| 组 | 项 | 预设值 |
|---|---|---|
| 口径 | 计数单位 | 滑块 sliders |
| | 每箱滑块数 | 固定值 **96** |
| | 滑块总数字段 | dispatch_qty（排产量） |
| 标签 | 比对方式 | insert_char，符号 `-` 补在第 **12** 位后 |
| | 复合条码取段 | 开，分隔符 `\|`，前缀 **JOB** |
| | 工单号识别规则 | `^JOB`（开机第一枪挡数量条码） |
| 策略 | 拉单失败 | **block 阻断**（正式 MES 用这个；测试期才用 offline） |

## ⑤ 上线前冒烟（5 分钟）

1. 扫一张**工单纸** → 监控页包装卡出现工单号/客户/规格/箱数
2. 扫一张**箱标签**（二维码那种四段码）→ 不报"标签不符"（复合取段生效）
3. 故意扫**数量条形码**（80.00 之类）→ 有在途单报"标签不符"；无在途单报"非工单码已忽略"
4. 做一箱看：托盘逐盘进箱计数 → 96/96 封箱 → 合格
5. 做完的工单**再扫一次** → 弹"需人工确认"提示且不重新开单
