# 捷昌 B 站打包流水线检测模型 · 图片标注规范

> **交付对象**：标注工程师
> **产线**：捷昌 B 站打包流水线，三道工序三个通道三个模型（一工位 / 二工位大件 / 二工位小件）
> **产品**：**两款产品**（黑色款 / 白色款），包装箱相同、打包工序相同，**两款都走这条线、都要进训练集**
> **有疑问**：拿不准的帧不要猜，截图集中反馈给项目负责人统一裁定

---

## 一、背景：这批标注是干什么用的（先读，影响画框方式）

现场是打包流水线：箱子串行流过 → 一工位放第一批物料 → 流到二工位，大件相机盯大件区、小件相机盯小件区各自清点。软件跑的是**跟踪模式 + 齐件即结算**：模型认出每样物品，软件数"该到的物品是不是都稳定出现在检测区里了"，凑齐并稳定若干帧就当场判合格。

和"动作识别"类项目不同，这里模型认的是**物品本体**。软件有两个判定机制直接吃标注质量：

1. **框中心点落区判定**——物品算不算"放进来了"，看的是检测框**中心点**是否落在检测区域（ROI）内；
2. **稳定帧数判定**——物品要**连续若干帧被稳定检出**才计数，检出忽有忽无（框时大时小、时有时无）会导致永远凑不齐。

由此产生本规范最重要的两条铁律：

> ⚠️ **铁律一：框只贴物品本体，不框手、不框手臂。**
> 手把物品放进箱的过程中，手会把框中心拽偏；框里带手还会让模型学到"物品=物品+手"，物品放定手离开后反而检不出。手指少量遮挡边缘可以带入，**成片的手背/手臂绝不入框**。
>
> ⚠️ **铁律二：同一物品在相邻帧的框要稳，宁可略松不要抖。**
> 边界忽紧忽松的标注训出来的模型框会抖，抖动直接冲击"稳定 N 帧"判定。贴合外轮廓、误差按验收标准控制即可，不追求逐帧像素级精抠。

## 二、素材与交付

| 项 | 内容 |
|---|---|
| 素材来源 | 现场三路相机各自录像抽帧（**必须用现场最终机位、最终分辨率**，机位换过要重录） |
| 抽帧密度 | 每路整周期录像每 3 帧抽 1 张起步；物品放入前后 2 秒的帧全保留 |
| 颜色覆盖 | **黑色款、白色款两种产品的完整周期都要有**，比例建议接近 1:1，缺一色的批次先补录再标 |
| 标注工具 | labelImg / X-AnyLabeling 等任意支持 YOLO 格式的工具 |
| 交付格式 | YOLO 目标检测格式：`images/` + `labels/`（每图一个同名 txt）+ `classes.txt`（类别顺序必须与下表 id 一致） |
| 框类型 | 全部为水平矩形框（bbox），无多边形、无关键点 |
| 数据集划分 | **三个通道三套独立数据集、三份 classes.txt，绝不混标混训**（三个模型互相独立） |

## 三、类别定义（按通道分三套）

> 下面三张类别表**从现场在用的三个模型里直接导出**（`GW1_an.pt` / `dajian4.23.pt` / `best7.8xiaojian.pt`），id 顺序与模型内置一致，**classes.txt 必须按表中顺序写、一个不加一个不减**——增量补数据重训要和旧模型类别对齐。
> 黑白是**两款产品**：箱子相同（同标 `箱子`/`box`），其余内件两款共用同一套类别、不按款拆类；若待训的新版模型类别有增删，以新模型为准并回改本表。

### 通道 1 · 一工位模型（5 类，源自现场模型 `GW1_an.pt`）

| id | 类别名 | 一句话定义 |
|----|--------|-----------|
| 0 | `box` | 包装箱本体 |
| 1 | `foot` | 放入的脚件 |
| 2 | `pillar_no_core` | **不带芯**的立柱 |
| 3 | `pillar_with_core` | **带芯**的立柱 |
| 4 | `cable_hook` | 线钩 |

> 1. 类别名沿用现有模型的英文命名，**classes.txt 必须按此顺序原样写英文**（增量训练要和旧模型 id 对齐）；
> 2. `pillar_no_core` 与 `pillar_with_core` 是**互斥对**：同一根立柱按当前实际状态标其一，绝不同帧双标；分不清带没带芯的帧跳过并截图反馈。

### 通道 2 · 二工位大件模型（9 类，源自现场模型 `dajian4.23.pt`）

| id | 类别名 | 一句话定义 |
|----|--------|-----------|
| 0 | `箱子` | 包装箱本体（物品都往里放的那个箱） |
| 1 | `线槽` | 放入箱内的线槽件 |
| 2 | `侧板` | 放入箱内的侧板 |
| 3 | `大框架` | 放入箱内的大框架主体件 |
| 4 | `小框架` | 放入箱内的小框架 |
| 5 | `传动杆` | 放入箱内的传动杆 |
| 6 | `手套` | 随箱附带的手套（含包装袋，如有） |
| 7 | `说明书` | 随箱附带的说明书 |
| 8 | `泡沫槽` | 箱内的泡沫内衬槽 |

### 通道 3 · 二工位小件模型（9 类，源自现场模型 `best7.8xiaojian.pt`）

| id | 类别名 | 一句话定义 |
|----|--------|-----------|
| 0 | `连接件` | 放入的连接件（含其独立小包装袋，如有） |
| 1 | `适配器` | 电源适配器（含包装袋/盒，如有） |
| 2 | `手控器` | 手控器（含包装袋，如有） |
| 3 | `水杯架` | 水杯架（注意：是水**杯**架） |
| 4 | `螺钉包` | 螺钉小包 |
| 5 | `泡沫槽_空` | **还没放东西**的泡沫槽 |
| 6 | `泡沫槽_有物` | **已放入物品**的泡沫槽 |
| 7 | `螺钉位_空` | **还没放螺钉包**的螺钉位 |
| 8 | `螺钉位_有物` | **已放入螺钉包**的螺钉位 |

> 1. 小件普遍带透明包装袋：**连物带袋一起框**（现场就是带袋放入的，模型必须认带袋状态）。裸件和带袋件都出现的话两种都标同一类；
> 2. `泡沫槽_空/_有物`、`螺钉位_空/_有物` 是**状态互斥对**：同一个槽/位每帧只能标其中一个状态类，按当前帧实际状态标；**正在放入的过渡帧**（物品一半在槽里）两个状态类都不标，只标物品本身（如 `螺钉包`）；
> 3. 状态类标的是**槽位本身**（框贴槽位轮廓），不是里面的物品——`泡沫槽_有物` 框泡沫槽，槽里的物品若属于上面 0~4 类另行单独标。

## 四、怎么画框（三个通道通用规则)

1. **贴合物品外轮廓一框**，含物品自身的包装袋；不含手、手臂（铁律一）。
2. **被手短暂遮挡的放置瞬间**：物品主体可见 ≥ 一半 → 按完整轮廓框（脑补被挡部分）；可见 < 一半 → 该帧跳过不标。
3. **物品在手中移入画面的过程帧**：能清晰辨认是哪类物品就标（只框物品不框手），认不清就跳过。运动模糊但类别可辨的帧**照标**——现场就是这种画面。
4. **放定之后的物品**：逐帧都标，这是数量大头也是计数的主依据。物品叠放/互相半遮挡时各标各的，按各自完整轮廓框。
5. **箱子**（大件通道）：贴箱体外轮廓，箱内已放入的物品不影响箱子框；箱盖翻开的耳翼算箱体一部分框入。
6. 同类物品一帧多个（如两个侧板）：**各画各的框**，绝不合并一框。

## 五、不标注清单（负样本纪律，同样重要）

以下内容**任何情况都不画框**——错标它们比漏标更伤模型：

1. **备料区/料架上的同类物品**：只标**作业台面/箱区**的目标；远处备料堆里的箱子、侧板等一律不标。（运行时软件靠 ROI 圈作业区，但训练集里备料区若时标时不标，模型会学出随机检出——所以统一为**不标**。）
2. **人体**：手、手臂不单独标，也不作为物品框的一部分带入（铁律一）。
3. **流走的成品箱**：已封箱/已流出作业区的箱子不标。
4. **无关杂物**：工具、扫码枪、抹布、手机、台面杂物。
5. **相邻工位串景**：相机拍到隔壁工位的物料（广角边缘常见），不标。

## 六、时序边界速查（拿不准"这帧算不算"时查这里）

| 情形 | 处理 |
|---|---|
| 物品刚入画/移动中 | 类别清晰可辨 → 标（只框物品）；辨不清 → 跳过 |
| 放置瞬间被手大面积挡住 | 可见 ≥ 一半按完整轮廓标；< 一半跳过 |
| 物品出画面一半（箱在传送边缘） | 可见部分 ≥ 一半按可见部分框；< 一半不标 |
| 拿起来又放回（重摆动作） | 全程按第四节规则照标，软件自己处理反复 |
| 黑款白款怎么标？ | 画框规则完全相同；类别归属按第三节最终类别表（箱子同标，内件以模型类别为准） |
| 完全认不出/严重遮挡 | 跳过，宁缺毋滥，截图反馈 |

## 七、数量与多样性要求

- 每个通道独立成套，各通道**每类目标框数下限 800**；`箱子` 这类全程在画面里的锚点类会自然到几千，照标不设上限（相邻帧近似重复也逐帧标，用标注工具"复制上一帧标注"提效）。
- **黑白两款产品各占约一半**；两款共用的类别（如 `箱子`）必须两款样本都有，只有单款样本的共用类别视为未完成。
- 覆盖：不同班次光照、不同操作员、物品不同摆放角度/位置；同一箱重录多遍不如多录几箱。
- 后续补录用同一机位；机位一旦调整，通知项目负责人评估是否需要补录重训。

## 八、质量验收

交付前自检，项目方按同样标准抽检 10%：

1. 类别错误率 = 0（尤其小件四类不得互混；带袋/裸件同类判定一致）；
2. **手/手臂入框抽检**：随机抽含放置动作的帧，框内出现成片手背/手臂判不合格（铁律一）；
3. 不标注清单（第五节）零违例，重点查备料区误标；
4. 框贴合度：边界与目标轮廓偏差不超过目标尺寸的 10%；同一静止物品相邻帧框抖动不超过 5%（铁律二）；
5. 黑白覆盖：每类别两种颜色样本都在，比例不劣于 3:7。
