## 一、背景：这批标注是干什么用的（先读，影响画框方式）

白款产品**目前没有模型**——这批标注用于**首训**白款小件模型（训练时与黑款素材混训，共用同一套 9 类，不按款拆类）。工位场景与黑款一致：俯拍相机对着滚筒输送线，包装箱滑进画面 → 操作员把小件逐格放进白色泡沫槽 → 满箱滑走 → 下一个箱进来。

软件跑的是**跟踪模式 + 齐件即结算**，两个判定机制直接吃标注质量：

1. **框中心点落区判定**——物品算不算"放进来了"，看检测框**中心点**是否落在检测区域内；
2. **稳定帧数判定**——目标要**连续若干帧稳定检出**才计数，检出忽有忽无 = 永远凑不齐 = 整箱误判。

由此产生本规范最重要的两条铁律（与黑款一致）：

> ⚠️ **铁律一：框只贴目标本体，不框手、不框手臂。**
> 放置过程手会把框中心拽偏；框里带手还会让模型学到"物品=物品+手"，物品放定手离开后反而检不出。手指少量遮挡边缘可带入，**成片的手背/手臂绝不入框**。
>
> ⚠️ **铁律二：同一目标相邻帧的框要稳，宁可略松不要抖。**
> 边界忽紧忽松训出来的模型框会抖，直接冲击"稳定 N 帧"判定。贴合外轮廓、误差按验收标准控制即可，不追求逐帧像素级精抠。

## 三、槽位版图（先认清楚白款箱内格局）

白款箱内小件区共 **4 个槽位**，与黑款结构同源：

- **左侧大格**：一整格算**一个**泡沫槽（上半区是**螺钉位**放螺钉包、下半区放**水杯架**）；泡沫槽框只画一个罩住整格，`螺钉位_*` 是这格内部的**子区域**，单独叠标在上半区；
- **三条窄槽**：各自独立一格逐格框，白款素材里从左到右依次装**适配器 / 手控器 / 连接件**——但**认实物不背槽位**，以当前帧实物认类；
- **顶部横槽的长金属杆（传动杆）和右侧白色侧板、右侧所有凹槽**：属于**二工位大件通道**的目标——不管空满、任何情况**一个框都不画**（见 std_w6）。

**类别设计的四个关键点（与黑款 v1.1 完全一致）**：

1. **物品类（0~4）连物带袋一起框**——现场就是带包装袋放入的，模型必须认带袋状态；裸件出现也标同一类。
2. **状态类（5~8）标的是槽位本身**：槽框贴**槽腔轮廓画满整槽**——哪怕物品只占槽的一半，`泡沫槽_有物` 也要框整条槽，不跟着物品缩水。
3. **物品框紧贴物品本体，可以比槽框小**：适配器只占槽的上半段，就只框上半段；不许为了和槽框对齐把物品框拉大。"满槽帧" = 状态框（整槽）+ 物品框（贴物）两个框叠着，这是对的。
4. **状态互斥**：同一个槽/位每帧只能标 `_空`/`_有物` 其中一个；**正在放入的过渡帧**（物品一半在槽里、手还没离开）两个状态类**都不标**，只标物品本身。物品放定手离开后，从下一个清晰帧起标 `_有物`。

## 五、整帧场景画法（六张标准答案）

### 满箱帧 — std_w1

- 左大格：`泡沫槽_有物` 罩整格 + 上半区叠 `螺钉位_有物` + `螺钉包`（贴袋）+ `水杯架`（下半区贴物）；
- 三条窄槽：各标 `泡沫槽_有物`，槽内物品贴物另标（适配器只占槽上半段就只框上半段）；
- 顶部传动杆、右侧侧板/大件槽：**零框**。

![满箱标准答案](标注规范assets_二工位小件_白款/std_w1_满箱.png)

### 空箱帧 — std_w2

- **4 个槽框**：左大格 1 个 `泡沫槽_空` + 上半区叠 1 个 `螺钉位_空`，三条窄槽各 1 个 `泡沫槽_空`；
- 注意：空箱进站时**大件（传动杆/侧板）通常已在箱内**——它们照旧不标，别因为"箱里有东西"把小件槽标成有物。

![空箱标准答案](标注规范assets_二工位小件_白款/std_w2_空箱.png)

### 放置中途帧 — std_w3

- 已放定的格标 `_有物` + 物品；未放的格照标 `_空`（本图：三窄槽已放好、左大格还空着）；
- 严格按**当前帧实际状态**逐格标，不参考前后帧脑补。

![放置中途标准答案](标注规范assets_二工位小件_白款/std_w3_放置中途.png)

### 手入画帧 — std_w4（铁律一的主战场）

- 手/手臂在画内但没有正在放东西的槽照标；
- **被手或手持物遮挡、状态看不清的子区域直接不标**——本图螺钉位被手里的袋子挡住，`螺钉位_*` 和 `螺钉包` 都没标，这是标准答案，不要猜状态；
- 正在放入的那格：状态类不标，只标物品（物品类别辨不清 → 整帧跳过）。

![手入画标准答案](标注规范assets_二工位小件_白款/std_w4_手入画.png)

### 出画临界帧 — std_w5

- 箱子滑动中：**仍完整可见的槽照标**（本图全部小件槽都还在画内，全标）；已出画/贴画面边缘截断的目标不标；整箱可见 < 一半全部不标。

![出画临界标准答案](标注规范assets_二工位小件_白款/std_w5_出画临界.png)

### 大件通道目标 — std_w6（最重要的不标示范）

- 顶部长金属杆（传动杆）、右侧白色侧板与右侧全部凹槽是**二工位大件模型**的目标，进了小件数据集就是污染——**任何情况不画框**。

![大件目标不标](标注规范assets_二工位小件_白款/std_w6_大件目标不标.png)

### 空线负样本帧

- 两箱之间只剩滚筒和背景的空档帧：**整帧零标注**，照常交付（空 txt 或无 txt，按工具默认）——这是重要的负样本，不许从数据集里删掉；
- 背景里的滚筒、台面下纸箱、金属圆盘件等一律不标。

![空线负样本](标注规范assets_二工位小件_白款/neg_空线负样本.jpg)

## 六、不标注清单（负样本纪律，同样重要）

以下内容**任何情况都不画框**——错标它们比漏标更伤模型：

1. **传动杆/侧板/右侧大件凹槽**（std_w6，白款最高频的坑：大件随箱进站，全程在画）；
2. **背景**：滚筒输送线本体、台面、台下纸箱、地面杂物、脚、金属圆盘件；
3. **人体**：手、手臂不单独标，也不作为物品框的一部分带入（铁律一）;
4. **已滑出作业区的箱子**（整箱可见 < 一半时）；
5. **箱体纸箱本身**——小件模型类别表里没有"箱子"类（状态类只标泡沫槽格）。

## 七、时序边界速查（拿不准"这帧算不算"时查这里）

| 情形 | 处理 |
|---|---|
| 物品在手中移入画面 | 类别可辨 → 只框物品；辨不清 → 跳过 |
| 正在放入某格的过渡帧 | 该格两个状态类都不标，只标物品 |
| 物品放定、手已离开 | 从下一清晰帧起：格标 `_有物`，物品另标 |
| 槽位/子区域被手或手持物挡住看不清 | 该槽此帧不标，不猜状态 |
| 箱子滑动中（进入/离开） | 完整可见的槽照标、出画/贴边截断的不标；整箱可见 < 一半全部不标 |
| 两箱之间的空线帧 | 整帧零标注，照常交付 |
| 小件区仍空着的格 | 照标 `_空`，不脑补（大件区槽永远不标） |
| 运动模糊 | 类别可辨照标；肉眼认不出跳过 |
| 完全认不出/严重遮挡 | 跳过，宁缺毋滥，截图反馈 |

## 八、数量与配重要求

白款是**从零首训**，没有"现役模型弱点"可参照——按黑款踩过的坑预防性配重：

| 类别 | 下限 | 理由 |
|---|---|---|
| `螺钉包` | **≥ 1500** | 黑款模型此类 0 检出的前车之鉴；白款透明袋+白底更难，必须超额 |
| `螺钉位_有物` | **≥ 1000** | 黑款把满位判成空（判定性错误），白款预防同样问题 |
| `水杯架` | **≥ 1200** | 白轮盘贴白泡沫，对比度低，黑款检出闪烁的高危复刻 |
| `连接件` | **≥ 1000** | 白件+半透明袋，全类中对比度最低 |
| `泡沫槽_空` / `泡沫槽_有物` / `螺钉位_空` | 各 ≥ 800 | 全程在画，自然达标，照标不设上限 |
| `适配器` / `手控器` | 各 ≥ 800 | 深色目标对比度好，维持覆盖 |

- 相邻帧近似重复也**逐帧都标**（用标注工具"复制上一帧标注"提效）；
- 覆盖要求：不同操作员、戴手套/徒手、物品不同摆放角度；同一箱重录多遍不如多录几箱；
- 本批只有晚班灯光素材，白天素材到位后按同规范补标混入。

## 九、质量验收

交付前自检，项目方按同样标准抽检 10%：

1. 类别错误率 = 0（重点：珠链状透明包=手控器、白色轮盘=水杯架，不得自行猜类；窄槽物品逐帧认实物）；
2. **状态互斥抽检**：同一槽位同帧出现 `_空`+`_有物` 双标 = 不合格；过渡帧带状态标 = 不合格；
3. **手/手臂入框抽检**：随机抽放置动作帧，框内成片手背/手臂 = 不合格（铁律一）；
4. 不标注清单（第六节）零违例，**重点查传动杆/侧板误标**（白款独有高频坑）；
5. 框贴合度：边界与目标轮廓偏差 ≤ 目标尺寸 10%；同一静止目标相邻帧框抖动 ≤ 5%（铁律二）；
6. 空线负样本帧不得缺失。
