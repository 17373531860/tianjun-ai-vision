# 打螺丝漏打检测与提醒 · 方案说明

> 致：贵司现场 / 工艺负责人
> 关于：弧形横梁打螺丝工位"漏打识别 + 屏幕提示 + 报警 + 补打"需求的实现方案

---

## 一、我们理解的您的需求

1. 系统能识别出**哪一颗螺钉没打**，并在屏幕上指出来；
2. 漏打时**报警**提醒，工人**补打**那一颗后报警自动取消；
3. 漏件判定希望在"一圈打完后"很短时间内完成，并提示漏的是哪颗；
4. 合格亮**绿灯**、取走工件；不合格亮**红灯**并显示不良点位；补完后转绿灯取件；
5. 红灯状态下如果直接把件取走，要计入**不良数量**；
6. 不良件没处理完，**不允许进入下一步**（NG 系统保护）。

我们用贵司实际产线视频（弧形横梁，14 颗 5N 螺钉 + 4 颗 7N 螺钉，共 18 颗）做了真实推理验证，下面先讲我们发现的一个关键问题，再讲方案。

---

## 二、我们发现的关键问题（很重要）

需求里有一个时间点叫"一圈打完"，整套提醒节奏都挂在它上面。但用您的视频实测后发现：

**问题一：用"拿取动作"当判定时机太晚。**
现在系统的结算信号是"拿取"，可"拿取"在现场就等于**把整个工件端离了工位**——等系统反应过来要判定时，工件和螺钉都已经不在镜头里了，**没法停在原地显示漏点、更没法补打**。

**问题二：用"工人停手"当"打完"信号不可靠。**
我们本想用"工人停手几秒"判断"这一圈打完了"。但实测发现，工人在打相邻两颗螺钉之间**停顿超过 2 秒非常常见**（整段视频里这样的停顿出现了 17 次，其中还有一次停了将近 1 分钟去调整工件）。所以"停手 2 秒就判定"会**频繁误判**——明明还在打，系统却以为打完了。

> 结论：除了"工件被端走"这个动作，现场**没有一个稳定可靠的信号能标记"这一圈打完了"这一刻**。所以我们调整了思路。

好消息是：**对每一颗螺钉本身的识别非常稳定**——整个加工过程中，系统每一帧都准确数出 14+4=18 颗，一颗不差。所以"判断哪颗没打"这件事，技术上完全可靠。

---

## 三、我们的方案：全程实时看板 + 离场判定

把"判定时机"从"打完那一刻"改成两段配合：

**第一段：加工全程 — 屏幕实时点位看板**
屏幕上按螺钉的真实位置画出 18 个点，工人每打好一颗，对应的点就由灰变绿。工人一抬眼就知道**还差哪几颗没打**，相当于一个"防呆提示板"，引导工人自己别漏。

**第二段：工件离场 — 自动判定合格/不合格**
当工人把工件端离工位（镜头里螺钉全部消失），系统立刻拿"离场前的最终状态"判定：
- **18 颗全打好** → 绿灯，合格，正常取件；
- **有漏** → 红灯 + 蜂鸣 + 屏幕高亮显示漏的是哪一颗，并进入"等待处理"状态。

**漏件后的处理（红灯状态）：**
- 工人把工件**放回**工位，补打漏的那颗 → 系统实时检测到 → **红灯自动转绿**，合格取件；
- 如果工人没补就直接拿走，或现场确认确实是不良 → 计入**不良数量**，并且**必须由操作员（或管理员）在屏幕上确认后，产线才能继续**——这就实现了"不良件不处理不放行"。

## 四、与您最初设想的差异（请确认）

这一点我们要诚实讲清楚，避免后期理解偏差：

| 您最初的设想 | 调整后的方案 | 原因 |
|---|---|---|
| 打完一圈 → 停 2 秒 → 自动判定 → 红灯补打 | 全程实时看板（工人自己看着别漏）+ 工件离场时判定 | "打完一圈"这个时刻在现场无法稳定识别（见第二节） |
| 漏件**实时**报警 | 屏幕全程实时提示进度；**报警在离场判定时触发** | 加工途中本来就有没打的螺钉，途中报警没有意义 |

**唯一的取舍点**：如果工人没看屏幕提示、漏着一颗就把工件端走了，那报警是在"端走那一刻"才响。这时工件已离手，需要工人**把件放回去补打**（补完红灯转绿），或者由操作员确认为不良。

**请您确认**：这种"全程看板 + 离场报警 + 放回补打"的流程，是否符合贵司现场的实际操作习惯？如果贵司更希望"打完必须停在工位等判定再取件"，那需要在工位上增加一个明确的"完成"动作（比如打完按一下按钮 / 踩脚踏 / 扫一下码），我们可以据此提供另一套方案。

## 五、现场操作流程（工人视角）

```
1. 把工件放上工位 → 系统自动识别 18 颗螺钉, 屏幕亮出 18 个灰点
2. 逐颗打螺钉 → 每打好一颗, 对应点变绿 (工人随时看进度)
3. 打完, 端起工件离开工位
        ├ 18 颗全绿 → 绿灯, 合格, 取走 (完成)
        └ 有灰点未打 → 红灯 + 蜂鸣 + 屏幕高亮漏点
                 ├ 放回工件补打那颗 → 自动转绿灯 → 取走 (合格)
                 └ 没补/确认不良 → 计入不良 + 操作员确认后产线继续
```

---

## 六、需要贵司确认 / 配合的事项

1. **第四节的流程取舍**：能否接受"全程看板 + 离场判定 + 放回补打"？还是需要工位加"完成"按钮/脚踏的另一套方案？
2. **"涂黑"工序**：我们理解本轮已取消，只判"每颗螺钉是否拧到位"。请确认。
3. **红绿灯**：确认是工位上的**物理灯柱**（我们对接现有报警灯柱），屏幕上另有进度看板。
4. **不良确认权限**：不良件放行需要操作员确认，是否需要"普通操作员可确认"还是"必须管理员密码"？
