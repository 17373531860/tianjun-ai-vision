# 附录 A：PLC 侧程序与操作（台达 DVP-ES3 / DVP32ES3，无电工自助版）

> **类型**：how-to
> **本文不讲**：天军软件侧怎么配（见主文档 [PLC完成脉冲对接指南_台达ES3.md](PLC完成脉冲对接指南_台达ES3.md)）、逐件覆盖本身怎么调参（见 `.claude/skills/debug-per-item/SKILL.md`）
> **与代码冲突时**：点表与默认值以主文档 + 代码为准，本文只补 PLC 侧

**这份文档写给谁**：完全没碰过 PLC、现场也没有电工、需要自己把台达 PLC 装起来的人。
**现在该做什么**：PLC 还没到货，**什么都不用装**。先通读一遍第二、三节，知道最后要录进 PLC 的程序只有 3 条梯级（加急停 4 条）。到货后从第六节第 1 步开始照做。

---

## 零、先记住这三句

1. 天军软件**只**做一件事：给 PLC 的 `M100` 写一个 300 毫秒的短脉冲（ON 300ms 后自动 OFF）。它不管气阀开多久。
2. **气阀开多久由 PLC 程序里的定时器 T0 决定**，默认 2.0 秒。要改开阀时间，改 PLC 里的 T0，不用动软件。
3. 别把 `M100` 直接接到气阀输出。要按下面的写法：`M100` 上升沿 → 自锁 → 定时 2 秒 → 自动关。这样万一网络丢了「关」那一帧，阀也会自己关，不会一直吹。

> **安全**：第一次联调时，先把气源关掉（或把电磁阀线拆下来），只看 PLC 面板上 `Y0` 的指示灯亮 2 秒再灭。确认动作对了，再通气。

## 零点五、机种档案（按 DVP-ES3 规格表已确认）

这几条不用再查了，直接照着办：

| 规格 | 值 | 对我们的意义 |
|---|---|---|
| 内置通讯口 | **RS-485 × 2、Ethernet × 1、CANopen × 1** | **有网口 → 走 Modbus TCP，这是主路径。** 灯塔占的串口和它完全无关，不冲突 |
| **没有 USB 编程口** | 编程只能走 **网口** 或 **RS-485** | ⚠️ 别买 USB 打印机线，插不上。第一次连机看 4.2 |
| 主机点数 | 32 / 48 / 64 / 80 | DVP32ES3 = 32 点（16 入 / 16 出），`X0`～`X15`、`Y0`～`Y15` 都在。我们只用 `Y0`（+可选 `X0`） |
| 程序容量 | 64k steps | 我们这段程序 **7 步**，占 0.01% |
| 编程语言 | 支持 IEC 61131-3（LD / ST / SFC / CFC） | 新建程序时**语言必须选 `LD`（梯形图）**，选到 ST/SFC/CFC 就抄不了第三节 |
| 内置 Micro SD 卡槽 | 有 | 可选：程序调好后备份一份到 SD 卡，换板子时能快速恢复 |
| 高速定位输出 | 4 轴 / 8 点 200kHz | `Y0` 通常同时被规划为高速定位输出点，见下方提醒 |

> **关于 `Y0` 的一个提醒**：本程序只用普通 `OUT Y0` 开关阀，**不碰任何定位指令，所以不冲突**，`Y0` 照用没问题。
> 但如果以后这台 PLC 还要接步进/伺服做定位，建议那时把气阀挪到 `Y4` 或更后面的点，把程序里两处 `Y0` 改掉即可。
> **软件侧完全不受影响**——天军只认 `M100`，`Y` 点随你挪。

**还剩两项必须看铭牌**（规格表里没写，且接错会烧板子）：

1. **供电电压**：ES3 主机常见是 **AC 100～240V**，也有 DC24V 供电的型号。**铭牌上一定印着，通电前必须看一眼。**
2. **输出型式**：型号 `T` 结尾 = 晶体管输出（只能带 DC24V 负载，要分清极性和公共端）；`R` 结尾 = 继电器输出（AC/DC 都能带）。这决定 `Y0` 怎么接线。

> 注意：**即使 PLC 本体是 AC 供电，气阀和中间继电器仍然需要一路 DC24V 电源**。别以为 PLC 通了 AC 就万事俱备。

## 一、要装什么软件（PLC 到货后再装）

只需要两个免费软件，都在台达官网下载中心：

| 软件 | 作用 | 必须装吗 |
|---|---|---|
| **ISPSoft** | 写程序、下载到 PLC、在线监控。台达 PLC 的编程软件 | 必须 |
| **COMMGR** | 通讯管理员。ISPSoft 不直接连 PLC，要先在 COMMGR 里建一条「通道」 | 必须 |

**怎么下**：

1. 浏览器打开台达下载中心（`downloadcenter.deltaww.com`），或百度搜「台达 ISPSoft 下载中心」。
2. 搜索框输入 `ISPSoft`，在结果里选「软件/Software」类别，**下版本号最大的那个**。
3. 再搜 `COMMGR`，同样下最新版。（有些 ISPSoft 安装包里已经捆了 COMMGR，装的时候看到勾选项就一起勾上；不确定就两个都单独下。）
4. 官网下载可能要注册一个免费账号，用邮箱注册即可。

**装的时候注意**：

- 解压后**右键 setup.exe → 以管理员身份运行**。不用管理员权限装，后面会连不上 PLC。
- 安装路径别带中文和空格，用默认的 `C:\Program Files (x86)\Delta Industrial Automation\` 就行。
- 杀毒软件/公司安全软件可能拦安装程序，看到弹窗选「允许」。
- **ISPSoft 版本别下太老的**：太老的版本机种列表里没有 ES3 系列，新建项目时选不到你的 PLC。真遇到选不到，回官网下更新的版本重装。
- 装完后 COMMGR 会常驻在屏幕右下角托盘（一个小图标）。**它必须是运行状态**，ISPSoft 才能连上 PLC。开机后如果托盘里没有它，从开始菜单手动启动。
- **ES3 没有 USB 编程口**，所以不用装 USB 驱动、也别买 USB 打印机线。编程走**网口**（一根普通网线，推荐）。

**顺便要买的硬件**（到货后才需要，先知道有这回事）：

| 东西 | 什么时候需要 | 说明 |
|---|---|---|
| 普通网线一根 | **一定要** | PLC 网口 ↔ 电脑/工控机，直连即可 |
| USB → RS-485 转换器 | **只在网口连不上、要走 485 兜底时** | 台达自家的 `IFD6500` 最省事，通用款也行。⚠️ 这个转换器要**专用**，不能和报警灯塔共用同一个 COM 口 |
| DC24V 开关电源 | 要驱动气阀/中间继电器时 | 见第七节接线清单 |
| 中间继电器 | 电磁阀功率较大时 | 见第七节接线清单 |

**没 PLC 时要不要提前装？** 不必急。但如果你想提前熟悉，可以现在就装好，按第三节把程序录进去、存成 `.isp` 文件。到货后只剩「连线 + 下载」两步，会省很多时间。ISPSoft 离线也能编辑和编译，只是不能下载。

## 二、点表（和主文档一致，别另起一套）

| 装置 | 名字 | 谁在写 / 谁在读 | 说明 |
|---|---|---|---|
| **M100** | 完成脉冲（来自 PC） | **天军软件写**，PLC 程序读 | 判合格时被写 ON 300ms 后写 OFF。PLC 程序**只取它的上升沿** |
| **M101** | 开阀请求（自锁位） | PLC 程序自己用 | 收到脉冲置位，定时到复位。天军不碰它 |
| **T0** | 开阀计时器 | PLC 程序自己用 | 默认 **2.0 秒**，决定气阀开多久 |
| **Y0** | 气阀输出（或中间继电器） | PLC 程序输出 | 接电磁阀线圈或中间继电器。大功率阀**必须**经中间继电器 |
| **X0**（可选） | 急停，接**常闭**触点 | PLC 程序读 | 正常时 X0 = ON；急停按下 X0 = OFF → 强制关阀 |

**T0 的设定值怎么填**：ES3 的 `TMR` 指令时基通常是 **100 毫秒**，所以 2.0 秒 = `K20`。

| 想要开阀 | 填 |
|---|---|
| 0.5 秒 | K5 |
| 1.0 秒 | K10 |
| **2.0 秒（默认）** | **K20** |
| 3.0 秒 | K30 |
| 5.0 秒 | K50 |

> **不用查手册也能验证时基**：下载后在监控表里看 `T0` 的当前值。触发一次，如果它在 2 秒内从 0 数到 20 然后阀关掉，时基就是 100ms，K20 正确。如果阀只开了 0.2 秒，说明你这台的时基是 10ms，把 K20 改成 `K200`；如果阀开了 20 秒，时基是 1 秒，改成 `K2`。**按开阀实际秒数等比例改 K 值就对了。**

**急停没接线怎么旁路**：**就用第三节的「最小版」程序，里面根本没有 X0**。⚠️ 千万不要在没接急停线的情况下抄「含急停版」——X0 没接线时一直是 OFF（=急停按下状态），阀永远不会动，你会以为是通讯坏了，白排查半天。等真接了急停常闭线，再加那一条。

## 三、梯形图程序（一共 3 条梯级）

### 3.1 最小版（先用这个，不含急停）

**梯级 1 —— 收到脉冲，置位开阀请求**

```
      ┌────────┐
──────┤ M100 ↑ ├──────────────( SET M101 )
      └────────┘
```

指令写法：

```
LDP  M100        // M100 的上升沿（只在 OFF→ON 那一瞬间导通一次）
SET  M101        // 置位开阀请求，会一直保持 ON 直到被 RST
```

**梯级 2 —— 开阀请求成立，开阀并开始计时**

```
      ┌──────┐
──────┤ M101 ├──────┬────────( Y0 )
      └──────┘      │
                    └────────[ TMR  T0  K20 ]
```

指令写法：

```
LD   M101        // 开阀请求 ON 期间
OUT  Y0          // 气阀输出 ON
TMR  T0  K20     // 同时计时 2.0 秒（K20 = 20 × 100ms）
```

**梯级 3 —— 定时到，关阀**

```
      ┌──────┐
──────┤  T0  ├──────────────( RST M101 )
      └──────┘
```

指令写法：

```
LD   T0          // 计时到达（T0 触点 ON）
RST  M101        // 复位开阀请求 → 梯级 2 的 Y0 立刻断开，T0 也随之复位归零
```

**完整指令列表（可整段核对）**：

```
LDP  M100
SET  M101
LD   M101
OUT  Y0
TMR  T0   K20
LD   T0
RST  M101
```

### 3.2 这个逻辑为什么满足要求

| 要求 | 由哪里保证 |
|---|---|
| 取上升沿、单次触发 | 梯级 1 用 `LDP`（上升沿）。PC 那 300ms 里 `M100` 一直是 ON，但 `SET` 只在变 ON 的那一个扫描周期执行 |
| 不依赖 PC 长持 ON | 自锁位 `M101` 接管了「阀该开着」这件事，`M100` 之后变 OFF 完全不影响 |
| OFF 帧丢了也不会永久粘阀 | 关阀由 PLC 自己的 `T0` 决定，与 PC 无关。哪怕网线在脉冲中间被拔掉，2 秒后阀照样关 |
| 上电 Y0 = OFF | `Y0` 和 `M101` 都是非停电保持型装置，PLC 上电、STOP→RUN 时自动清 0。**不需要额外写初始化程序** |
| 节拍安全 | 一块板 2～3 分钟一次，阀只开 2 秒，两次之间隔得非常远，不会重叠 |

**两个小行为，知道就好**：

- 2 秒内连发两次脉冲（比如你连点两下「试发脉冲」），阀**不会**延长到 4 秒，仍从第一次算起 2 秒后关。想让每次脉冲重新计时，在梯级 1 的 `SET M101` 后面再加一条 `RST T0`（可选，不做也没问题）。
- 如果你的 `M100`/`M101` 恰好落在停电保持区（少数机种可配），那就在最前面加一条上电初始化梯级：用「初始脉冲」触点驱动 `RST Y0` + `RST M101`。初始脉冲触点在 AS/ES3 上常见是 `SM402`，老 DVP 系列是 `M1002`——在 ISPSoft 里搜「初始脉冲」能查到你机种的叫法。**不确定就先别加这条，不影响功能。**

### 3.3 含急停版（只有真接了急停常闭线才用）

把梯级 2 改成串一个 `X0` 常开触点，并加一条梯级 4：

```
LDP  M100
SET  M101

LD   M101
AND  X0          // 急停常闭：正常时 X0 = ON，串在这里才允许输出
OUT  Y0
TMR  T0   K20

LD   T0
RST  M101

LDI  X0          // X0 = OFF（急停被按下）时导通
RST  M101        // 强制撤销开阀请求，急停松开后也不会自己再开
```

急停按下时：`X0` 变 OFF → 梯级 2 不输出（阀立刻关）+ 梯级 4 复位 `M101`。松开急停后阀保持关闭，要等下一次完成脉冲才会再开。

### 3.4 在 ISPSoft 里怎么把这些录进去

1. 项目树里双击 **Prog0**（或 `程序 → Prog0`）打开梯形图编辑区。
2. 光标点在第一行的第一个格子上。
3. **最省事的录入方式：直接敲指令。** 选中格子后直接键盘输入 `LDP M100`，回车，ISPSoft 会自动画出上升沿触点。依次把第三节的指令列表一行一行敲进去。
4. 也可以用鼠标：点工具栏的触点图标（`-| |-` 常开、`-|/|-` 常闭、`-|↑|-` 上升沿）放到格子里，再在弹出框填装置名（如 `M100`）；输出线圈用 `-( )-` 图标；`SET` / `RST` / `TMR` 这类属于应用指令，用「应用指令」图标 `{ }`，然后填指令名和操作数。
5. 每写完一条梯级，按工具栏或菜单里的**「编译」**。编译窗口报 0 错误才算录对了。有错会指到具体那一行。
6. 存盘：`文件 → 另存为`，起名 `完成脉冲_气阀.isp`，放到你自己找得到的目录。**这个文件要留好**，以后换电脑、改开阀时间都靠它。

> 上面提到的按钮名称以你装的 ISPSoft 版本为准，位置可能略有差异，但「编译」和「另存为」一定在菜单里能找到。

## 四、通讯侧：让 PLC 能被天军连上

**好消息**：Modbus TCP 从站是 ES3 内建功能，**PLC 侧不用写任何通讯程序**。你只要给 PLC 设一个 IP 地址，天军就能连上写 `M100`。

### 4.1 推荐默认值（到货后按现场实际填最后一列）

| 项 | 推荐值 | 说明 | 现场实际 |
|---|---|---|---|
| PLC IP | `192.168.1.5` | 台达出厂常见默认值。以 ISPSoft 的 HWCONFIG 打开后显示的为准 | ______ |
| 子网掩码 | `255.255.255.0` | 固定这个 | ______ |
| 默认网关 | 留空或 `192.168.1.1` | 同一根网线直连时用不到 | ______ |
| Modbus 端口 | **`502`** | Modbus TCP 标准端口，别改 | ______ |
| Modbus 站号 | **`1`** | 天军界面「从站号」填一样的值。连不上时可试 `0` 或 `255` | ______ |
| 工控机 IP | `192.168.1.100` | 前三段必须和 PLC 一样，最后一段不能相同 | ______ |

### 4.2 怎么给 PLC 设 IP

在 ISPSoft 里：项目树双击 **HWCONFIG** → 双击画面里的 CPU 模块 → 找到 **以太网 / Ethernet 基本设定** → 填 IP 地址、子网掩码 → 关掉参数窗口 → 在 HWCONFIG 里点**下载**（把硬件组态下到 PLC）→ 设定生效。

**第一次不知道 PLC 的 IP 怎么办**（ES3 没有 USB 口，按这个顺序试）：

1. **先试出厂默认 IP**（最快）：把电脑 IP 手动设成 `192.168.1.100 / 255.255.255.0`，网线直连 PLC，命令行 `ping 192.168.1.5`。通了就照 4.2 进去改成你想要的 IP。
2. **让 COMMGR 扫一下**：在 COMMGR 里建 Ethernet 通道时，IP 输入框旁边一般有「搜索 / Search」之类的按钮，能把同一网段内的台达设备广播扫出来，直接读到真实 IP。
3. **走 RS-485 兜底**：用 USB → RS-485 转换器（如台达 `IFD6500`）接到 PLC 的 **COM1（RS-485）** 端子，COMMGR 里建一条串口通道（类型选 RS232/RS485 一类，波特率按手册默认，台达常见 `9600, 7, E, 1`，站号 1）。连上后照 4.2 改 IP，之后就可以拔掉 485 只走网线了。

> 第 3 条只是为了「进得去改 IP」。**日常运行不需要 485**，天军是走网口的。

### 4.3 本项目的实际接法（USB 相机 + 工控机网口空闲 + 不上 MES）

这是最简单的一种：**PLC 独占工控机的网口，一根普通网线直连，两端各插一头，中间什么都不要。** 不需要交换机、不需要路由器、不需要接厂内网，也不用找 IT 要 IP 地址。

⚠️ **这种直连场景必须给工控机手动设静态 IP。** 因为这根线上没有路由器发地址，网卡如果留着"自动获得 IP"，几十秒后会自己分配一个 `169.254.x.x` 的地址，然后 `ping` PLC 永远不通——**这是直连接法头号翻车原因**。

工控机上设置（Windows）：

1. `控制面板 → 网络和共享中心 → 更改适配器设置`（或桌面右下角网络图标右键 → 打开网络设置）。
2. 右键那块接 PLC 的「以太网」→ **属性**。
3. 双击列表里的 **Internet 协议版本 4 (TCP/IPv4)**。
4. 选「**使用下面的 IP 地址**」，填：
   - IP 地址：`192.168.1.100`
   - 子网掩码：`255.255.255.0`
   - **默认网关：留空**（直连用不到，填了反而可能让 Windows 以为这是主网卡）
   - DNS：**留空**
5. 确定 → 确定。命令行 `ping 192.168.1.5` 应该能通。

两个正常现象，别当故障：

- Windows 右下角网络图标会显示黄色感叹号 / 「无 Internet 访问」。**这是对的**，这根线本来就只通到 PLC。天军的 License 是本机验证，不需要联网。
- PLC 断电时 Windows 会提示「网络电缆被拔出」。也正常，PLC 上电就恢复。天军只在发脉冲那一刻才去连 PLC，平时不占连接。

因为没接厂内网，你还顺带省掉了这些麻烦：不会 IP 冲突、不会被 DHCP 抢地址、防火墙不用配外网规则。IP 就用上面这一对，记到第九节表里。

### 4.4 同网段与网线注意点（换现场/换接法时看）

- **前三段一样、最后一段不同**：`192.168.1.5`（PLC）和 `192.168.1.100`（工控机）是对的；`192.168.1.5` 和 `192.168.2.100` 连不上。
- PLC 和工控机**一根普通网线直连就行**，不需要交叉线，也不一定要交换机。
- 网线远离变频器、伺服动力线走，别和动力线捆在同一根线槽里。**这是本项目唯一需要认真对待的物理层要求**（数据量极小，带宽从来不是问题，干扰才是）。

以下情况本项目用不上，换现场时再看：

- **工控机网口已经接了厂内网/MES**：加一块 USB 网卡或 PCIe 网卡专门接 PLC。⚠️ 两块网卡**不能设成同一网段**，否则 Windows 会走错网卡。
- **视频源是网络摄像头/NVR**：把 PLC 挂到相机那台交换机上，IP 设成同网段一个没人用的地址即可（相机码流几 Mbps，PLC 几乎不占带宽，不会互相影响）；或者同上加一块独立网卡。
- **厂内网是路由器自动分配（DHCP）**：PLC 用固定 IP，要避开 DHCP 地址池，免得撞地址。

### 4.5 和报警灯塔不会冲突

灯塔走的是工控机的**串口（COM）**，PLC 走的是**网口**，物理上就是两套，天然不冲突，不需要做任何隔离设置。ES3 规格已确认有 Ethernet，所以这是默认状态。

两种会碰到串口的情况，都**必须用独立的 USB-485 转换器**，绝对不能和灯塔共用同一个 COM 口（共用会两边都失灵）：

- 只是临时接 485 去改 PLC 的 IP（4.2 第 3 条）——改完拔掉即可，天军侧不用动。
- 极端情况下网口实在用不了，要让天军长期走 Modbus RTU：天军界面「连接方式」改选 `Modbus RTU (485 串口)`，填这个专用转换器的 COM 口。**点表和 PLC 程序完全不变**，`M100` 还是 `M100`。

## 五、到货后需要核对的几项

规格表已经确认了通讯口、点数、编程语言（见 0.5 节），**不用再查**。剩下这几项到货后花十分钟核对，能省掉后面 90% 的排查。手册在台达下载中心搜 `DVP-ES3 操作手册` / `DVP-ES3 程序手册`。

**看铭牌就行的两项（通电前必看，接错会烧板子）**：

| 要看什么 | 怎么判断 | 影响什么 |
|---|---|---|
| **供电电压** | 铭牌印的输入电压。ES3 常见 `AC 100~240V`，也有 DC24V 型号 | 接错直接烧。见第七节第一条 |
| **输出型式** | 型号后缀：`T` = 晶体管输出、`R` = 继电器输出 | 决定 `Y0` 怎么接线、能不能直接带阀。见第七节 |

**可以不查手册、用现场试出来的两项**：

| 要核对什么 | 手册在哪写 | 不想查手册就这么试 |

| **M100 的 Modbus 地址是不是 2148** | 程序手册「Modbus 装置对应地址」表 | 照主文档填「台达 M 编号 = 100」，点「试发脉冲」，在 ISPSoft 监控表里看 `M100` 有没有闪。闪了就是对的；不闪按第七节第 7 条试 2147 / 2149 |

## 六、到货后的操作顺序（照这个次序做，别跳）

**准备阶段**

1. 装 ISPSoft，装 COMMGR（第一节）。确认 COMMGR 在右下角托盘运行。
2. **先看铭牌确认供电电压**（AC 还是 DC24V），按第七节接好电源并通电。**这一步先不接气阀**，`Y0` 端子空着。
3. 一根普通网线，把 PLC 的网口和电脑/工控机连起来。

**建立通讯**

4. 打开 **COMMGR** → `Add`（新增）→ 建一条 **Ethernet (TCP/IP)** 通道，填 PLC 的 IP，起个名字如 `PLC_ETH`，建好后把状态点成 **START**（绿色）。
   - 还不知道 PLC 的 IP？按 4.2 那三条顺序试（先试默认 `192.168.1.5`）。
5. 打开 **ISPSoft** → `文件 → 新建项目`：
   - **机种一定要选对**：控制器类型选 `DVP-ES3`（或列表里与你铭牌一致的 ES3 型号）。选错机种会编译报错或下载失败。
   - 如果弹出让选**程序语言/POU 语言**：**必须选 `LD`（梯形图）**。ES3 支持 LD/ST/SFC/CFC 四种，选到别的就抄不了第三节的程序。
   - `工具 → 通讯设定`，选第 4 步建的那条通道，确定。
6. 试连一下：菜单 `PLC → 系统信息`（或任意读取动作）。能读出 PLC 型号 = 通讯通了。读不出来看第七节排查。

**录程序并下载**

7. 按第三节把 3 条梯级录进去，**编译 0 错误**，存盘。
8. 如果要改 PLC 的 IP：进 HWCONFIG 设好并下载硬件组态（4.2）。
9. 把 PLC 打到 **STOP**（面板拨钮拨到 STOP，或 ISPSoft 菜单 `PLC → STOP`）。**下载必须在 STOP 状态**。
10. `PLC → 传输 → 下载`，勾选「程序」和「硬件组态」，确定。等进度走完。
11. 把 PLC 打回 **RUN**（面板拨钮或 `PLC → RUN`）。面板 RUN 灯亮、ERROR 灯不亮。

**PLC 单机自测（还不用天军）**

12. ISPSoft 里 `视图 → 装置监控表`（或项目树里新增监控表），把 `M100`、`M101`、`Y0`、`T0` 四个都加进去，点**「在线监控」**。
13. 在监控表里右键 `M100` → **强制 ON**，然后马上右键 → **强制 OFF**（或用「上升沿强制」一类的功能）。
    应该看到：`M101` 变 ON → `Y0` 变 ON（PLC 面板 Y0 指示灯亮）→ `T0` 当前值从 0 往上数 → 数到 20 → `M101` 和 `Y0` 一起变 OFF，灯灭。**整个过程约 2 秒。**
    - ⚠️ 做完测试**一定要解除所有强制**（右键 → 解除强制 / 全部解除）。留着强制会让后面联调看到假象。
14. 这一步成功 = PLC 程序完全正确。剩下的问题都只可能在通讯或接线。

**接执行机构**

15. 断电，按第七节把 `Y0` 接到中间继电器/电磁阀，恢复上电。重做一次第 13 步，这次应该能听到阀动作 2 秒。

**和天军联调**

16. 按主文档第二节在「MES → 外部设备」里配好这台设备（预设模板 → 填 IP → 地址填 100 → **选绑定工位** → 保存）。
17. 点卡片上的「**测试**」——通了说明网络和端口对。
18. 点卡片上的「**试发脉冲**」——同时盯着 ISPSoft 监控表。`M100` 闪一下、`Y0` 亮 2 秒、阀动作 = **全链路打通**。
19. 最后跑一块真板子：打完螺丝、系统判合格，看阀是否自动动作一次。

**收尾备份（建议做）**

20. 程序确认无误后存一份 `.isp` 到 U 盘或工控机上，并把第九节两张表填完。
21. ES3 有 **Micro SD 卡槽**：插一张卡，用 ISPSoft 的「PLC → 存储卡 / 备份」功能把程序备份进去。以后 PLC 换板子或程序丢了，插卡就能恢复，不用重新装 ISPSoft 录一遍。

## 七、失败排查（10 条）

| # | 现象 | 原因和处理 |
|---|---|---|
| 1 | ISPSoft 连不上 PLC（读不到系统信息） | ① COMMGR 没启动，或那条通道不是 **START** 绿色状态 ② ISPSoft 的 `工具 → 通讯设定` 没选中这条通道 ③ 走网口时 IP 不同网段：命令行 `ping PLC的IP` 不通就是网络问题 ④ ISPSoft 不是以管理员身份运行 |
| 2 | `ping` PLC 不通 | ① 电脑 IP 前三段和 PLC 不一致 ② 网线没插好/网口灯不亮 ③ 电脑上装了两块网卡且设成了同一网段 ④ PLC 的 IP 不是你以为的那个——**ES3 没有 USB 口进不去**，按 4.2 顺序办：先试默认 `192.168.1.5`，再用 COMMGR 的搜索按钮扫，最后才用 USB→RS-485 转换器接 COM1 进去看真实 IP |
| 3 | 下载失败/报错 | ① PLC 不在 **STOP** 状态——下载必须先 STOP ② 新建项目时**机种选错**（不是 DVP-ES3）③ 程序没编译或编译有错 ④ 下载途中通讯中断，重试一次 |
| 4 | 编译报错找不到指令 / 编辑区画不出触点 | ① ISPSoft 版本太老不支持 ES3，或机种选错——回官网下最新版重装 ② **POU 语言选成了 ST/SFC/CFC**：那种编辑器是打字或流程图，不是梯形图。删掉这个程序 POU 重建一个，语言选 `LD` |
| 5 | 天军点「测试」就失败 | ① PLC 没上电/没 RUN ② IP 或端口填错（端口必须 `502`）③ 工控机和 PLC 不同网段（先在工控机上 `ping` 通再说）④ 工控机防火墙拦了出站连接（少见，把天军后端加白名单） |
| 6 | 「测试」通了但「试发脉冲」失败 | ① **从站号**不对：先试 `1`，不行试 `0` 或 `255` ② 天军界面「写入类型」误选成「保持寄存器 D」——写线圈必须选「线圈 M/Y」 ③ 地址超出 PLC 支持范围 |
| 7 | 「试发脉冲」提示成功，但 `M100` 在监控表里根本不闪 | **地址 0 基/1 基搞错了**，这是最常见的坑。天军界面填的是 **0 基**：M100 = 2148。有些手册和上位机软件按 1 基写作 `002149`，比这个大 1。处理办法：界面「地址填写方式」改选「Modbus 原始地址 (0 基)」，2148 不行就试 2147 或 2149，每试一次点「试发脉冲」看 `M100` 是否闪。闪了就定死这个值 |
| 8 | `M100` 会闪，但 `Y0` 不动 | ① 程序没下载成功（重下一次）② PLC 在 STOP 没在 RUN ③ 抄了「含急停版」但急停线没接——`X0` 一直 OFF 把阀锁死了，改用「最小版」（见 2 节末的警告）④ 监控表里还留着强制没解除 |
| 9 | `Y0` 灯亮但阀不动 | 这是电气侧不是程序侧：① 24V 电源没接/保险丝断 ② 电磁阀是大功率的，晶体管输出（型号 `T` 结尾）带不动，必须加中间继电器 ③ 晶体管输出接线极性/公共端接错 ④ 气源没开、气管没通 |
| 10 | 阀一直吹不关 / 开的时间不对 | ① 开的时间不对是**时基问题**，按第二节等比例改 `K` 值 ② 一直不关：检查梯级 3 是不是漏录了，或 `T0` 编号在两处写得不一致（梯级 2 写 T0、梯级 3 也必须是 T0）③ 手动能关但自动不关，检查是否误改成了「脉冲宽度 = 0」（那种模式要 PLC 自己清 `M100`，本文程序不适用） |
| 补 | 打完螺丝不自动发（手动能发） | 属于软件侧，见主文档第六节：最常见是**没绑定工位**，其次是这一轮判了 NG（NG 本来就不发脉冲） |

## 八、接线检查清单（通电前逐项打勾）

**电源**

- [ ] **先看铭牌印的输入电压再通电**：ES3 主机常见是 **AC 100～240V**，也有 DC24V 供电型号。⚠️ **把 220V 接到 DC24V 机种、或把 24V 接到 AC 机种，都会当场烧板子。** 铭牌怎么写就怎么接
- [ ] AC 供电机种：火线/零线接在标 `L` / `N` 的端子上，别接到输入点端子去
- [ ] DC24V 供电机种：正负极别接反（端子标 `+24V` / `0V` 或 `24G`）
- [ ] **另备一路 DC24V 给气阀和中间继电器**——PLC 本体是 AC 供电时也一样需要。机身自带的 24V 输出端子只够带输入点/小传感器，别用它去驱动电磁阀
- [ ] 24V 电源容量够（所有输出负载相加，留 30% 余量）
- [ ] 电源进线有空开/保险丝
- [ ] PLC 的 `FG`/接地端子接厂房地线

**Y0 输出侧**

- [ ] 看清型号后缀：`T` = 晶体管输出（**只能** DC24V 负载，要接对公共端和极性）；`R` = 继电器输出（AC/DC 都行）
- [ ] `Y0` 所在输出组的**公共端（COM/UP-ZP 之类）已接**，不接公共端输出永远不动
- [ ] **电磁阀功率大于 PLC 单点输出能力时，必须经中间继电器**：`Y0` 只驱动继电器线圈，继电器触点再去驱动电磁阀
- [ ] 电磁阀/继电器线圈这类**电感负载并了吸收元件**：DC 负载并二极管（反向并接，注意方向）、AC 负载并 RC 吸收器。不加，输出点会被反峰电压慢慢打坏
- [ ] 输出线和 24V 动力线分开走，不和变频器动力线同槽

**输入侧（只在启用急停时）**

- [ ] 急停按钮用**常闭（NC）**触点接到 `X0`
- [ ] 输入公共端（`S/S` 或 `SS`）已按手册接 24V 或 0V
- [ ] 没接急停就**不要**用含急停版程序（见第二节警告）

**网络**

- [ ] 网线插在 PLC 的 RJ45 网口，两端网口灯有亮
- [ ] PLC 与工控机同网段、末位不冲突
- [ ] 网线不和动力线捆在一起

**与现有报警灯塔的关系**

- [ ] 灯塔仍接工控机**串口（COM）**，没有被改动
- [ ] PLC 走**网口**，和灯塔各走各的
- [ ] 万一走 Modbus RTU：PLC 用**独立的** USB-485 转换器，**没有**和灯塔共用 COM 口

**联调安全**

- [ ] 第一次测试前气源关闭或电磁阀线拆开，只看 `Y0` 指示灯
- [ ] 气阀的执行机构行程内没有手、没有工件卡着
