# v3.59.0 (2026-09-17)

> 单功能版：自定义模式新增「容器定界周期」——周期主权可归容器（容器到位开周期、离场立即结算，周期内动作无序完备判定）。默认 `custom_cycle_owner='steps'` 零配置差异。源自东莞现场"箱体常驻画面、周期内完成拿说明书/拿电池等动作"的包装场景诉求。

## 功能变更

- [FEAT-001] 容器定界周期：自定义模式周期主权可归容器
  - 需求: 现场场景为"包装盒进入画面即一个工件周期开始，工人在盒内完成若干动作（拿说明书/拿大小电池，无固定顺序），盒子离开画面立即出 OK/NG"。既有模式全部不匹配：检测模式 `last_step` 结算会自动剥掉结算步骤的 `accept_once`，叠加检测模式"步骤交替即算新出现"规则，常驻画面的包装盒每次动作交替后重复入账 → 永远 NG（四轮真实视频实验复现确认为结构性冲突，不是参数问题）；既有混合跟踪（custom_mixed_with）契约明确"周期主权归步骤侧"，容器只是计数器不是周期边界；独立跟踪模式容器有主权但判定只有数量维度
  - 实现:
    - **ContainerCycleGate**（`source_custom_mix.py`）：`pipeline_config.custom_cycle_owner='container'` 时构建。容器标签稳定在场满 `container_gate_appear_seconds`（默认 1s，防闪现误开）确认开周期；离场满 `container_gate_gone_seconds`（默认 3s，桥接工人俯身遮挡丢检）确认后强制结算。容器标签由门独占消费不入步骤侧记账；容器缺席时整帧动作不入账、不误开周期（工件不在位的动作不算数）
    - **`_settle_container_cycle`**（`source_settlement_mixin.py`）：容器离场结算入口，按 `custom_based_on` 分支——`sequential` 走原 `_settle_custom_cycle`；纯 custom 走原结算器带空闲中断事件回退；`detection` 形态做**无序完备判定**（必做步骤全到场=OK、缺步=NG 带缺步原因；同一动作重复出现宽容不判 NG，与检测模式的重复步骤 NG 语义不同——容器场景下工人多拿一次说明书不是缺陷）
    - **步骤侧让位守门**（`_custom_cycle_owner=='container'` 时）：events_check 自定义结算块整体让位（尾部步骤特定事件照常）、first_step 重现结算让位、空闲超时让位、首个动作入账不二次 `start_cycle`
    - **runner 标签过滤放行**：容器标签行建议 `enabled=False`（不参与完备判定），`_get_enabled_labels` 显式放行容器标签，否则推理出口就被丢弃、周期永远开不了
    - **状态卫生**：`_clear_step_runtime_state` 联动 `gate.reset()`（停止/切项目不留在场残影）；`start_cycle` 静默未开成时下一帧自动重试
    - **前端**：LogicConfigTab 自定义模式新增「周期定界」选择器（步骤驱动/容器定界）+ 容器定界参数卡（容器标签下拉可输 + 到位确认秒 + 离场确认秒），index.vue 水合/同步/保存三处对齐
    - **可观测**: `/source/detection/results` 透出 `container_gate`（容器在场/周期开合/离场倒计时），未配置不透出零差异
  - 验证: 单测 22 例（门 FSM/构建守门/结算分支/让位守门）+ 相邻回归 229 例绿 + e2e 浏览器测试 3 例（预填/翻转保存/默认零差异）+ 真实视频跑批 13 周期 11 OK 2 NG（1 NG 为片头空盒收走判缺步符合语义，1 NG 为该项目 label_splits 区域配置误差与模式无关）
  - 影响文件: backend/api/source_custom_mix.py, backend/api/source_settlement_mixin.py, backend/api/source_step_stats_mixin.py, backend/api/source_events_check_mixin.py, backend/api/source_project_config_apply.py, backend/api/source_state_init.py, backend/api/source.py, backend/api/source_routes.py, frontend/src/views/Project/LogicConfigTab.vue, frontend/src/views/Project/index.vue, tests/test_container_cycle_gate.py(新), tests/e2e_browser/test_container_cycle_owner.py(新)
