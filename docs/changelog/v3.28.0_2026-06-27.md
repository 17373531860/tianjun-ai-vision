# v3.28.0 (2026-06-27)

> 主题：**逐件覆盖模式（打螺丝漏打场景）大幅增强 + 插件配置统一保存接入主程序保存按钮 + 传感器清洁插件 v1.2.0**。
> 主线给逐件覆盖模式补齐「工件离场快照判定 + 漏打挂起待补/待确认态 + 判定时机与结算时机解耦」三块能力，全部默认关 = 老项目零差异；插件平台新增项目 Tab `onSave` 统一保存能力（插件配置随项目「保存配置」一并落库，免插件自带保存按钮）；传感器清洁插件升级 v1.2.0（选择性抑制系统自带 OK/NG 提示框 + 棉签使用记录数据页）。

## 功能变更

- [FEAT-001] 逐件覆盖模式：工件离场快照判定 + 漏打挂起待补态（打螺丝漏打场景）
  - 需求: 打螺丝逐颗覆盖场景下，工人未扭完就把工件拿走会被直接判 NG，没有"补打"的缓冲；离场判定也缺一个稳定时机
  - 实现: 新增"离场触发结算"（工件标签持续消失=离场，可与"拿取动作"组成双条件防误判提前结算）；新增"漏打挂起待补（NG 保护）"——离场时若有漏打不立即记 NG，进待补态点灯提示漏哪颗，工人补满转 OK，超时/人工点「确认 NG」才落账；待补报警支持 once/sustained 两种触发形式 + 待补超时秒数 + "红灯内取件算 NG" + 框色高亮（已扭/未扭分色）
  - 影响文件: backend/api/source_per_item_mixin.py, backend/api/source_routes.py, frontend/src/views/Project/index.vue, frontend/src/views/Monitor/index.vue, frontend/src/views/Monitor/PerItemPanel.vue

- [FEAT-002] 逐件覆盖模式：判定时机与结算时机解耦（判定层）
  - 需求: 老逻辑只在结算那刻一次性判 OK/NG，无法做到"打完即亮绿、取走才落账"，也无法手动点判定
  - 实现: 新增 judge_timing（on_settle 默认/all_done 全覆盖完即判/label 指定标签出现即判/manual 手动点击判定）；判定层只拍快照亮绿/红不落账，落账仍由结算时机负责；判定合格绿灯走可配 judge_ok_event_id（与落账"合格"事件分开）；检测主页新增「手动判定」按钮（per-item-control action=judge）
  - 影响文件: backend/api/source_per_item_mixin.py, backend/api/source_routes.py, frontend/src/views/Project/index.vue, frontend/src/views/Monitor/PerItemPanel.vue

- [FEAT-003] 插件平台：项目 Tab `onSave` 统一保存能力
  - 需求: 插件项目配置 Tab 之前需自带"保存配置"按钮，与主程序「保存配置」并存造成双按钮、且插件保存常出现保存后回弹
  - 实现: 项目 Tab 注册时可多传 onSave 异步处理器，主程序「保存配置」成功后通用地调用各 Tab 的 onSave，插件配置随项目一并落库，插件无需自带保存按钮
  - 影响文件: frontend/src/composables/usePluginLoader.js, frontend/src/store/usePluginThemeStore.js, frontend/src/views/Project/index.vue

- [FEAT-004] 传感器清洁插件 v1.2.0：选择性抑制提示框
  - 需求: 插件整页覆盖会连带抑制掉全部提示框，客户希望"只盖系统自带 OK/NG 用插件红色横幅，其他自定义事件提示框仍正常展示且事件仍有效"
  - 实现: 插件前端只抑制系统自带 OK/NG 提示框，自定义事件提示框透传展示；修正 event_id 字符串/数字类型比较（后端按字符串记 event_id，前端用 Number() 归一）导致的误抑制
  - 影响文件: plugins-examples/sensor-clean/frontend/dist/index.esm.js, plugins-examples/sensor-clean/plugin.json

- [FEAT-005] 传感器清洁插件 v1.2.0：棉签使用记录数据页（数据中心对齐）
  - 需求: 插件需要一个与主程序数据中心对齐的、面向棉签生命周期的数据页（每根棉签产品数/NG/超限/时长）
  - 实现: 插件整页覆盖数据中心（data.layout.body 槽位），新增独立 SQLite 表 p_sensor_clean_swab_records；内存累加当前棉签，换签/超限/手动复位三点定稿落库；前端统计卡 + 轻量柱状图 + 明细表格 + 筛选 + CSV 导出；新增后端 /swab/records 查询接口
  - 影响文件: plugins-examples/sensor-clean/backend/hooks.py, plugins-examples/sensor-clean/backend/routes.py, plugins-examples/sensor-clean/backend/preset.py, plugins-examples/sensor-clean/backend/__init__.py, plugins-examples/sensor-clean/frontend/dist/index.esm.js
