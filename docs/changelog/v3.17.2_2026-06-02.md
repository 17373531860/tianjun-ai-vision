## Bug 修复（根因定位 + 配置解法，非代码改动）
- [BUG-001] 金龙 GW1 末步结算「重复步骤」误判 NG
  - 症状: 浸泡结束/热水浸泡等工序步骤反复进出画面，整周期被判 NG+1；客户称已开「严格顺序 + 单次接受」仍 NG。
  - 根因: 守门拦截要求「严格顺序」AND「单次接受」**同时**为真。JLGW1 关键两步（热水浸泡/浸泡结束）库内 `accept_once=0`（只开了严格顺序），守门不触发 → 重现进周期判回退 NG。客户自述「开了单次接受」实际未保存生效。
  - 修复: 配置层 —— 给这两步补开「单次接受」。已用真实模型 bestGW1.pt + 真实现场视频端到端验证：单次接受关 → 该周期 NG；开 → OK。
  - 影响文件: tests/test_jlgw1_settlement_repro.py（真实视频端到端复现剧本）, tests/test_strict_once_first_step_guard.py（守门回归护栏）

## 已知问题
