# v3.47.0 (2026-08-07)

> 本版是一次**多分支汇合发版**：将并行开发的 5 个 worktree 分支（system-optimize / external-connect / worktime-plugin / multi-workstation / sy8）与 dev-qing 补账两提交全部吸收进主线，逐分支合并逐分支回归。

## 功能变更

- [FEAT-001] 多工位监控布局重构（三工位横排 + 网格分页总览 + 放大详情）
  - 需求: 原监控页固定 2x2 网格，三工位缺一角难看，且工位数硬上限 4，多工位客户无法扩展
  - 实现: 三工位=三行横排（左视频 16:9 右数据面板，均接显示设置开关）；4+ 工位=网格总览（自动/2x2/3x3/4x4 可选 + 分页），点卡片放大单工位详情（大视频+SOP 大图+CT 指标，上一路/下一路循环）；后端 MAX_CHANNELS 4→64，Source 页自定义工位数同步放开；MJPEG 按「可见工位」收放流（数据轮询仍覆盖全部工位，翻页不丢计数/Toast/MES）；流被服务端正常收流后自动重连（带可见性守门）
  - 影响文件: frontend/src/views/Monitor/index.vue, frontend/src/views/Source/index.vue, backend/api/channel_manager.py, tests/e2e_browser/test_multi_workstation_layout.py

- [FEAT-002] YoloVision 训练平台互连 v1.1（模型双向分发 + 现场帧采样回流自学习闭环）
  - 需求: 与公司训练平台打通"现场出难样本 → 平台训练 → 新模型下发"闭环，契约 interconnect-contract 1.1
  - 实现: 模型通路——POST /api/v1/interconnect/models/push 接收 .yvmodel 包（路径穿越/违禁载荷/zip 炸弹/逐产物 SHA-256 安全校验）+ 拉取分发模式（游标增量轮询，坏包跳过不卡游标、传输失败停轮保序）；models 表加 source/meta 列（迁移 m0008），模型仓库来源徽标 + 训练分析弹窗。样本通路——推理循环挂采样器（错误隔离，关闭 O(1) 早退；置信度带/未检出周期内守门/检出闪断/NG 事件帧），磁盘队列 + 后台 worker 异步回传（限流+指数退避+对端离线不丢帧）；device_id 稳定身份（License machineId 同源）。前端互连设置页 + 导航入口。默认关，零配置零影响
  - 影响文件: backend/api/interconnect.py, backend/services/interconnect/*（7 个新文件）, backend/db/migrations/m0008_model_interconnect_meta.py, frontend/src/views/Interconnect/index.vue, frontend/src/api/interconnect.js

- [FEAT-003] 客户环境开机首启提速 + 授权激活转圈治本（六项）
  - 症状: 开机后第一次启动等十分钟以上、偶发启动失败要重开；授权导入后按钮一直转圈
  - 实现: ①import-license 验签立即返回，后端冷启动移出 IPC，启动失败弹明确错误不再无限转圈 ②逐通道模型加载+视频源恢复移入 startup-heavy-init 后台线程（顺带修检测恢复先于 mes_hook 注入的隐患），RTSP 打开加 10s 超时并补回 threads;1 保护 ③Electron 启动 300s 死线改弹性（日志滚动就延展、静默 90s 判死、绝对上限 20min，启动期进程退出立即止损）④安装器把安装目录+数据目录加 Defender 排除（卸载移除）⑤孤儿扫描降频 7 天一次、诊断 COUNT(*) 改 MAX(id)、自动清理延后 5 分钟、m0007 补 defect_records.cycle_id 索引 ⑥machineId 缓存命中快路径，指纹校验后台异步
  - 影响文件: electron/main.js, electron/preload.js, electron/backend-manager.js, electron/license-manager.js, electron/build/installer.iss, frontend/src/views/Activation/index.vue, backend/main.py, backend/api/source_camera_start_mixin.py, backend/api/source_capture_loop_mixin.py, backend/db/migrations/m0007_defect_cycle_index.py

## Bug 修复

- [BUG-001] 短信配置保存中文模板变乱码（dev-qing 补账）
  - 症状: 保存短信配置后 AT 模板中文偶发被覆盖为平铺脏字段
  - 根因: 保存时平铺字段优先于嵌套 at_modem 字段回显
  - 修复: 嵌套 at_modem 优先于平铺脏字段
  - 影响文件: backend/services/sms_config.py

- [BUG-002] macOS 多通道 MPS 并发推理触发 Metal 断言弑进程
  - 根因: MPS 不支持跨线程并发 predict/empty_cache
  - 修复: `backend/core/torch_device.py` 全局 MPS_LOCK 把 predict/warmup/release/empty_cache 全部串行；客户机 Windows CUDA 不受影响
  - 影响文件: backend/core/torch_device.py, backend/api/source_detect_runners_mixin.py

- [BUG-003] 模型加载幂等按名字比对导致通道 gpu_device 不生效
  - 修复: 幂等判断按**实际设备**比对，激活/启动尊重通道 gpu_device 配置
  - 影响文件: backend/api/source_model_load_mixin.py, backend/api/channel_manager.py

- [BUG-004] layout.body 整页覆盖插件与宿主取流互踢（画面冻帧、检测框还在动）
  - 根因: 插件 <img> 与宿主 fetch(/video_feed) 抢同一通道 MJPEG 连接（后端每通道只保留最新一条）
  - 修复: 覆盖生效时宿主拒绝起流（startMultiStreams 入口守卫）+ fetchChannelCount 先停旧流
  - 影响文件: frontend/src/views/Monitor/index.vue

- [BUG-005] start_backend.sh 在 miniconda/macOS 环境启动失败
  - 修复: 自动探测 conda 安装位置（anaconda3/miniconda3，用户目录或 /opt）+ 环境名回退 + 去掉 macOS BSD xargs 不支持的 -r
  - 影响文件: start_backend.sh

- [BUG-006] alarm 页 e2e 汇总文案断言未随数字口径动态文案更新（dev-qing 欠账）
  - 修复: 页面对象断言取两种口径共有前缀
  - 影响文件: tests/e2e_browser/pages/alarm_page.py
