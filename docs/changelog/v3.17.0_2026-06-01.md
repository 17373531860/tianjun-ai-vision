# v3.17.0 (2026-06-01)

> 福建金龙双工位定制 R1–R5 全功能完整验证发布：把「步骤耗时三档」配置列改为**按插件存在条件渲染**（未装插件客户字节级零差异，修 v3.16.0 给所有客户都显示该列的体验缺陷），并以完整 E2E / BDD / 可见浏览器 UAT 矩阵确认 R1–R5 全部可交付。

## 功能变更

- [FEAT-001] 「步骤耗时三档」配置列按插件存在条件渲染
  - 需求: v3.16.0 在项目步骤设置表无条件加了「步骤耗时三档」列，没装福建金龙插件的客户也会看到一列空的「需插件」占位，属体验缺陷。
  - 实现: 新增 `hasDurationsSlot` 计算属性（探测插件是否注册了 `project.step-cell.durations` 插槽），表头 `<th>` 与单元格 `<td>` 同加 `v-if="hasDurationsSlot"`；未装插件时整列（表头+单元格）完全不渲染，做到字节级零差异，不留占位列。
  - 影响文件: frontend/src/views/Project/index.vue
