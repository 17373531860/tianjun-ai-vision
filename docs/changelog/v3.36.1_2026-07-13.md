# v3.36.1 (2026-07-13)

## 功能变更

- [FEAT-001] 区域事件 overlap 规则新增「目标框扩边」(object_margin)
  - 需求: TP 现场 0707 回放 #35 (10:25-10:34) 工人在工件下沿扫条码——扫码枪与
    工件物理接触但两个检测框几何上不相交, 重叠判定永不成立 → 误判缺扫码 NG。
    时间/位移门槛都救不了这种"动作发生在目标框边缘外侧"的几何盲区。
  - 实现: 规则级可选参数 `pipeline_config.region_events.rules[].object_margin`
    (归一化 0~0.2, 默认 0=行为零差异)。重叠判定前把目标框四边虚拟外扩该比例
    再判相交; 扩边只参与"是否相交", 重叠深度门槛 (min_overlap_ratio) 仍按原始
    目标框算, 避免扩边稀释"必须压进去"的语义。纯空间几何量, 与帧率/工人速度
    无关 (用户点名约束: 不允许再引入帧率敏感参数)。
    前端逻辑设置规则卡新增「目标框扩边」输入 (仅 overlap 类型渲染), 保存守门
    与后端解析同款钳位。
  - 验证: 单测 66 通过 (4 个新用例: 桥接小间隙/不误伤远处工具/深度门槛按原框/
    解析钳位); CI E2E 4 通过 (UI→落库断言并入既有用例); 可见浏览器 UAT 6/6;
    TP v5.1 回放矩阵 36 周期全对 (35 合格+1 真复检+0 误判), 扩边 0~0.06 扫描中
    0.02 为最优且 9 组秒基参数组合全部达标; 降帧率仿真 (30→24/20/15fps 抽帧)
    验证秒基门槛口径在 20fps 仍全对而帧数口径 20fps 即漏判。
  - 影响文件: backend/api/source_region_events.py,
    frontend/src/views/Project/LogicConfigTab.vue,
    frontend/src/views/Project/index.vue,
    tests/test_region_events.py, tests/e2e_browser/test_region_events_tab.py,
    tests/uat/uat_20260713_region_object_margin.py

- [FEAT-002] 展会全应用插件 v1.4.1 — 区域规则面板对齐目标框扩边
  - 需求: 插件项目页的区域规则面板是独立重做的一套, 主程序加了新参数后插件侧
    缺同款输入, 展会机上无法配置。
  - 实现: 重叠类规则卡新增「目标框扩边」输入 + 新建规则默认值 + 保存清洗
    (0 不落库 / 0~0.2 钳位 / 非 overlap 类型剔除该键, 与主程序同口径)。
    plugin_version 1.4.0 → 1.4.1, 重新打包签名 (dist/天军_展会_全应用定制界面-
    1.4.1-showcase.tjvplugin), 离线验签通过。
  - 验证: 可见浏览器 UAT 6/6 (清单版本/输入渲染/填 0.02 保存落库回读/切
    region_exit 类型清洗剔除)。
  - 影响文件: plugins-examples/tianjun-showcase/frontend/dist/showcase-app.html,
    plugins-examples/tianjun-showcase/plugin.json,
