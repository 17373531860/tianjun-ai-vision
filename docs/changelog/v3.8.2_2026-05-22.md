# v3.8.2 (2026-05-22)

> 主题：工业级全屏启动体验 — 粒子球 + 手势识别 + 真实日志驱动的赛博 splash，叠加 v3.8.0 手部骨架配置化与二段管线。

## 功能变更

### [FEAT-001] 全新赛博 splash 启动界面（取代旧 400×300 小弹窗）
- **需求**：客户工控机开机时旧 splash 简陋、跟产品定位不符；启动等待的几秒钟用户什么也看不到。
- **实现**：
  - 新增 `electron/splash/` 目录：`index.html` / `main.js` / `audio.js` / `preload.js` + `vendor/` (Three.js + MediaPipe) + `fonts/` (6 个 ttf 字体，全部本地化，离线工厂可跑)。
  - Three.js + WebGL 粒子球 + UnrealBloomPass 后处理 + 5 阶段状态机（IDLE → HOVER → COLLAPSE → EXPLOSION → READY）。
  - 8 道全屏代码瀑布 + SVG 拓扑图 + 四角 cyber HUD（SYS / VER / UID / CHN / GPU / MEM / MODEL / FPS / TIME / SEED）+ 底部 BOOT 序列叙事。
  - 程序化 Web Audio 音效（粒子碰撞持续滴答、stage 切换、握拳磁脉冲、加载完成）；左下角 `♪ AUDIO ON` 一键静音。
- **影响文件**：
  - 新增：`electron/splash/index.html`、`electron/splash/main.js`、`electron/splash/audio.js`、`electron/splash/preload.js`、`electron/splash/vendor/{three,three-addons,mediapipe}/*`、`electron/splash/fonts/*.ttf`
  - 删除：`electron/splash.html`（旧 300×400 弹窗）

### [FEAT-002] Splash 进度条由真实后端 stdout 行数驱动（不再假 6 秒模拟）
- **需求**：之前的 splash 是"装样子"的假进度条；现在要把进度跟后端真实加载状态绑定。
- **实现**：
  - 主进程 `electron/main.js` 监听 `BackendManager` 的 `stdout` / `stderr` / `ready` 事件，通过 IPC `splash:backend-log` / `splash:backend-ready` 转发给 splash renderer。
  - Splash 端 `main.js` 新增 IPC 桥 + 缓冲队列：每收到一行后端日志进度 +0.5%（封顶 95%），后端 ready 强制补到 100%。
  - 进度条左侧 stage 标签按行数粗略映射 (INITIALIZING / BOOTSTRAP / LOADING DB / LOADING UI / WARMUP)，下方 step 文案直接取最近一条日志。
  - 满 100% 后播完成音效 → 600ms 停留 → IPC `splash:finished` 通知主进程关 splash + 显示主窗。
- **沙盒兼容**：浏览器直开 splash（`splashAPI` 不存在）时退回 5 秒 easeOutQuad 假进度，方便开发调试。
- **影响文件**：
  - `electron/main.js`、`electron/splash/main.js`、`electron/splash/preload.js`

### [FEAT-003] Splash 接入工位 1 摄像头做手势触发（MediaPipe Hands）
- **需求**：用户对屏幕握拳 → 中心粒子塌缩；张开五指 → 爆炸辐射，进入 logo 揭示阶段。
- **实现**：
  - Splash 启动时调 `splashAPI.getWorkstationConfig()` 读 `backend/data/workstation_config.json` 拿 `channels."1".usb_device_id`，给 `getUserMedia({deviceId: {ideal}})` 精确锁同一台 USB 摄像头。
  - MediaPipe Hands `locateFile` 改本地 (`./vendor/mediapipe/`)，离线机器零延迟。
  - 摄像头 / MediaPipe 不可用时调 `scheduleAutoplayFallback()`：等后端 ready 后自动 COLLAPSE → EXPLOSION → READY，不卡死。
  - 任何时候按 `ESC` 跳过手势直接进 READY（兜底）。
- **影响文件**：
  - `electron/splash/main.js`

### [FEAT-004] 主窗与 splash 双双全屏 + 杀菜单栏 + 杀标题栏（工业部署形态）
- **需求**：截图上"Windows 标题栏 + File/Edit/View 菜单栏"两条都不该出现，应用从启动开始就全屏。
- **实现**：
  - `electron/main.js` 顶部 `Menu.setApplicationMenu(null)` 全局禁菜单（DevTools 仍可用 Ctrl+Shift+I 打开）。
  - `createWindow()`：`fullscreen: true` + `frame: false` + `backgroundColor: '#02060c'`（跟 splash 同色，过场无闪烁）；主窗创建时 `show: false` 后台预热加载，`splash:finished` 才显示。
  - `createSplashWindow()`：同样 `fullscreen + frame:false + alwaysOnTop`，预加载 `splash/preload.js`。
- **影响文件**：
  - `electron/main.js`

### [FEAT-005] Navbar "退出" 按钮改走 IPC 优雅关机
- **需求**：全屏无边框后没有窗口 × 按钮，"退出"必须能触发 8 步关机流程。
- **实现**：
  - `electron/preload.js` 暴露 `electronAPI.gracefulQuit() → ipcMain.handle('app:graceful-quit')`，handler 调 `mainWindow.close()` 触发已注册的 `startGracefulShutdown`。
  - `frontend/src/layout/Navbar.vue` 的 `case 'logout'` 分支改写：检测到 `window.electronAPI.gracefulQuit` 存在时走 IPC，否则退回老行为（浏览器调试模式 router 跳 `/login`）。
- **影响文件**：
  - `electron/preload.js`、`electron/main.js`、`frontend/src/layout/Navbar.vue`

### [FEAT-006] USB 摄像头 `deviceId` 持久化（思路 B：前端 enumerateDevices）
- **需求**：splash 端要拿到工位 1 上次绑定的那台 USB 摄像头的稳定标识，下次启动直接锁。
- **实现**：
  - 后端 `channel_manager.py` 新增 `PUT /api/v1/workstations/{channel_id}/usb-device` 端点 + `UsbDeviceBindRequest` schema (`device_id` / `device_label`)，用 `save_channel_source(merge=True)` 仅追加这两个字段不动其它配置。
  - 前端 `Source/index.vue` 新增 `tryPersistUsbDeviceId(channelId, deviceIndex, deviceLabel)` helper：USB 摄像头启动成功后调 `navigator.mediaDevices.enumerateDevices()` 拿浏览器侧 `MediaDeviceInfo.deviceId`，按 OpenCV index 顺序匹配 videoinput，PUT 回写后端；任何失败静默不阻塞主流程。
  - 多工位 (`saveAndStartMulti`) + 单工位 (`saveAndStart`) 两条 USB 启动路径都加了调用。
- **影响文件**：
  - `backend/api/channel_manager.py`、`frontend/src/views/Source/index.vue`

### [FEAT-007] MediaPipe 手部骨架"完美渲染"配置化（v3.8.0 起，本次合并发布）
- **需求**：友商手部骨架渲染明显更准，逆向后定罪是 `model_complexity=1` + `min_detection_confidence=0.5` 这两行硬参数；客户工厂黑手套 / 俯视场景仍是死区，需要把这些参数拉出来配置 + 留二段管线接口。
- **实现**：
  - `source.py` 加 `mediapipe_model_complexity` / `mediapipe_track_confidence` 字段，默认 `complexity=0` 保守，不影响老客户。
  - `source_routes.py` `StreamConfigRequest` 加 Optional 字段（`default=None` 防老前端误重置）。
  - `source_mediapipe.py` baseline 初始化时读 host 字段；顺手修了 baseline 分支没把 path/kind 落到 `_hand_detector_path_loaded` 导致 `apply_overlay` 每帧误 reload 的 bug。
  - Settings UI 加一键预设按钮组「省 CPU 模式 / 高精度模式」+ 高级折叠（单选档位 + 跟踪置信度 slider）+ 工业死区提示。
- **300 帧实测**（米色手套平视场景）：命中率 12.3% → 47.7%，提升 3.9 倍；工业黑手套俯视场景双方均 0%（MediaPipe 训练分布外的死区，留给二段管线解决）。
- **影响文件**：
  - `backend/api/source.py`、`backend/api/source_routes.py`、`backend/api/source_mediapipe.py`、`frontend/src/views/Settings/index.vue`
