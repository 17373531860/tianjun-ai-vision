# v3.17.1 (2026-06-02)

> 福建金龙定制收尾：修复项目「步骤设置」表在工控机矮屏下横向滚动条沉到视口外划不动的体验缺陷；配套插件升级到 v1.3.0（警告框/NG 框的提示框由开关升级为可选「内置 / 系统预设 / 自定义提示框」，自绘套用主程序显示设置样式）。主程序侧仅含滚动条修复，插件单独打包发客户。

## Bug 修复

- [BUG-001] 步骤设置表横向滚动条矮屏不可见、无法左右滑动
  - 症状: 工控机矮屏（如 1366×680）下打开项目「步骤设置」，表格列很宽需要横向滚动，但底部横向滚动条沉到视口外/被底部状态栏遮挡，表现为"滑块不见了、固定住了划不动"。
  - 根因: 步骤表滚动容器是 flex 撑满高度，底部 padding 把容器实际底边顶到了视口下方约 12px，横向滚动条正好落在不可见区域。
  - 修复: 滚动容器加 `.step-table-scroll`，`margin-bottom: 52px` 把可视底边推回视口内（避开底部状态栏）；同时把横向滚动条加粗到 14px、改青色高亮（#06b6d4），更易抓取。纯 CSS 改动，不动表格结构与逻辑。
  - 影响文件: frontend/src/views/Project/index.vue

## 功能变更（插件 v1.3.0，单独打包发客户）

- [FEAT-001] 警告框/NG 框的提示框由"开关"升级为"可选提示框"
  - 需求: 客户希望警告档/NG 档触发时，除了插件内置的橙/红框，还能选用主程序「显示设置」里配好的系统预设框（合格/不合格/扫码等）或自定义提示框。
  - 实现: 步骤单元格里的提示框配置从复选框改为下拉，可选「不弹 / 内置警告框(橙) / 内置 NG 框(红) / 系统预设 / 自定义提示框」共多档；前端轮询自绘时按所选提示框标识去当前项目显示设置取颜色/位置/文字/时长渲染；后端配置字段从布尔升级为提示框标识字符串，向后兼容旧布尔值（True→内置框 / False→不弹）。
  - 影响文件: plugins-examples/fujian-jinlong/backend/__init__.py, plugins-examples/fujian-jinlong/frontend/dist/index.esm.js, plugins-examples/fujian-jinlong/plugin.json
  - 验证: 后端三档逻辑 5 场景复现（警告档确认不判 NG）；前端下拉 9 选项 + 选中保存为提示框标识 + 自绘按未压墨蓝色样式弹出，10/10 通过；签名包离线验签 + 真实安装均通过。

## 已知问题 / 排障记录

- 现场报"警告档导致 NG+1"经日志定位为**主程序原生顺序模式的"步骤重复"判废**，与插件三档/警告档无关：某步骤在画面里反复进出（消失延迟内未结束、之后又出现）被记成重复序列触发 NG。属检测稳定性 + 顺序模式防错叠加，按调消失延迟/检测调参处理，不在本版代码改动范围。
- 插件不随安装包内置，客户需在界面单独上传 v1.3.0 签名包（与既往一致）。
