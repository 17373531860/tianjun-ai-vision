# v2.7.1 (2026-04-17)

## Bug 修复

- [BUG-001] 扫码器手动添加设备覆盖已有设备
  - 症状: 手动添加第二个扫码器后，第一个被覆盖消失
  - 根因: "手动添加"按钮只设置 showAdd=true，未重置 editingId 和 form，导致如果之前编辑过设备，再次添加时走了 updateScannerDevice（更新）而非 createScannerDevice（新建）
  - 修复: 新增 handleManualAdd 方法，点击手动添加时先重置 editingId=null 和 form=defaultForm()
  - 影响文件: frontend/src/views/MES/ScannerPanel.vue

- [BUG-002] 顺序检测步骤回退未判定为 NG（A-B-A-B-C 误判为 OK）
  - 症状: A-B-C 顺序检测下，A-B-A-B-C 被判为合格
  - 根因: 步骤入队逻辑使用全局去重 `if label not in current_cycle_steps`，非连续重复步骤被静默丢弃
  - 修复: 引入 _cycle_regression 标志；仅连续相同步骤去重(last_added_step==label)；非连续重复步骤仍入队并标记 _cycle_regression=True；结算时如 _cycle_regression 为 True 立即判 NG（步骤回退）
  - 影响文件: backend/api/source.py

- [BUG-003] 后端日志噪音 (_get_mgr 失败和循环# 调试日志)
  - 症状: 后端终端大量重复日志输出，影响问题定位
  - 根因: _get_mgr 对未配置通道打印错误；_capture_loop 每帧打印调试信息
  - 修复: 移除 _get_mgr 中的 print 和 _capture_loop 中的 debug_log
  - 影响文件: backend/api/source.py

- [BUG-004] 报警灯串口连接失败无详细错误信息
  - 症状: Linux 开发机和 Windows 现场机均连接失败，无法定位原因
  - 根因: connect 方法只返回 bool，未传递具体错误（权限不足/串口不存在/驱动缺失）
  - 修复: connect 返回 {"ok": bool, "msg": str}，包含 PermissionError/SerialException 详细信息；Linux 下自动尝试 chmod 666；API 返回具体错误消息；添加 udev 规则自动设置 CH340 权限
  - 影响文件: backend/api/alarm.py

## 功能变更

- [FEAT-001] 集群副机心跳与主机在线副机显示
  - 需求: 主机无法看到哪些副机已连接，缺少实时感知
  - 实现: 后端 ClusterCollector 新增 _connected_slaves 字典和 register_slave/get_connected_slaves 方法（20秒超时自动清理）；新增 /cluster/heartbeat POST 和 /cluster/slaves GET 接口；副机前端每10秒自动发心跳；主机前端"已连接副机"卡片显示工位标识、IP、检测状态、在线时长
  - 影响文件: backend/services/cluster_collector.py, backend/api/cluster.py, frontend/src/api/cluster.js, frontend/src/views/MES/ClusterPanel.vue

- [FEAT-002] 虚拟扫码器/称重器 tkinter 版 + bat 一键启动
  - 需求: 现场测试需要虚拟设备，但客户电脑无法安装 PyQt5；之前的 PyInstaller 打包方案不可行
  - 实现: 用 tkinter（Python 自带）重写虚拟扫码器和虚拟称重器；创建 bat 脚本自动查找软件自带 Python 运行，无需安装任何额外库
  - 影响文件: tools/virtual_scanner.pyw, tools/virtual_weight.pyw, tools/启动虚拟扫码器.bat, tools/启动虚拟称重器.bat
