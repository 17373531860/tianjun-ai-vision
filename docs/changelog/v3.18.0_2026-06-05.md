# v3.18.0 (2026-06-05)

> 合入 `feat/plugin-dev`：RFC12「全页面整页覆盖」插件框架 + 天军展会全应用定制插件（showcase）。分支已先吸收主线 v3.16~v3.17.3，语义复核（金龙三档 UI 与整页覆盖共存）+ 冒烟（后端 import + 前端 build）全过，`--no-ff` 合入保留分支节点。

## 功能变更

- [FEAT-001] RFC12 全页面整页覆盖框架 — 把「插件整页替换主程序页面主体」能力从**仅 Monitor**（`monitor.layout.body` 且强约束双工位）扩展到**全部 8 个主视图**
  - 需求: 客户级整套 UI 重设计需纯插件落地，主程序保持精简、零差异默认
  - 实现: Monitor/Project/Settings/Source/Model/Data/Alarm/MES 各加 `<TjSlot name="*.layout.body">` 整页挂载点；无插件注册对应 slot 时 TjSlot 回退默认内容（即原生页面），客户不装插件体验零差异；与既有局部 slot（如金龙 `project.step-cell.durations` 三档列）正交共存
  - 影响文件: frontend/src/views/{Monitor,Project,Settings,Source,Model,Data,Alarm,MES}/index.vue, docs/plugin-system/design/12_full_page_override_rfc.md
- [FEAT-002] 天军展会全应用定制插件（showcase, Tier2，主作者签名）
  - 需求: 展会展示用一整套高科技重设计界面
  - 实现: iframe 承载 8 页整应用整页覆盖原型，真数据驱动（设备状态/节拍/雷达评分/良品统计/NG TOP3/实时预警 + 顶栏天气 IP 定位 + `/auth/me` 鉴权身份 + 数字孪生 3D 工位随模式切换）；后端新增 `showcase_stats.py` 只读统计端点（挂 `/data` 前缀）+ `system_display.py` 系统状态采集（CPU/内存/GPU，全 try/except 降级）；RSA-PSS + HMAC 主作者签名产出生产可装 `.tjvplugin`
  - 影响文件: backend/api/showcase_stats.py, backend/api/system_display.py, backend/api/__init__.py, plugins-examples/tianjun-showcase/*, plugins/showcase/*, scripts/plugin/dev-activate-showcase.py
