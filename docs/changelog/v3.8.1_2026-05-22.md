# v3.8.1 (2026-05-22)

## Bug 修复

- [BUG-001] **严格+单次接受 — 翻转等多余出现不再累加 PT**
  - 症状: PT 合并档下「翻转」耗时虚高，或合法步骤 PT=0.0s
  - 根因: 守门每帧拦截导致计时表不更新；后改为仅拦「多余位置的新出现」
  - 修复: `source_settlement_mixin.py` 提前算 is_new_appearance，只拦 spurious 新出现
  - 影响文件: backend/api/source_settlement_mixin.py

- [BUG-002] **TensorRT 引擎版本不兼容时自动回退 PyTorch**
  - 症状: 画面在跑但检测数一直 0，日志 TRT deserialize 失败
  - 根因: 预热失败被吞掉，留下空壳模型；engine 与 runtime TRT patch 不一致
  - 修复: `_warmup_model_cuda` 返回 bool；预热失败自动 load 原始 .pt
  - 影响文件: backend/api/source_model_load_mixin.py

- [BUG-003] **Monitor 中间步骤闪动 + OK/PT 不同步**
  - 症状: 第 2/3 步状态闪；最后一步 OK 了中间步仍 `--` 或只有 PT 无 OK
  - 根因: 画面残留识别回退 active；漏做误判 NG；中间步 OK 等权威 PT 过严
  - 修复: 已走过步骤锁定 completed；真漏做才 NG；结算步 OK 时同步前面步 OK；PT=0 显示 `--`
  - 影响文件: frontend/src/views/Monitor/index.vue
