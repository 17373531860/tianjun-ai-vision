# v2.7.15 (2026-04-25)

## Bug 修复

- [BUG-015-001] 工单管理表头修改了模板没生效, 一直是硬编码中文
  - 症状: 客户在"字段配置"里改了显示名(比如把"工单号"改成"批次号"), 工单管理列表的表头依然是"工单号", 没跟着变
  - 根因: `OrderPanel.vue` 表头 9 个 `<el-table-column>` 的 `label` 写的全是字面量字符串, 跟模板没绑定
  - 修复: 表头改成 v-for 渲染 `visibleColOrder`, 每列 label 用 `colLabel(key)` 从模板动态解析
  - 影响文件: `frontend/src/views/MES/OrderPanel.vue`

- [BUG-015-002] 新建工单弹窗字段标签变成数字 (0/1/2/...)
  - 症状: 用户在"字段配置"里把显示名填成 1/2/3/4/5 测试, 新建工单弹窗里就出现了数字标签 + 表格里 system 列的标签也错乱
  - 根因: 老版本没有 system 列概念, 用户的 localStorage 模板里只有 PRESET 字段, "新建工单"循环 `template.value` 时把 PRESET 字段的"显示名"原样拿来用
  - 修复: 加 `formItems` computed (过滤掉 type='system' 的列), 新建/编辑表单只渲染表单字段; system 列单独走表格表头别名
  - 影响文件: `frontend/src/views/MES/OrderPanel.vue`

- [BUG-015-003] 字段配置弹窗"显示开关"默认 OFF, 关闭后表格变全空白
  - 症状: HMR 热更新后打开字段配置, 所有 system 列的"显示"开关都是关闭状态, 即使没动它, 关闭弹窗→保存后, localStorage 里被写死成 `visible:false`, 工单管理表格变成完全空白
  - 根因:
    - HMR 热更新不会重跑 `onMounted → loadTemplate`, 内存里的 `template.value` 还是旧版状态 (没有 visible 字段)
    - `<el-switch v-model="row.visible">` 遇到 undefined 默认渲染成 OFF
    - 用户即使没动开关, 关闭弹窗保存后 visible=false 被写进 localStorage
  - 修复:
    - `loadTemplate` 加一次性迁移 `TEMPLATE_VISIBLE_MIGRATED_KEY`: 第一次加载 v2.7.15 时把所有列的 visible 强制重置为 true
    - `openTemplate` 拷贝 tplDraft 时强制 normalize visible (`it.visible !== false`)
  - 影响文件: `frontend/src/views/MES/OrderPanel.vue`

## 功能变更

- [FEAT-015-001] 工单管理表头全动态化 (all_dyn 方案)
  - 需求: 客户希望工单管理表格的表头跟字段配置模板走, 改了模板表头立刻变 — 不只表单字段, 系统列(来源/状态/进度/良品-不良/良率/创建时间/操作)也要能改显示名
  - 实现:
    - 新增 `SYSTEM_COL_META` 常量 (label + typeLabel), `SYSTEM_COL_KEYS`, `SYSTEM_COL_ORDER`
    - `buildDefaultTemplate` 同时生成表单字段(PRESET) + 系统列(SYSTEM)
    - `colLabel(key)` 从模板解析表头, 找不到回落到默认中文名
    - `loadTemplate` normalize 时自动补齐缺失的 system 列 (向后兼容老 localStorage)
    - 字段配置表格里, system 列只允许改 label, key/type/required/options 锁定
  - 影响文件: `frontend/src/views/MES/OrderPanel.vue`

- [FEAT-015-002] 字段"显示"开关 - 任意列可隐藏
  - 需求: 用户希望对系统列也能"完全控制" — 至少能隐藏不需要的列(比如不想看"创建时间")
  - 实现:
    - 新增 `COL_META` 整合表格 9 列的 prop / width / fixed
    - 新增 `visibleColOrder` computed, 按模板顺序过滤 `visible !== false`
    - 字段配置弹窗加"显示"列, 所有字段(system / preset / custom)都可显隐
    - 表头 v-for 渲染, 全关 → 表格变空 (符合用户意图, 重新打开走"字段配置")
  - 影响文件: `frontend/src/views/MES/OrderPanel.vue`

- [FEAT-015-003] 自定义字段也能进表格 (从 extra_data 取值)
  - 需求: 用户在字段配置里加的自定义字段(custom_1 等), 之前只在新建工单表单里, 表格看不到值
  - 实现:
    - `visibleColOrder` 不再限制必须在 COL_META 里, 所有 visible 字段都进列
    - `colMetaFor(key)` helper: 自定义字段没 COL_META 定义时用默认 `{ prop: key, width: 120 }`
    - 表头 v-for 兜底分支: `{{ row.extra_data?.[key] ?? row[key] ?? '' }}`
  - 影响文件: `frontend/src/views/MES/OrderPanel.vue`

- [FEAT-015-004] system 列"类型"显示具体类型而不是统称"列表列"
  - 需求: 字段配置弹窗"类型"列对 system 列原本只显示"列表列", 用户搞不清每列实际是什么(标签/进度条/按钮组)
  - 实现: `SYSTEM_COL_META` 每项加 typeLabel (标签 / 状态标签 / 进度条 / 良品-不良数 / 百分比 / 时间 / 按钮组), 类型列直接显示 + 后缀"(不可改)"
  - 影响文件: `frontend/src/views/MES/OrderPanel.vue`

## 已知约束

- 系统列的 key/type/required/options 仍然不可改 (改了等于让代码渲染不出内容, 比如把 status 的 key 改成 xxx 后端没这字段, 整列空白)
- 系统列删除按钮锁定, 用"显示"开关代替删除 (效果一样且可恢复)
- 一次性迁移 `TEMPLATE_VISIBLE_MIGRATED_KEY` 只在第一次加载 v2.7.15 时触发, 之后用户主动关闭的列状态完全保留
