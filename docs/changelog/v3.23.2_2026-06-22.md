## Bug 修复

- [BUG-001] 工单拉取「上银 HIWIN」一键预设 api 字段带空格 → 拉单 404「请求的服务器不存在」
  - 症状: 现场点「工单拉取 → 预设模板 → 上银 HIWIN」一键导入后，扫码拉工单报
    `外部MES返回非成功（statusCode=404）:请求的服务器不存在`。但网络是通的、工单也确实存在。
  - 根因: 上银 MES 是「单网关地址 + 请求体 api 字段选服务」结构，目标服务由请求体里的
    `api` 值决定。前端「上银 HIWIN」一键预设把客户文档里的笔误照抄了——`api` 写成带空格的
    `hiwin/webcn/ai_error prevention_job_info/query`（`ai_error` 与 `prevention` 之间是空格），
    网关按此值找不到服务 → 返回业务码 404「请求的服务器不存在」。全仓仅此一处带空格，
    mock 服务器与所有 UAT 脚本均直填正确的下划线串，因此自动化测试全程绕过该预设、从未暴露
    （测试盲区）。
  - 修复: 预设 `api` 值空格改为下划线 `hiwin/webcn/ai_error_prevention_job_info/query`。
    现场已保存的旧配置不会自动变，需在「工单拉取 → 高级设置 → 请求体模板」手动把空格改成下划线
    后重测（拿不存在的工单号应回成功 0 条 = 服务路由通，真实工单回 1 条带客户名/排产量/规格）。
  - 影响文件: frontend/src/views/MES/OrderPullPanel.vue
