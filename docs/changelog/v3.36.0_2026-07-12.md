# v3.36.0 (2026-07-12)

## 功能变更

- [FEAT-001] 导航栏 Logo 客户自定义上传（显示设置）
  - 需求: 客户想换检测主页左上角 logo，不改包不进代码，一般操作员在设置页就能换
  - 实现: 设置页「基本信息设置」卡新增「导航栏 Logo」块——上传图片前端居中裁方并压缩到
    256×256 PNG data URL，与显示设置其余字段同走 localStorage 持久化；导航栏
    `Navbar.vue` 优先取自定义 logo，空值回退内置 `/app-icon.png`；提供「恢复默认」。
    桌面快捷方式图标是打包期烘进 exe 的资源，运行时不可改（已与需求方确认不做）。
  - 影响文件: frontend/src/views/Settings/index.vue, frontend/src/layout/Navbar.vue,
    frontend/src/store/useSystemStore.js
  - 测试: tests/e2e_browser/test_settings_page.py（上传→导航栏生效→刷新持久→恢复默认
    回环）+ tests/uat/uat_20260712_navbar_logo_upload.py（可见浏览器三件套）

- [FEAT-002] 展会全应用插件 v1.4.0 — 全量对齐主程序 v3.33~v3.35
  - 需求: 展会插件停留在 v3.31/v3.32 功能面，v3.33~v3.35 三个版本的新配置项与新
    覆盖层在插件界面里没有入口，展会演示与真机能力脱节
  - 实现（全部在插件单文件 `showcase-app.html` 内，主程序零改动）:
    - 项目页-区域事件: 规则卡按类型条件渲染补齐全字段（秒基确认 min_seconds /
      位移门槛 min_move / 重叠深度 / 辅助约束 / 区域组合 / 消失确认秒 / 出区
      gone_frames+match_iou / 附加事件 / 锚点跟随），新增每类置信度 class_conf 与
      结算判定 settlement_rules 编辑器；保存清洗对齐主程序 _sanitizeRegionEvents
      （0 值调优字段不落库、半截锚点丢弃、无效判定行剔除）
    - 项目页-同标签区域拆分: 新配置块（固定/锚点、区域外三策略、多轮次含 v3.34
      两防护 trigger_min_seconds/trigger_conf、每轮独立区域），保存时插件版
      syncSplitVirtualSteps 幂等同步虚拟步骤（split_origin 标记 + 孤儿清理）
    - 项目页-逐件: v3.33 重复打防护四参数 + 换板兜底 workpiece_absent_settle_frames
    - 项目页-步骤表: 「等待不被打断」列（消失等待>0 才可编辑）+「外设门控」列
      （去皮/称重判定三态，启用即注入 weighing.drive_mode='step_gate' 融合模式）
    - 项目页-称重: 融合模式提示 + 前置选择有效期 context_expiry（四种过期方式）+
      视觉料源防错 visual_guard（规则表）；融合模式下称重块在顺序模式也可见
    - 项目页-事件: require_ack 展开「确认后保留周期（断点补做）」ack_keep_cycle
    - 监控页: v3.33 重复打黄条（last_warning + 展示秒数倒计时）+ 个体格 dup 琥珀环;
      v3.34 确认响应带 kept_cycle=true 时提示「保留周期，从断点继续补做」
    - MES 页: 网关新建连接支持 database 数据库直写适配器（五种库型，config 键名对齐
      database_adapter，选中隐 HTTP 字段）；包装结算流新增「条码/收尾」编辑面板
      （复合条码取段/工单号识别正则/放工单=收尾动作，PUT 部分更新）
    - plugin.json v1.4.0，main_version_min 提到 3.35.0
