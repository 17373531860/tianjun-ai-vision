# v2.5.0 (2026-04-09)

## 功能变更

- [FEAT-001] 报警灯空闲常亮模式
  - 需求: 检测运行时报警灯保持常亮，OK/NG 闪烁后恢复常亮，颜色可选
  - 实现: AlarmManager 增加 idle_light 配置，start/stop_detection 控制常亮开关，事件闪烁后自动恢复
  - 影响文件: backend/api/alarm.py, frontend/src/views/Alarm/index.vue

- [FEAT-002] 工件条码绑定系统
  - 需求: 扫码器扫到条码后自动绑定当前检测工件，支持中途扫码、去重、误检重绑
  - 实现: MESHookManager 增加 _pending/_inspecting_workpiece 机制，mid_cycle 默认绑定时机，rebind_mode 支持 rescan/auto_rebind/manual
  - 影响文件: backend/services/mes_hooks.py, backend/models/mes_models.py, backend/api/scanner.py, backend/services/scanner.py, backend/api/sessions.py

- [FEAT-003] Data 页工件码列
  - 需求: 数据页周期表显示绑定的工件条码
  - 实现: CycleResponse 增加 serial_no，LEFT JOIN WorkpieceInspection+Workpiece
  - 影响文件: backend/api/sessions.py, frontend/src/views/Data/index.vue

- [FEAT-004] 扫码成功提示框
  - 需求: 扫码成功后弹出可配置的 Toast 提示
  - 实现: useSystemStore 增加 scan toast 预设，Monitor 轮询 scan_event 触发 showToastById
  - 影响文件: frontend/src/store/useSystemStore.js, frontend/src/views/Monitor/index.vue, frontend/src/views/Settings/index.vue

- [FEAT-005] 未绑码告警（Toast + 闪烁横幅）
  - 需求: 周期结算时若未绑定条码，显示醒目告警
  - 实现: warn_no_barcode toast + 黄色闪烁 banner CSS 动画，300ms 延迟跟在 OK/NG toast 之后
  - 影响文件: frontend/src/views/Monitor/index.vue, frontend/src/store/useSystemStore.js, frontend/src/views/Settings/index.vue

- [FEAT-006] 扫码记录管理增强
  - 需求: 清空记录、快速调整去重间隔、日期筛选
  - 实现: 清空 API + 前端红色清空按钮，去重间隔 InputNumber 突出显示，工件追溯面板日期范围筛选
  - 影响文件: backend/api/scanner.py, frontend/src/api/scanner.js, frontend/src/views/MES/ScannerPanel.vue, frontend/src/views/MES/WorkpiecePanel.vue

- [FEAT-007] Modbus RTU/TCP MES 适配器
  - 需求: 通过 RS485 或 TCP 将检测结果写入 Modbus 寄存器给客户 MES 仪表
  - 实现: ModbusRTUAdapter（pymodbus）支持 RTU/TCP 双传输、可配置 OK/NG 值、寄存器映射（result_code/ok_count/ng_count/total_count/const 等）、pymodbus 版本兼容（slave vs device_id）
  - 影响文件: backend/services/mes_adapters/modbus_adapter.py (新), backend/services/mes_adapters/__init__.py, backend/requirements.txt, frontend/src/views/MES/GatewayPanel.vue

- [FEAT-008] 扫码器模拟器
  - 需求: 开发调试用的 TCP 扫码器模拟器
  - 实现: PyQt5 GUI，可配置条码内容、发送次数、频率
  - 影响文件: tools/scanner_simulator.py (新)

## Bug 修复

- [BUG-001] 视频黑屏（改步骤设置后返回 Monitor）
  - 症状: 修改步骤设置后回到 Monitor 页视频黑屏
  - 根因: generate_mjpeg 在 is_running=False 时立即退出，前端 onStreamError 重试阈值太低
  - 修复: 始终使用 vm.generate_mjpeg()，增加重试阈值到 50，加 stream health check
  - 影响文件: backend/main.py, backend/api/source.py, frontend/src/views/Monitor/index.vue

- [BUG-002] Tracking 模式非预期物品导致 NG
  - 症状: 启用了 box 检测框但 box 不在物品清单中，结果被算作 extra 导致 NG
  - 根因: _settle_counting_cycle 将所有检测到的类别都计入 active_count，不在 expected_items 中的也算
  - 修复: 忽略不在 expected_items 中的物品，仅 expected 物品触发新周期
  - 影响文件: backend/api/source.py

- [BUG-003] 未绑码告警不触发
  - 症状: 周期合格结算但未扫码，无 warn_no_barcode 提示
  - 根因: mes_hooks.py 中 `from backend.services.scanner` 应为 `from services.scanner`，import 异常被 try/except 静默吞掉导致 is_warn_no_barcode 恒返回 False
  - 修复: 修正 import 路径，添加异常 print 输出
  - 影响文件: backend/services/mes_hooks.py

- [BUG-004] Monitor 单通道模式 MES 数据不传递
  - 症状: 单通道模式下 mesData computed 始终为空，未绑码 banner 不显示
  - 根因: startPolling 未将 data.mes 赋值到 multiChannelData[0].mes
  - 修复: 显式赋值 multiChannelData.value[0].mes = data.mes
  - 影响文件: frontend/src/views/Monitor/index.vue

- [BUG-005] 设置页 Toast 配置卡消失
  - 症状: 显示设置页面 "系统预设提示框" 卡片不渲染，OK/NG 设置消失
  - 根因: 活跃项目 detection_config 为 null/\"null\"，浅拷贝导致 toasts 对象未初始化
  - 修复: detection 状态初始化改为深拷贝，el-card 加 v-if 防御性渲染，修复 DB 中的 null 配置
  - 影响文件: frontend/src/store/useSystemStore.js, frontend/src/views/Settings/index.vue
