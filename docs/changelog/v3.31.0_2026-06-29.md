# v3.31.0 (2026-06-29)

> 主题：**主程序原生「称重投料模式」(`logic_mode='weighing'`) 落地**——电子秤配料防错全流程（选型号/扫码绑件 → 放件自动去皮 → 投料对比标准量 → 缺料/超量报警 → 逐件逐料记录落库）+ PL2303 USB 转串口驱动内置（Windows 客户机免装）+ mock_weight 无硬件模拟 + bestar 示例插件退役（逻辑上提主线）。
> 萍乡百斯特项目终验收范式。按「主程序原生 + 配置驱动」归位：称重是通用配料产线基础设施，标准量/料别顺序/公差/去皮方式全部进项目 `pipeline_config.weighing` 配置，百斯特只是它的第一个实例。

## 功能变更

- [FEAT-001] 原生称重投料检测引擎（设备驱动状态机）
  - 需求: 配料产线按型号给每道料设标准量，放件去皮→投料→读数稳定→对比标准量→缺料/超量判定→逐件记录，区别于 YOLO 视频帧驱动
  - 实现: 新增 `weighing_engine.py`，与 sequential/detection/custom/tracking 并列的原生模式。由电子秤每帧读数推进 `WeighingStation` 状态机（去皮/稳定判定/料别校验/判定）。状态机**纯逻辑可单测**（喂合成重量序列即可），副作用（报警/去皮指令/上传/落库）由引擎执行层翻译。配置全来自 `pipeline_config.weighing`，不新增 ORM 列
  - 影响文件: backend/services/weighing_engine.py, backend/api/source_project_config_apply.py

- [FEAT-002] 称重模式 REST API + 外设数据管道接入
  - 需求: 监控页选人员/型号/扫码、去皮/置零/复位控制、实时看板、逐件记录查询
  - 实现: 新增 `/api/v1/weighing/*`（context/scan/tare/zero/reset/feed/state/records）。外设管道对 `weight` 角色设备在 weighing 模式通道把读数喂给引擎 `feed_weight`
  - 影响文件: backend/api/weighing.py, backend/main.py, backend/services/external_device_pipeline.py

- [FEAT-003] 逐件逐料记录持久化落库（6.1 台账可追溯，重启不丢）
  - 需求: 终验收要求逐件记录初值/终值/料别/判定/时间并长期可追溯；原内存台账重启即失
  - 实现: 新增 `weighing_records` 表（新表 create_all 自动建），`_do_record` 写库 + 内存双写（落库 try/except 隔离不拖垮主链路），`get_records` 改为优先读库、DB 不可用回退内存。已验证重启后记录仍在
  - 影响文件: backend/models/weighing_models.py, backend/services/weighing_engine.py, backend/main.py

- [FEAT-004] 称重投料前端三件套（配置/监控/数据）
  - 需求: 项目配置称重参数、监控页实时看板、数据页逐件台账
  - 实现: 项目管理新增「称重投料模式」+「称重配置」标签页（料别顺序/型号标准量公差/去皮方式/稳定判定/料别校验/报警事件映射），配置注入严格守门——仅 `logic_mode='weighing'` 时注入，不污染其他模式项目；监控页 `WeighingPanel` 实时看板（人员/型号选择/扫码/实时重量/相位/各料投料进度+判定/去皮置零复位）；数据页「称重记录」标签（统计磁贴/工位筛选/CSV 导出，工位数取系统级 workstations 修正只显工位1的 bug）
  - 影响文件: frontend/src/views/Project/index.vue, frontend/src/api/weighing.js, frontend/src/views/Monitor/WeighingPanel.vue, frontend/src/views/Monitor/index.vue, frontend/src/views/Data/index.vue

- [FEAT-005] 电子秤接入：PL2303 驱动内置 + mock_weight 模拟
  - 需求: 称重器走 RS232→USB（Prolific PL2303 芯片），Windows 客户机免装驱动；无真机时可先验逻辑
  - 实现: 安装包内置 PL2303 驱动（installer.iss 用 pnputil 预装 .inf / 静默运行 .exe，electron-builder extraResources 打包驱动）；外设新增 `mock_weight` 协议（无硬件流式模拟重量，支持去皮/置零控制命令）；外设面板加"模拟称重"选项。Linux 真机经 `serial_continuous` 协议端到端验证通过
  - 影响文件: electron/build/installer.iss, electron/package.json, backend/services/external_device_protocols.py, backend/services/external_device.py, frontend/src/views/MES/ExternalDevicePanel.vue
