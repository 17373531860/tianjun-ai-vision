# v3.55.0 (2026-08-22)

> 主题：**检测主页按工位 logic_mode 切工艺面板 + Monitor 巨石重构收口**。
> 槽位 id 是客户布局落库契约，本版不改名；同槽内按该工位模式换组件。
> 无后端 schema / 配置键变更，升级零配置差异。未切 public、未跑安装包 CI（本地发版材料）。

## 功能变更

- [FEAT-001] 按工位模式显示对应工艺面板
  - 需求: 双/三工位以前对所有 `logic_mode` 都画 SOP 卡；跟踪/逐件/称重工位应显示自己的清点、逐件覆盖、称重投料看板。
  - 实现: `resolveModePanelKind()`（轮询 `project_config.logic_mode` 优先，回退绑定项目）。`WorkstationModePanel` 在槽内切换 `TrackingChecklistPanel` / `PerItemPanel` / `WeighingPanel`；步骤类（sequential / region_events / custom_mix）仍走 SOP。槽位 id 不动：dual=`sop-row`、triple=`sop`、zoom=`sop`、single=`mode-panel`。`custom_mix` 的 mix-panel 与 SOP 并存，不替换 SOP。无步骤概念时隐藏三工位/放大态步骤表（布局编辑态除外）。
  - 影响文件: frontend/src/views/Monitor/monitorModes.js, WorkstationModePanel.vue, TrackingChecklistPanel.vue, WorkstationColumn.vue, index.vue, SingleChannelMonitor.vue

- [FEAT-002] 放大态 / kiosk / 单工位接入同一套 ModePanel
  - 需求: 网格点卡放大、副屏 kiosk、单工位主页也要按模式切面板，且 kiosk 只读不能点称重/逐件写按钮。
  - 实现: 放大/kiosk 共用 `SingleChannelMonitor`，sop 槽优先 ModePanel；`readonly` 下称重输入禁用、逐件「手动开始/结算/判定/确认 NG」不渲染且 `handleControl` 守门。单工位 `mode-panel` 走 `currentProject`（停机无轮询）+ 运行中 `_pollProjectConfig`。
  - 影响文件: SingleChannelMonitor.vue, index.vue, PerItemPanel.vue, WeighingPanel.vue

- [REF-001] SingleChannelMonitor 右侧仪表盘抽出 ChannelDashboard
  - 需求: 放大/kiosk 右侧 stats / summary-row / step-table / controls 去重，避免与单工位主页两套 DOM。
  - 实现: 新组件 `ChannelDashboard.vue` 仅服务 zoom 画布。单工位右侧栏槽位拓扑不同（`charts` vs `summary-row`、controls 嵌在 step-table、插件步骤单元格），**不**无差异共用，以免破坏 v3.54 布局落库。
  - 影响文件: ChannelDashboard.vue, SingleChannelMonitor.vue
