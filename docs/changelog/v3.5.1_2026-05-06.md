# v3.5.1 (2026-05-06)

## 功能变更

- [FEAT-301] Monitor 页 PT/CT 三档显示口径 + 后端字段暴露
  - 需求: Monitor 页 PT (步骤耗时) / CT (周期时间) 历来只显示历史平均，
    用户希望能切到"最近一轮"或"当前周期内"实时跳动，且 PT 和 CT 各能独立切。
  - 实现:
    - 后端 `/api/v1/source/detection/results` 新增 4 个字段：
      - `last_cycle_time` — 最近合格 cycle 时长 (= `cycle_times[-1]`)
      - `last_cycle_time_with_ng` — 最近 cycle 时长含 NG (取 `cycle_times[-1]` / `ng_cycle_times[-1]` 的最大)
      - `current_cycle_time` — 当前 cycle 已耗时 (`time.time() - cycle_start_time`，is_detecting=False 时为 0)
      - `last_step_durations` — 每个 step label 历史最后一次 duration (`step_durations_history[label][-1]`)
    - 前端 systemStore.display.monitor 增加 `ptMode` / `ctMode` (默认 'avg')，三档：
      - **avg** — 历史最近 100 轮均值 (默认，旧行为)
      - **last** — 最近一个已结束 cycle 的值
      - **current** — 当前正在跑的 cycle 已耗时 (实时跳)
    - Settings 页 → 显示设置 → 检测中心显示 增加两个独立下拉选择器
      (PT 显示口径 / CT 显示口径)，支持 9 种组合 (avg/last/current × 2)。
    - Monitor `formatStepPT` / `getDisplayCT` / `displayCT` 全面改造，跟随 mode + ctIncludeNg 二维组合。
    - `multiChannelData` 缓存 `lastCycleTime` / `currentCycleTime` / `lastStepDurations`
      支持多工位场景下每通道独立显示。
  - 影响文件:
    - 修改: `backend/api/source_routes.py`, `frontend/src/store/useSystemStore.js`,
      `frontend/src/views/Settings/index.vue`, `frontend/src/views/Monitor/index.vue`
    - 新增: `tests/test_pt_ct_modes_exposure.py`

- [FEAT-302] 数据中心快捷 CSV 导出与 PT/CT 显示口径联动
  - 需求: 用户在显示设置切到"平均"后，希望数据中心"导出当日/某周/某月/日期范围"
    4 个快捷 CSV 按钮的输出也跟着变成平均口径，而不只是 Monitor UI 变化。
  - 实现 (方案 B: 加列, 兼容老脚本):
    - 后端 `/data/export/csv` 端点接受 `pt_mode` / `ct_mode` query 参数。
    - 新增 `_calc_aggregates(cycles, steps)` 工具函数：cycle 求总平均，
      step 按 `step_label` 分组求各 step 平均。
    - `_write_session_export` / `_write_cycle_export` / `_write_range_export`
      三个 builder 全部接受 mode：
      - `ct_mode=avg` → 周期详情区在"耗时(秒)"列旁额外多一列 **"耗时(平均/秒)"**，
        每行填范围内 cycle 时长全局平均
      - `pt_mode=avg` → 步骤详情区额外多一列 **"耗时(平均/秒)"**，
        每行填该 step label 在范围内的全局平均
      - `last/current/None` → 不加列，保持原列结构 (老脚本兼容)
    - `build_csv_response` 透传新参数。
    - 前端 `exportDateRangeCsv` / `exportWeekCsv` / `exportMonthCsv`
      三个函数增加 `ptMode` / `ctMode` 参数。
    - `Data/index.vue` 的 `resolveExportScopeParams` 从 systemStore
      读取并透传到 4 个快捷按钮 + 弹出对话框路径。
  - 影响文件:
    - 修改: `backend/api/sessions.py`, `backend/api/sessions_export.py`,
      `frontend/src/api/data.js`, `frontend/src/views/Data/index.vue`
    - 新增: `tests/test_csv_export_pt_ct_modes.py`

## 兼容性

- v3.5.0 的所有 API/数据结构完全兼容，无需 migration。
- CSV 导出新增的"耗时(平均/秒)"列**仅在 `pt_mode=avg` / `ct_mode=avg` 时输出**，
  老的 CSV 处理脚本（依赖"耗时(秒)"列名）完全不受影响。
- systemStore 的 `ptMode` / `ctMode` 默认 'avg'，等同于 v3.5.0 显示行为。
