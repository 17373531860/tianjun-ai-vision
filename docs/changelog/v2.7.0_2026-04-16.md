# v2.7.0 (2026-04-16)

## 功能变更

- [FEAT-001] 扫码器 LON/LOFF 模式（TCP 55256）
  - 需求: 供应商确认 TCP 55256 + LON/LOFF 是正确连接方式，替代 WMax 逆向二进制协议
  - 实现: 新增 `text_lon` 设备类型作为默认模式；连接后保持 TCP，检测开始发 LON，停止发 LOFF；测试按钮闪灯 3 秒自动 LOFF；搜索设备改为 TCP 端口扫描不触发闪光
  - 影响文件: backend/services/scanner.py, backend/api/scanner.py, backend/models/mes_models.py, frontend/src/api/scanner.js, frontend/src/views/MES/ScannerPanel.vue

- [FEAT-002] 防重复结算开关
  - 需求: 跟踪模式下同一结算批次同时产生 OK + NG 两个结果，数据库只记录一个
  - 实现: 项目配置新增「防重复结算」开关（settle_dedup），开启后同一结算批次已结束周期的后续事件被抑制；默认关闭，不影响原有逻辑
  - 影响文件: backend/api/source.py, frontend/src/views/Project/index.vue

- [FEAT-003] TensorRT 转换超时保护与环境诊断
  - 需求: TensorRT FP16 转换在桌面 3070 上挂起超过 20 分钟
  - 实现: 线程化 export 加 600 秒超时；新增 GPU/CUDA/TensorRT 环境诊断 API；前端显示详细错误信息和"环境诊断"按钮；workspace 限制 4GB
  - 影响文件: backend/api/models.py, frontend/src/api/model.js, frontend/src/views/Project/index.vue

- [FEAT-004] 集群超时推送选项
  - 需求: 等齐模式下工位超时不推送 MES 会导致客户不知道
  - 实现: ClusterConfig 新增 timeout_push 布尔字段；超时时推送 overall_result="TIMEOUT" 含 missing_stations 列表到 MES
  - 影响文件: backend/services/cluster_collector.py, backend/api/cluster.py, backend/models/mes_models.py, backend/main.py, frontend/src/api/cluster.js, frontend/src/views/MES/ClusterPanel.vue

- [FEAT-005] 前端数值限制全面放开
  - 需求: 某些场景下 360/3600 秒上限不够用
  - 实现: 所有 el-input-number 移除 :max 限制，:min 设为 0，浮点值 precision=2，整数值 precision=0
  - 影响文件: frontend/src/views/Project/index.vue, frontend/src/views/Settings/index.vue, frontend/src/views/MES/GatewayPanel.vue, frontend/src/views/MES/ExternalDevicePanel.vue, frontend/src/views/MES/ClusterPanel.vue, frontend/src/views/MES/OrderPanel.vue, frontend/src/views/MES/DefectPanel.vue, frontend/src/views/Alarm/index.vue, frontend/src/views/Source/index.vue

- [FEAT-006] 前端术语通用化
  - 需求: 包装场景特有词汇（箱子/箱码）替换为通用词（目标/目标编号）
  - 实现: 替换所有前端 UI 文本，后端 API 路径和变量名不变
  - 影响文件: frontend/src/views/MES/ClusterPanel.vue, frontend/src/views/MES/GatewayPanel.vue, frontend/src/views/MES/WorkpiecePanel.vue, frontend/src/views/Monitor/index.vue, frontend/src/views/Data/index.vue

- [FEAT-007] 称重器 Modbus ASCII + 连续发送双模式
  - 需求: 自动称重机支持两种串口协议
  - 实现: ExternalDevice 框架新增 modbus_ascii 和 continuous_serial 协议支持
  - 影响文件: backend/services/external_device.py, frontend/src/views/MES/ExternalDevicePanel.vue

- [FEAT-008] 扫码器条码自动注入外部设备
  - 需求: 工位 3 的扫码器 B 扫到码后需要自动关联到同工位的称重器
  - 实现: ScannerService._inject_barcode_to_external_devices 自动注入同 channel_id 的外部设备
  - 影响文件: backend/services/scanner.py

## Bug 修复

- [BUG-001] 修复: 未扫码 Toast 在扫码后仍然显示
  - 症状: 双工位检测下扫码成功后仍显示"未扫码"
  - 根因: had_workpiece 标志在 end_cycle 之后才检查，此时 _inspecting_workpiece 已被清除
  - 修复: 将 had_workpiece 检查移到 end_cycle 之前
  - 影响文件: backend/api/source.py

- [BUG-002] 修复: MES 前端操作无反馈
  - 症状: MES 系统配置中超过 80% 的按钮点击后无任何成功/失败提示
  - 根因: 各面板缺少 ElMessage 反馈和 loading 状态
  - 修复: 全面添加 ElMessage 反馈（成功/失败/取消区分）和 loading 状态
  - 影响文件: frontend/src/views/MES/*.vue

- [BUG-003] 修复: cluster_config.timeout_push 列缺失导致启动报错
  - 症状: 后端启动报 no such column: cluster_config.timeout_push
  - 根因: 数据库迁移逻辑未包含新字段
  - 修复: 在 backend/main.py migrations 列表中添加 timeout_push 列迁移
  - 影响文件: backend/main.py
