# v3.32.0 (2026-07-07)

> 主题：**同标签区域拆分 + 区域事件模式（TP 工位流程监测）** 两个检测能力落地，配套 MediaPipe 骨架样式可配、频闪逐帧诊断、推理线程单例守护三项现场稳健性增强；同期完成巨型视图拆分（Monitor/Project 九批）、DB 迁移版本化、路由挂载统一登记、开发者文档体系 + 文档 CI 门禁等一批工程治理。

## 功能变更

- [FEAT-001] 同标签区域拆分（虚拟步骤 / 多轮次 / 违序即时事件）
  - 需求: 电机装配对角打螺丝类场景——同一个模型标签（如"打螺丝"）在画面不同区域代表不同工序步骤，需要按落点拆成独立虚拟步骤参与顺序判定，支持多轮次（8 颗螺丝分 2 轮对角）与"工件就位提示"。
  - 实现: steps_config 每步可配拆分区域（命名子区域 + 轮次），检测框按中心点落区映射为虚拟步骤名进入状态机；"违反严格顺序时立即触发"可绑定事件当场报警（对所有顺序类项目通用）；SOP 面板/步骤统计按虚拟步骤展示。
  - 影响文件: backend/api/source.py, backend/api/source_step_stats_mixin.py, frontend/src/views/Project（LogicConfigTab/StepsConfigTab）, frontend/src/views/Monitor/index.vue
- [FEAT-002] 区域事件模式（logic_mode='region_events'，TP 工位流程监测）
  - 需求: TP 现场"测硬度→扫码→下工件"类人工工位，步骤不是"模型类别在场"而是"主体与目标区域发生一段持续交互的动作"——需要一种以动作规则（主体标签 × 目标区域 × 持续帧数 × 位移门槛）为步骤的第 6 种逻辑模式。
  - 实现: 独立动作引擎——每条规则维护命中累计（episode），min_frames 确认、消失确认秒数闭合、按确认序列与期望序列比对结算 OK/NG；步骤面板"进行中"由引擎 in-flight 快照驱动（动作确认前即点亮，与顺序模式对齐）；结算判定文案输出"(缺事件 X)/(事件 X 重复≥N 次)"。
  - 现场打磨（2026-07 TP 实测三处）: ① 位移门槛的轨迹包络改为中心点 5 帧中位数平滑后进包络——手划过遮挡把检测框"切"小导致的单帧中心跳变不再算位移；② 动作互斥打断（常开）——一个动作确认瞬间其他进行中 episode 立即收尾，防止消失确认秒数把复检场景两段命中桥接成一次导致序列少步误 NG；③ 前端结果列不做"重复/乱序=NG"推断（复检序列合法性由后端结算判定说了算）。
  - 影响文件: backend/api/source_region_events.py, backend/api/source_region_events_mixin.py, backend/api/source_routes.py, backend/api/source_event_trigger_mixin.py, backend/api/source_state_init.py, frontend/src/views/Monitor/index.vue
- [FEAT-003] MediaPipe 自定义纯色骨架样式（连线/关键点颜色分离可配）
  - 需求: 现场投屏与定制界面需要骨架叠加融入整体配色，默认绿线红点观感差。
  - 实现: 系统设置性能页新增"自定义骨架样式"开关 + 姿态/手部各自的连线颜色、关键点颜色（空 = 跟随连线色）、线宽共 7 个字段，走视频流配置端点持久化；二段 pipeline（工业 hand-detector ROI 路径）渲染复用同一套样式。
  - 影响文件: backend/api/source_mediapipe.py, backend/api/source_routes.py, frontend/src/views/Settings/index.vue, frontend/src/store/useSystemStore.js
- [FEAT-004] 频闪逐帧自动诊断转储（diag_flicker）
  - 需求: "检测框一闪一闪"类现场反馈只靠口述无法定位，需要自动抓现场证据。
  - 实现: 每帧采样监视标签到环形缓冲，2 秒内在场翻转次数超阈值自动落 JSON（近 50 帧逐帧在场/原始框/推理与采集 fps）到 backend/diag_flicker/（运行时产物已 gitignore）；采样体抽公共方法供 custom_mix 与 region_events 两模式共用。
  - 影响文件: backend/api/source_inference_loop_mixin.py, backend/api/source.py, .gitignore
- [FEAT-005] DB 迁移版本化治理（RFC 方案 B）
  - 需求: 旧 migrate_database() 一把 ALTER 手工堆叠，无版本无幂等，老客户升级路径不可审计。
  - 实现: backend/db/migrations/ 目录化 mXXXX_*.py 迁移 + 注册表，旧函数改断言桩；改 schema 必须新建迁移（AGENTS 第八节不变量 8）。
  - 影响文件: backend/db/migrations/*, backend/database.py

## Bug 修复

- [BUG-001] 推理线程单例守护（加锁 + 代数）
  - 症状: 快速停止/启动检测或项目切换竞态下可能残留两条推理线程同时跑，帧结果交错、CPU 翻倍。
  - 根因: 启动推理线程无互斥，旧线程退出判定靠布尔标志，交叠窗口内新旧线程并存。
  - 修复: 启动加锁 + 线程代数（generation）标记，循环内代数不匹配立即自退，保证任意时刻至多一条存活；新增单测 tests/test_inference_thread_singleton.py。
  - 影响文件: backend/api/source.py, backend/api/source_inference_loop_mixin.py
- [BUG-002] ROI 画区与实际检测区偏差
  - 症状: 前端画的 ROI 与后端实际裁剪检测的区域有肉眼可见偏移。
  - 根因: 缺陷 A——快照通道与推理帧尺寸不一致；缺陷 B——归一化坐标系在旋转/翻转链路上错位。
  - 修复: 快照走推理同源帧 + 坐标系统一换算（commit 8289b45）。
  - 影响文件: backend/api/source_routes.py, frontend/src/views/Project
- [BUG-003] e2e 门卫端口写死 8001/6001
  - 症状: 隔离环境（8002/6002）跑 e2e_browser 全量误跳过。
  - 修复: 门卫探活端口跟随 E2E_API_URL / E2E_BASE_URL 环境变量解析。
  - 影响文件: tests/e2e_browser/conftest.py
