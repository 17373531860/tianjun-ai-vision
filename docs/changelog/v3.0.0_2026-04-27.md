# v3.0.0 (2026-04-27)

## Bug 修复

- [BUG-300-001] 修复检测启动卡住、开始按钮不可用、TensorRT 引擎不兼容
  - 症状: 选择 `oppo_sop1` 后开始检测超时，Monitor 按钮不可用或检测状态不同步。
  - 根因: 开发机 Python 3.13 与 TensorRT 运行链路不匹配，旧 `.engine` 也和当前 TensorRT 版本不兼容。
  - 修复: 新建并切换到 Python 3.10 的 `tianjun-runtime` 环境，按 CI 依赖安装 CUDA 12.8 / TensorRT / PyTorch 运行栈，并重建 `oppo_sop1` TensorRT engine。
  - 影响文件: `start_backend.sh`, `backend/uploads/models/converted/19_tensorrt_fp32_sm_89.engine`

- [BUG-300-002] 修复检测停止/待机接口被离线扫码器拖慢约 20 秒
  - 症状: 点击"待机"或"停止"后界面长时间无响应，接口最终超时。
  - 根因: `stop_scanning()` 停止 WMax/auto 扫码器时，为了发送关闭命令同步重连离线设备。
  - 修复: `trigger_on` 保留自动重连，`trigger_off` 遇到离线设备直接跳过，不再为了停止动作阻塞重连。
  - 影响文件: `backend/services/scanner.py`

- [BUG-300-003] 修复会话启动时导出设置加载失败
  - 症状: 后端日志出现 `加载导出设置失败: name 'DataExportSetting' is not defined`。
  - 根因: `source_session_lifecycle_mixin.py` 使用 `DataExportSetting` 但没有导入模型。
  - 修复: 补充模型导入，检测会话启动时可正常读取导出/录像设置。
  - 影响文件: `backend/api/source_session_lifecycle_mixin.py`

- [BUG-300-004] 修复离线扫码器/外设反复打印大段 traceback
  - 症状: 未连接扫码器、称重器或 TCP 设备时，日志被 `ConnectionRefusedError` 等堆栈刷屏。
  - 根因: 预期的离线/拒绝连接错误和真正异常共用完整异常日志。
  - 修复: 增加预期连接错误分类，离线场景只输出一行 warning 并继续重试，未知异常才保留 traceback。
  - 影响文件: `backend/services/scanner.py`, `backend/services/external_device_protocols.py`

- [BUG-300-005] 修复数据中心 MES 工单筛选缺少刷新函数
  - 症状: 数据中心切换 MES 工单筛选时控制台提示 `loadSessions` 未定义。
  - 根因: 前端模板绑定了筛选刷新函数，但脚本里缺少实现。
  - 修复: 增加 `loadSessions()`，按当前日期重新加载会话或清空概览。
  - 影响文件: `frontend/src/views/Data/index.vue`

- [BUG-300-006] 修复 MES 工件状态标签类型警告
  - 症状: 工件追溯页面出现 ElementPlus `ElTag type` 无效警告。
  - 根因: `rework`、`queued` 等状态映射为空字符串。
  - 修复: 所有已知状态都映射到合法类型，并给未知状态默认 `info`。
  - 影响文件: `frontend/src/views/MES/WorkpiecePanel.vue`

- [BUG-300-007] 修复报表跨天班次统计边界和平均耗时单位误读
  - 症状: 夜班/跨天时间段统计边界不稳定，平均耗时单位容易被误读。
  - 根因: 日期与小时过滤逻辑分散，导出字段未明确单位。
  - 修复: 统一日期/小时过滤函数，CSV 和页面明确显示毫秒单位。
  - 影响文件: `backend/api/reports.py`, `frontend/src/views/Report/index.vue`

- [BUG-300-008] 修复录像写入失败对用户不可见
  - 症状: FFmpeg 写帧失败时可能只在后台异常，前端看不到是哪条录像通道失效。
  - 根因: 录像线程没有集中记录失败事件，也没有在检测结果里暴露给 Monitor。
  - 修复: 增加录像失败事件缓存、查询展示和清空接口，保留详细原因用于排查。
  - 影响文件: `backend/api/source_recorder.py`, `backend/api/source_recording_api_mixin.py`, `backend/api/source_recording_thread_mixin.py`, `backend/api/source_routes.py`, `backend/api/source_state_init.py`, `frontend/src/views/Monitor/index.vue`

- [BUG-300-009] 修复 Electron 开发模式前端端口与计时器清理问题
  - 症状: 开发模式偶发加载错误前端地址，退出/重启后仍有延迟任务残留。
  - 根因: 前端 URL 优先级和多处 `setTimeout` 管理分散。
  - 修复: 开发 URL 优先读环境变量，Electron 主进程统一管理并清理 timeout。
  - 影响文件: `electron/main.js`

- [BUG-300-010] 修复多通道 Monitor 局部状态串扰
  - 症状: 多工位切换、停止、恢复后局部状态可能残留到其它通道。
  - 根因: 前端多通道运行态没有在关键生命周期统一重置，部分更新不是不可变更新。
  - 修复: 增加多通道运行态重置逻辑，并规范 `multiChannelData` 更新方式。
  - 影响文件: `frontend/src/views/Monitor/index.vue`
