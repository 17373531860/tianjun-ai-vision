# v3.48.1 (2026-08-11)

> 主题：**体验修复补丁版**——多工位监控视频加载/卡顿治本（MJPEG 连接饿死 + WebKit 兼容）+ 数据中心录像播放失败治本（坏缓存/超时）+ NG 录像回看三件套（结果筛选/倍速/下载）+ Electron 退出僵尸后端兜底 + PG 基线迁移 CI 修复。

## Bug 修复

- [BUG-001] 多工位监控（>4 工位）视频加载不出来 / 黑屏 / 看起来只有几帧
  - 症状: 九工位总览页视频全部转圈加载不出；Safari/WebKit 下即使单工位放大也黑屏；画面肉眼只有 3 帧/秒但底部显示 20+ FPS
  - 根因: ① 浏览器对同一 host 的 HTTP/1.1 并发连接上限是 6，九路 MJPEG 长连接 + 150ms 数据轮询全挤同一个后端 host，互相踢流永远加载不出；② WebKit 的 fetch() 不支持 `multipart/x-mixed-replace` 流式读取，MJPEG 一律零帧断流；③ 回退用的快照轮询固定 300ms 节拍，放大单路也只有 3.3fps，被感知为"超级卡"（底部 FPS 是后端推理帧率，不是显示帧率）
  - 修复: 可见工位 > 4 时放弃 MJPEG 长连接改走 `/snapshot` 单帧轮询（短请求复用 socket）；MJPEG 连续 2 次零帧断流自动降级快照轮询（治 WebKit）；快照取帧节奏按并发工位数自适应（≤2 路 80ms≈12fps / ≤4 路 120ms / ≤9 路 200ms / 更多 300ms）
  - 影响文件: frontend/src/views/Monitor/index.vue

- [BUG-002] 数据中心录像点开报「视频加载失败」，且一旦失败永远失败
  - 症状: Data 页周期录像弹窗黑屏报错；同一条录像每次点开都失败
  - 根因: `convert_video_for_browser` 直接往缓存路径写转码产物，转码超时/被杀会留残缺文件，下次请求 `os.path.exists` 命中坏缓存直接回传；且超时仅 60s，会话级长录像根本转不完，超时回退的 mp4v 原始文件 Chromium 解不了
  - 修复: 先写 `.tmp` 临时文件、成功后 `os.replace` 原子落位（缓存要么完整要么没有）；缓存名 `_h264` → `_h264v2` 让历史坏缓存自然失效重转；超时 60s → 300s；失败半成品 finally 必清
  - 影响文件: backend/api/sessions.py

- [BUG-003] 客户机每次启动都在"清理残留进程"（Electron 退出留下僵尸 python）
  - 症状: 关闭应用后 python 后端进程残留占着 GPU 显存，下次启动依赖启动期清残留逻辑兜底
  - 根因: `finishShutdown` 用 3s race 抢跑 `stopBackend()`，而 stop() 内部最坏路径是"优雅等 3s → 软杀等 5s → 强杀"，后端退出慢（模型/CUDA 释放）时 Electron 先 `app.exit` 自尽，强杀永远轮不到
  - 修复: race 窗口 3s → 8s；新增 `forceKillSync()` 同步强杀兜底（win32 走 `taskkill /f /t`，POSIX 杀进程组），`app.exit(0)` 前必执行完
  - 影响文件: electron/main.js, electron/backend-manager.js

- [BUG-004] DB Matrix CI（PostgreSQL）基线迁移红灯
  - 症状: `alembic upgrade` 基线报 `NoReferencedTableError: detection_sessions.operator_id could not find table 'users'`
  - 根因: `alembic/env.py` 只 import 了 4 组模型模块，v3.10+ 的 auth_models（users 表）及 notify/weighing/plc/trigger 模型不在 metadata 里，外键解析失败
  - 修复: env.py 补齐 5 组模型 import
  - 影响文件: alembic/env.py

## 功能变更

- [FEAT-001] 数据中心 NG 录像回看三件套：结果筛选 + 播放倍速 + 下载录像
  - 需求: 客户回看录像基本只关心 NG 周期，逐条翻太慢；长录像原速看太久；浏览器放不了的老编码录像需要能拿到文件
  - 实现: 周期列表新增「全部 / 仅 OK / 仅 NG」筛选（后端 `GET /data/sessions/{id}/cycles` 新增 `result=ok|ng` 参数）；播放弹窗新增 0.5x~4x 倍速（记住选择，换视频不重置）；新增「下载录像」按钮（同 `/data/videos/{id}` 端点 FileResponse）；视频报错文案引导用下载兜底
  - 影响文件: backend/api/sessions.py, frontend/src/api/data.js, frontend/src/views/Data/index.vue
