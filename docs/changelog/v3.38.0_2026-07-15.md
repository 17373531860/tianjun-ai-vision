# v3.38.0 (2026-07-15)

> 主题：**川南"框冻结"治本 + 萍乡班次/皮重 + 扫码器旁路 SN 监控**——收尾持久化整体搬出推理线程（PersistWorker 异步落库）+ MES 网关推送熔断器与锁窗口收敛 + 清理事务卫生，根治检测画面周期收尾卡顿；检测运行中收到外部开工时新工单回填运行工位；萍乡百斯特自定义班次列表 + 皮重记录看板 + 监控页称重数值条；dev-qing 合入扫码器旁路 SN 实时监控与 NG top3 保持。

## 功能变更

- [FEAT-001] 收尾持久化出推理线程（PersistWorker 异步落库，川南"框冻结"治本第一刀）
  - 需求: 川南现场反馈检测画面周期收尾时"框卡死"约 0.5~1s；根因是 cycle 收尾的 DB 写（cycle/step 落库、录像关联）在推理线程内同步执行，SQLite 写锁竞争时阻塞出帧。
  - 实现: 新增 `source_persist_worker.py`——每通道一条 FIFO 落库工作线程，推理线程只入队不落库；cycle 开始/结束/废弃、step 记录全部改走队列；`TIANJUN_SYNC_PERSIST=1` 可退回同步模式（测试/排查用）；错误隔离（单条任务失败不倒线程）；配套热路径索引迁移 m0001（step_records.cycle_id + video_clips.related_id）。
  - 影响文件: backend/api/source_persist_worker.py, backend/api/source_session_lifecycle_mixin.py, backend/api/source_recording_api_mixin.py, backend/models/models.py, backend/db/migrations/m0001_hot_path_indexes.py, tests/test_persist_worker.py, tests/test_recording_db_leak.py, docs/rfc/收尾持久化出推理线程_设计方案_RFC.md

- [FEAT-002] MES 网关推送熔断器 + 分发锁窗口收敛（治本第二刀）
  - 需求: MES 端点失联时推送反复超时重试，长时间占用 DB 会话与锁，间接拖累检测热路径。
  - 实现: 推送熔断器（同一连接连续失败跳闸→冷却期内跳过→半开试探恢复；更新连接/测试连接自动复位熔断）；dispatch 改为每条连接推完即 commit，缩短单事务锁持有窗口；新增熔断状态查询与复位入口。
  - 影响文件: backend/services/mes_gateway.py, backend/api/mes_gateway.py, tests/test_mes_gateway_circuit_breaker.py, tests/test_mes_gateway_dispatch_isolation.py, tests/test_mes_gateway_lock_release.py

- [FEAT-003] 数据清理事务卫生（治本第三刀）
  - 需求: 数据页批量清理旧 session 时单个大事务长时间持写锁，正在检测的工位落库被顶住。
  - 实现: 清理按 cycle 分批小事务提交；录像等文件删除移到 DB 事务提交之后执行，文件 IO 不再夹在锁窗口内。
  - 影响文件: backend/api/sessions_maintenance.py, tests/test_cleanup_txn_hygiene.py

- [FEAT-004] 检测运行中外部开工工单回填运行工位（川南反馈）
  - 需求: 川南范式下工位已在检测时收到外部系统新开工，此前新工单不接管运行中工位，四要素不上屏。
  - 实现: 入站开工成功后触发工单变更钩子，把最新激活工单回绑到正在检测的工位（工件在途不打断），监控页四要素随即刷新；BDD 场景 17-19 覆盖。
  - 影响文件: backend/services/mes_hooks.py, backend/services/mes_inbound.py, tests/features/chuannan_mes_integration.feature, tests/step_defs/test_chuannan_mes_integration.py, tests/uat/uat_20260715_task_info_rebind.py

- [FEAT-005] 自定义班次列表（萍乡百斯特）
  - 需求: 客户排班不止白/夜两班，需要自定义班次名称与时段，数据页按班次筛选、导航栏显示当前班次。
  - 实现: 项目配置支持自定义班次列表（名称+起止时间，跨零点支持）；后端按配置解析当前班次标签（替代硬编码 day/night）；数据页班次筛选动态渲染配置班次；导航栏可选显示当前班次（显示设置开关）。
  - 影响文件: backend/api/source_session_lifecycle_mixin.py, backend/api/sessions.py, backend/services/weighing_engine.py, frontend/src/views/Project/index.vue, frontend/src/views/Data/index.vue, frontend/src/layout/Navbar.vue, frontend/src/views/Settings/index.vue, tests/test_shift_resolution.py

- [FEAT-006] 皮重记录与监控页称重数值条（萍乡百斯特）
  - 需求: 称重投料模式需要留痕去皮值，且操作员希望在监控页直接看到实时秤值。
  - 实现: 自动/手动去皮时记录皮重并随逐件记录落库，称重面板显示皮重；新增监控页称重数值条组件（实时重量/皮重/净重/步骤门控状态，融合模式下显示），项目称重配置页加"检测中心显示实时称重数值"开关。
  - 影响文件: backend/services/weighing_engine.py, frontend/src/views/Monitor/WeighingLiveBar.vue, frontend/src/views/Monitor/WeighingPanel.vue, frontend/src/views/Monitor/index.vue, frontend/src/views/Project/WeighingConfigTab.vue, tests/test_weighing_engine.py, tests/test_weighing_fusion.py

- [FEAT-007] MES 数据库直写驱动内置（达梦/MySQL/SQLServer）
  - 需求: v3.35 数据库直写适配器上线后，客户机需手工装驱动，现场部署繁琐。
  - 实现: dmPython / pymysql / pymssql 进 requirements 随包出厂。
  - 影响文件: backend/requirements.txt

- [FEAT-008] 扫码器旁路 SN 实时监控（dev-qing 合入）
  - 需求: 客户扫码器不接软件、只往固定目录写 SN txt，需要监控页能看到当前 SN 且周期开始时锁定快照。
  - 实现: 后台守护线程定期扫描实时导出规则的输入目录并缓存当前 SN；新增旁路状态只读端点（本版补齐 summary/response_model 文档四件套）；cycle_start 快照优先读内存缓存、无缓存再 glob 兜底，不阻塞热路径；监控页 MES 条可选显示旁路 SN（显示设置 showBypassSn，默认关）。
  - 影响文件: backend/services/scanner_bypass_monitor.py, backend/api/export_realtime.py, backend/main.py, backend/services/export_snapshot.py, frontend/src/views/Monitor/index.vue, frontend/src/views/Settings/index.vue, frontend/src/api/export.js, tests/test_scanner_bypass_monitor.py

- [FEAT-009] 传感器清洁插件 v1.4.3（dev-qing 合入）
  - 需求: 现场真值重标定 + 换棉签动作段重复计数问题。
  - 实现: 真值重标定 + 换棉签动作段去重。
  - 影响文件: plugins/sensor-clean（插件包）
