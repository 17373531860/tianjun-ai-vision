# v3.60.0 (2026-09-19)

> 主题：**六和二工位锁付整改批次**——逐件覆盖三连能力：整板拖动重配准（工装板周期中被挪动后槽位跟着走）、动作框扩边救援（标注偏心的"已完成"框就近记账）、混合逐件虚拟步骤（「开头扫码 → 逐件锁付 → 结尾扫码」编排，与 v3.49 容器虚拟步骤全对称的基建扩充）。全部默认关零配置差异。随版收编 v3.59.0a 东莞群光现场补丁。

## 功能变更

- [FEAT-001] 整板拖动重配准（逐件覆盖，默认关）
  - 需求: 六和二工位工装板在周期中被工人整体拖动后，锁定槽位留在旧位置，覆盖脱靶 31/32 永不合格；部分现场工装真固定，故做成开关
  - 实现: `pipeline_config.per_item.board_rereg_enabled`（默认 false）。触发条件=可靠关联 <50% 槽位且检出 ≥50% 槽位连续 4 帧；质心平移做初值 + 两轮最近邻中位数精配 + ≥60% 一一对应验证通过才提交整板迁移，同步刷新 `last_aligned_frame`。独立逐件与混合逐件同源生效（混合侧 `_PerItemMixEngine.feed` 汇总跨步骤可靠位移估计整板平移）
  - 影响文件: backend/api/source_per_item_mixin.py, backend/api/source_custom_mix.py, frontend/src/views/Project/LogicConfigTab.vue, frontend/src/views/Project/index.vue

- [FEAT-002] 动作框扩边救援 coverage_margin（步骤级，默认 0=关）
  - 需求: 模型"已完成"框标注偏离螺丝中心，个别槽位永远盖不到（真实视频 31/32 NG）
  - 实现: 步骤级 `per_item.coverage_margin`（0~2 倍）。动作框按倍数扩边后，仅当恰有一个"最近的未覆盖合格槽位"时就近记账，防止扩边误伤多槽
  - 影响文件: backend/api/source_per_item_mixin.py, frontend/src/views/Project/LogicConfigTab.vue, frontend/src/views/Project/StepsConfigTab.vue, frontend/src/views/Project/mixItemDefaults.js

- [FEAT-003] 混合逐件虚拟步骤 custom_mix_per_item_virtual_step（默认关）
  - 需求: 六和工艺新增「开头扫码几次 → 锁 32 颗 → 结尾扫码几次」，扫码不计次数但首尾必须各确认到；顺序 [扫码,扫码] 连续重复步骤会被 disappear_delay 强制清零守门拦住无法合并连扫
  - 实现: 与 v3.49 容器虚拟步骤全对称——`custom_mix_per_item_virtual_step`+`_label` 两键；全部逐件行完成瞬间（粘性 completed 口径）把虚拟标签注入稳定标签流走常规序列状态机，序列变 [扫码, 锁付完成(虚拟), 扫码] 后两个扫码不再相邻、消失等待自然合并连扫。统一 `virtual_step_complete()/virtual_step_activity()` 分发口径（tracking=整箱达标 / per_item=全行完成），注入/缺步提前发现/严格顺序共用容器虚拟步骤同一条通路零新分支。前端步骤设置卡开关+名称，自动生成/移除 `per_item_virtual` 步骤行
  - 影响文件: backend/api/source_custom_mix.py, backend/api/source_step_stats_mixin.py, backend/api/source_settlement_mixin.py, frontend/src/views/Project/StepsConfigTab.vue, frontend/src/views/Project/index.vue

- [FEAT-004] 物品侧活动脉冲豁免空闲超时（混合逐件，自动生效零配置）
  - 需求: 逐件作业动辄几分钟，期间步骤序列零推进，步骤侧空闲超时会把干活中的周期强杀
  - 实现: `_PerItemMixEngine` 记录覆盖总数每次向前推进的时刻（`last_progress_time`，回落只降基线），步骤侧空闲判定前用它顺推 `_last_step_added_time` 锚点；跟踪混合无脉冲返回 0 零差异
  - 影响文件: backend/api/source_custom_mix.py, backend/api/source_step_stats_mixin.py

## Bug 修复

- [BUG-001] 期望序列含重复步骤时 NG 原因空列表
  - 症状: 序列 [扫码, 虚拟, 扫码] 缺第二次扫码结算 NG，原因打出"缺少: []"现场无法解读
  - 根因: 缺步计算用 set 口径，重复步骤只入 set 一次算不出"第二次没做"
  - 修复: `_check_events` 缺步为空时按多重集补齐（挂起匹配用素标签，展示带"扫码(第2次)"注记）；`_container_virtual_label` 更名 `_mix_virtual_label` 泛化两种混合
  - 影响文件: backend/api/source_settlement_mixin.py

- [BUG-002] v3.59.0a 东莞群光现场补丁收编（随版）
  - 症状: ①勾选列表残留已停用步骤/容器标签 → 每周期必"缺步 NG"；②容器定界周期中标签闪断重现被前端按"重复出现"刷红；③旧版换主模型步骤 id 与保留拆分虚拟步骤撞车
  - 修复: 结算必做清单剔除停用步骤与容器标签；前端 SOP 统一剔除停用步骤 + `container_gate` 豁免重复/乱序推断；加载时 id 冲突自愈重编并提示
  - 影响文件: backend/api/source_settlement_mixin.py, frontend/src/views/Monitor/monitorModes.js, frontend/src/views/Monitor/index.vue, frontend/src/views/Project/labelSplit.js, frontend/src/views/Project/index.vue
