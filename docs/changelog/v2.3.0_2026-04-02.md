# v2.3.0 (2026-04-02)

## 功能变更

- [FEAT-001] 内置 MES 系统 — 工单管理
  - 需求: 客户需要在检测系统内管理生产工单，追踪生产进度和良率
  - 实现: 10 张数据表（工单/批次/工件/检测关联/缺陷/缺陷代码/扫码器/扫码记录/MES连接/通讯日志），完整的工单状态机（draft→pending→in_progress→paused→completed/cancelled），原子计数递增，良率自动刷新，自动完工检查
  - 影响文件: backend/models/mes_models.py, backend/services/work_order.py, backend/api/mes.py, backend/main.py

- [FEAT-002] 内置 MES 系统 — 单件追溯
  - 需求: 每个工件从扫码登记到检测完成的全链路追溯，含返工重检支持
  - 实现: Workpiece 表 + WorkpieceInspection 中间表架构，支持一个工件多次检测（返工场景），UniqueConstraint(serial_no, project_id) 确保不重复
  - 影响文件: backend/models/mes_models.py, backend/services/workpiece.py, backend/api/mes.py

- [FEAT-003] 内置 MES 系统 — 缺陷自动分类
  - 需求: NG 工件自动记录缺陷，支持检测标签→缺陷代码映射
  - 实现: DefectCode 字典表定义映射规则，Cycle NG 时自动从 result_reason 提取标签匹配缺陷代码，支持 Pareto 统计
  - 影响文件: backend/models/mes_models.py, backend/services/defect.py, backend/api/mes.py

- [FEAT-004] MES Hook 异步集成引擎
  - 需求: MES 系统不能影响检测帧率，异常不能中断检测
  - 实现: MESHookManager 使用独立线程 + 队列 + 独立 DB session，5 个 Hook 锚点注入 source.py（scan_received/cycle_start/cycle_end/session_start/session_end），所有 Hook 在 try/except 中执行
  - 影响文件: backend/services/mes_hooks.py, backend/api/source.py

- [FEAT-005] VS600 扫码器 TCP 通讯服务
  - 需求: 威码视 VS600 固定式读码器通过网口对接，每个工位前扫码登记工件
  - 实现: 每台设备独立监听线程，LON 指令触发，自动重连（指数退避），扫码去重，三种条码解析模式（direct/separator/regex）
  - 影响文件: backend/services/scanner.py, backend/services/barcode_parser.py, backend/api/scanner.py

- [FEAT-006] MES REST API（30 条端点）
  - 需求: 前端页面和外部 MES 系统需要标准化接口访问数据
  - 实现: 22 条 MES 端点（工单/工件/缺陷/缺陷代码 CRUD + 追溯 + Pareto）+ 8 条扫码器端点（设备管理/测试/状态/记录）
  - 影响文件: backend/api/mes.py, backend/api/scanner.py, backend/main.py

- [FEAT-007] MES 前端管理页面
  - 需求: 工单管理、工件追溯、缺陷分析、扫码器管理的完整操作界面
  - 实现: 4 个标签页（OrderPanel/WorkpiecePanel/DefectPanel/ScannerPanel），工单状态流转按钮，追溯详情侧边栏，Pareto 柱状图，扫码器设备卡片
  - 影响文件: frontend/src/views/MES/*.vue, frontend/src/api/mes.js, frontend/src/api/scanner.js, frontend/src/router/index.js, frontend/src/layout/index.vue

- [FEAT-008] Monitor MES 信息条
  - 需求: 检测监控页面实时显示当前工件序列号和工单进度
  - 实现: 在 get_detection_results 中注入 MES 实时数据，Monitor 右侧面板统计区下方添加 MES 信息条（工件序列号/状态 + 工单号/进度/良率）
  - 影响文件: backend/api/source.py, frontend/src/views/Monitor/index.vue

- [FEAT-009] Data 页 MES 工单筛选
  - 需求: 数据中心按工单维度筛选检测记录
  - 实现: 查询面板添加 MES 工单下拉选择器，加载进行中和已完成的工单列表
  - 影响文件: frontend/src/views/Data/index.vue

- [FEAT-010] 开发者模式（密码保护）
  - 需求: 多工位功能仅开发/调试时可用，避免客户误操作
  - 实现: 导航栏设置菜单新增"开发者模式"选项，点击需输入密码（tianjunKEJI），默认关闭，关闭时输入源页面仅显示单工位选项，开启后才显示双工位/四工位
  - 影响文件: frontend/src/store/useSystemStore.js, frontend/src/layout/Navbar.vue, frontend/src/views/Source/index.vue
