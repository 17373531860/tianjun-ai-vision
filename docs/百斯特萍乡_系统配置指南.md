# 萍乡百斯特项目 · 系统配置指南 v1.0

> 适用版本：v3.35+（视觉 SOP × 称重门控融合架构）。
> 阅读对象：实施工程师。按本文从零配到可验收。
> 更新时间：2026-07-10
>
> **零差异声明**：本文所有新能力默认关闭。不按本文开启任何开关的存量客户（含 v3.31 秤驱动称重客户）行为与旧版完全一致。

---

## 〇、架构一图流

```
相机 → YOLO 推理 ─┬─ 步骤标签 → 顺序 SOP 状态机（违序/缺步/超时报警）
                  └─ 检测框  → 视觉料源防错（动作×料盆区域 → 料别/违规）
电子秤 RS232 → 外设数据管线 → 称重引擎（步骤门控：去皮 / 标准量判定）
                                  ↓ 门控放行 → 步骤才计入周期
报警（缺料/超量/投错/违规）→ 事件链 → 三色灯 + 定格 → USB 确认按钮解除
逐件记录 → 数据中心 + MES 推送网关 →（HTTP 接口 或 达梦数据库直写，二选一/都推）
```

配置顺序建议：**秤 → 项目 → 门控 → 称重参数 → 防错 → 事件报警 → 确认按钮 → 数据上传**。

## 一、电子秤接入（外部设备）

1. 秤设置为**指令应答模式**（连续输出与应答二选一，秤面板可调），RS232 参数：**9600 / 8 / N / 1**。
2. 界面：`MES 管理 → 外部设备 → 新建`，类型选**串口称重器**，填串口号（如 COM3），**绑定工位 = 检测项目所在工位**。绑定对了读数才会喂给称重引擎，秤设备无需在项目里再选一遍。
3. 验证：外部设备列表看实时读数；空秤放砝码读数应跟着变。

## 二、检测项目（视觉 SOP 主线）

1. `项目管理 → 新建项目`，**逻辑模式 = 顺序模式**（不是"称重投料"——那是纯秤驱动的老模式，本项目用融合模式）。
2. 上传训练好的模型，`步骤设置` 里按工序顺序添加四步：`钢帽放秤 → 舀料 → 装杯 → 倒料入工件`（标签名与模型一致）。
3. `逻辑设置` 里按需开启**严格顺序**（违序立即报警）与周期/步骤超时。违序、缺步、超时报警都是顺序模式自带能力，无需额外配置。

## 三、步骤外设门控（融合核心）

位置：`项目 → 步骤设置 → 「外设门控」列`（顺序类模式才显示）。

| 步骤 | 门控类型 | 说明 |
|---|---|---|
| 钢帽放秤 | **去皮门控** | 视觉看到放件后，等秤上毛重超阈值且稳定 → 系统自动发去皮指令 → 步骤放行 |
| 倒料入工件（或称重步骤） | **称重判定** | 净重稳定后按「当前型号 × 料别」对比标准量：合格放行；缺料/超量报警，可配"拦截等纠正"（工人补/舀出料后自动重判）或"记 NG 放行" |

- 称重判定门控里的**判定料别**：留空 = 按料别顺序自动取；双料工序（钢帽水泥→钢脚水泥两轮）建议分别建两个步骤各指定料别。
- 任一步骤启用门控后，项目页自动出现**「称重配置」页签**（见下节）。
- 门控放行前该步骤不计入周期（监控页表现为该步骤一直"未完成"），秤条件一满足立即放行。**引擎异常时门控自动放行，绝不卡产线**。

## 四、称重配置页签

位置：`项目 → 称重配置`（融合模式顶部有蓝色提示条说明当前驱动方式）。

1. **料别顺序**：`钢帽水泥、钢脚水泥`（每件按此顺序投料）。
2. **型号标准量表**：每个产品型号 × 每种料别填 `标准量 / 下容差 / 上容差`（kg）。**未配型号的判定结果是 no_spec，不算合格也不报缺料**——上线前务必把在产型号配全。
3. **去皮/稳定参数**：去皮触发毛重、稳定容差、稳定采样帧数，默认值可先用，现场按秤的跳动情况微调。
4. **前置要求**：开工必须先选人员/型号（对应验收 6.5）。
5. **前置选择有效期**（新）：治"昨天选的型号今天忘了换"。
   - 策略：`永不失效`（默认）/ `每天定时`（如每天 08:00 后昨天的选择作废）/ `按班次`（跨班次即失效，班次表可配、支持跨午夜夜班）/ `N 小时`。
   - 失效时清什么可选（型号 / 人员），过期后开工会被前置校验拦截并报警提示重选。
6. **视觉料源防错**（新，对应"装错盆"错误示范）：
   - 开启后加规则，每条规则 = `动作标签 × 判定区域（在视频画面上画多边形） × 类型`：
     - **料别映射**：`舀料` 命中「钢帽料盆」区域 → 系统认定当前投的是钢帽水泥，与应投料别不符 → 投错报警（可配拦截等纠正）。两个盆各建一条。
     - **动作限区**：`装杯` 只允许出现在小盆区域，区域外出现立即报警（抓帮工异步装错，独立于步骤相位）。
   - `连续帧` 默认 3（防单帧误检），`报警冷却` 默认 5 秒（防刷屏）。
   - 机位挪动后**必须重画区域**。

## 五、事件与报警确认

1. `项目 → 事件设置`：给缺料/超量/投错/限区违规映射的事件勾选**「需人工确认（重做本周期）」**——报警后整个工位定格，直到有人确认。称重配置页「校验与报警」区可为每类报警（缺料/超量/投错/前置未过/限区违规）分别指定触发哪个事件。
2. 确认入口（三选一，可并存）：
   - 监控页界面确认按钮（默认，无需配置）
   - **USB 物理确认按钮**：`MES 管理 → 扫码器 → 添加 USB 扫码枪 → 用途选「报警确认按钮」`，选好对应工位。按钮本质是发固定码的 HID 键盘，按一下 = 解除本工位定格。选型见《百斯特萍乡_按钮及配件选型》。
   - 操作员权限不够时走"借管理员密码提权确认"（v3.23 既有能力）。

## 六、数据上传（达梦数据库直写）

位置：`MES 管理 → 推送网关 → 新建连接 → 适配器类型选「数据库直写」`。

1. **连接参数**：数据库类型选**达梦 DM**（也支持 MySQL/PostgreSQL/SQL Server/SQLite），填主机/端口（达梦默认 5236）/账号/密码/库名/**目标表名**（可带 schema 前缀，如 `PROD.T_WEIGH_RECORD`）。
2. **字段映射模板**：顶层键名 = 目标表**列名**，值用 `{字段路径}` 引用检测数据。单行示例：

```json
{
  "SN": "{sn}",
  "MODEL_NAME": "{model}",
  "OPERATOR": "{operator}",
  "MATERIAL": "{material}",
  "NET_WEIGHT": "{net}",
  "VERDICT": "{verdict}",
  "CREATE_TIME": "{timestamp}"
}
```

   每料一行（数组展开，同一事务）示例：

```json
{
  "_array_source": "results",
  "_item_template": {
    "SN": "{sn}",
    "MATERIAL": "{item.material}",
    "NET_WEIGHT": "{item.net}",
    "VERDICT": "{item.verdict}",
    "CREATE_TIME": "{timestamp}"
  }
}
```

3. **推送时机**：订阅 `weighing_product_done`（每件完成）或 `cycle_end`（每周期）。
4. **重试/日志**：复用网关既有能力（重试次数/间隔、通讯日志页可查每次 INSERT 结果）。
5. **驱动**：达梦驱动 `dmPython` 需装进客户机 Python 环境（随达梦客户端提供或 pip 安装）；未装时测试推送会直接提示要装哪个包。表名/列名有白名单校验（仅字母数字下划线），天然防注入。
6. 客户 IT 若最终给的是 HTTP 接口，同一面板建 REST 连接即可，两种可并存。

## 七、上线前检查单

- [ ] 秤应答模式 + 外设面板能看到实时读数，去皮/置零指令有响应
- [ ] 四步模型现场实测 20 件无漏步
- [ ] 每个在产型号的标准量表配全（无 no_spec）
- [ ] 故意错误各演一遍：违序 / 跳步 / 缺料 / 超量 / 装错盆 / 帮工错区 → 全部报警且定格
- [ ] USB 确认按钮按一下能解除定格
- [ ] 前置有效期按客户班次配好，跨班开工不重选会被拦
- [ ] 达梦库里能查到测试记录（含每料净重与判定）
- [ ] 断电重启后配置全在、检测自动恢复（若开了开机自动恢复）
