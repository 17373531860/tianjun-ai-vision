## 三、后端环境配置（Python）

### 1. 安装 Anaconda/Miniconda

- **Anaconda**（推荐，包含常用库）：https://www.anaconda.com/download
- **Miniconda**（轻量）：https://docs.conda.io/en/latest/miniconda.html

安装完成后重启终端。

### 2. 创建 conda 环境

```bash
# 创建名为 tianjun 的环境，Python 3.10
conda create -n tianjun python=3.10 -y

# 激活环境（每次开发都要先激活）
conda activate tianjun
```

### 3. 安装 PyTorch（带 CUDA 12.1，约 2.5GB）

**这一步很重要，必须单独安装！**

```bash
# 确保已激活 tianjun 环境
conda activate tianjun

# 安装 PyTorch + CUDA 12.1
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

验证 PyTorch：
```bash
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA 可用: {torch.cuda.is_available()}')"
```

如果显示 `CUDA 可用: True`，说明安装成功。

### 4. 安装后端所有依赖

```bash
# 确保在项目根目录
cd tianjun-ai-vision

# 安装 requirements.txt 中的所有依赖
pip install -r backend/requirements.txt
```

### 5. 安装 FFmpeg（视频录制必需）

**Windows:**
1. 下载：https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-win64-gpl.zip
2. 解压后将 `bin` 文件夹中的 `ffmpeg.exe` 和 `ffprobe.exe` 复制到项目根目录的 `ffmpeg/` 文件夹
3. 或者将 `bin` 目录添加到系统环境变量 PATH

**Linux (Ubuntu):**
```bash

sudo apt install ffmpeg -y
```

**Mac:**
```bash
brew install ffmpeg
```

验证 FFmpeg：
```bash

```

## 九、常见问题

### Q1: PyTorch 安装后 CUDA 不可用

检查：
```bash
python -c "import torch; print(torch.cuda.is_available())"
```

如果返回 `False`：
1. 确认已安装 NVIDIA 驱动（版本 >= 525）
2. 确认安装的是 CUDA 版本的 PyTorch
3. 重新安装：`pip uninstall torch && pip install torch --index-url https://download.pytorch.org/whl/cu121`

### Q2: 后端启动报错 "Module not found"

确保在项目根目录下设置 PYTHONPATH：
```bash
export PYTHONPATH="${PYTHONPATH}:$(pwd)"
```

### Q3: 前端 npm install 失败

```bash
# 清除缓存重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q4: 端口被占用

```bash
# Linux/Mac：查找并杀死占用端口的进程
lsof -ti:8001 | xargs kill -9  # 后端端口
lsof -ti:6001 | xargs kill -9  # 前端端口

# Windows
netstat -ano | findstr :8001
taskkill /PID <进程ID> /F
```

### Q5: 摄像头打不开

- 确认摄像头未被其他程序占用
- 检查摄像头索引是否正确（一般是 0）
- Linux 需要权限：`sudo chmod 666 /dev/video0`

## 十三、重要注意事项

### 1. conda 环境不在 Git 仓库中
- Git 仓库**不包含** Python 环境
- 每个开发者必须**自己安装**所有 Python 依赖
- 安装大小约 **5-8GB**（主要是 PyTorch）

### 2. node_modules 不在 Git 仓库中
- Git 仓库**不包含** node_modules
- 必须运行 `npm install` 下载前端依赖
- 安装大小约 **200-500MB**

### 3. 模型文件
- `best.pt` 是 YOLO 模型文件，**已包含**在仓库中
- 如需更换模型，替换此文件即可

### 4. FFmpeg
- 视频录制功能需要 FFmpeg
- Windows 用户需手动下载并配置
- Linux 用户可直接 `apt install ffmpeg`

### 5. NVIDIA 显卡
- AI 推理需要 NVIDIA 显卡
- 需安装 525 或更高版本的驱动
- 无显卡可运行但会很慢（使用 CPU）

## 十四、常见安装错误

### 错误 1: torch 安装失败
```
ERROR: Could not find a version that satisfies the requirement torch
```
**解决**：使用正确的 pip 源
```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 错误 2: CUDA 不可用
```python
torch.cuda.is_available() 返回 False
```
**解决**：
1. 确认安装了 NVIDIA 驱动
2. 确认安装的是 CUDA 版本的 PyTorch（不是 CPU 版本）

### 错误 3: npm install 失败
```
npm ERR! code ERESOLVE
```
**解决**：
```bash
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
```

### 错误 4: 模块找不到
```
ModuleNotFoundError: No module named 'xxx'
```
**解决**：确保激活了正确的 conda 环境
```bash
conda activate tianjun
```
