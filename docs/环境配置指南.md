## 三、后端环境配置

### 1. 安装 Anaconda/Miniconda

下载地址：https://www.anaconda.com/download 或 https://docs.conda.io/en/latest/miniconda.html

### 2. 创建 conda 环境

```bash
# 创建名为 tianjun 的环境，Python 3.10
conda create -n tianjun python=3.10 -y

# 激活环境
conda activate tianjun
```

### 3. 安装 PyTorch（带 CUDA 12.1）

```bash
# Windows / Linux
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 4. 安装后端依赖

```bash
# 进入项目根目录
cd tianjun-ai-vision

# 安装依赖
pip install -r backend/requirements.txt
```

### 5. 安装 FFmpeg（视频录制需要）

**Windows:**
1. 下载：https://github.com/BtbN/FFmpeg-Builds/releases
2. 解压，将 `bin` 目录添加到系统 PATH
3. 或者将 `ffmpeg.exe` 和 `ffprobe.exe` 复制到项目根目录的 `ffmpeg/` 文件夹

**Linux (Ubuntu):**
```bash
sudo apt update
sudo apt install ffmpeg -y
```

### 6. 验证后端环境

```bash
conda activate tianjun

# 验证 PyTorch 和 CUDA
python -c "import torch; print(f'PyTorch: {torch.__version__}, CUDA: {torch.cuda.is_available()}')"

# 验证 ultralytics
python -c "from ultralytics import YOLO; print('ultralytics OK')"
```


### 方式二：手动启动

**终端 1：启动后端**
```bash
# 激活环境
conda activate tianjun

# 设置 Python 路径
export PYTHONPATH="${PYTHONPATH}:$(pwd)"  # Linux/Mac
# 或
set PYTHONPATH=%PYTHONPATH%;%cd%          # Windows CMD

# 启动后端
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8001 --reload
```

**终端 2：启动前端**
```bash
cd frontend
npm run dev
```

## 九、常见问题

### Q1: PyTorch 安装后 CUDA 不可用

检查：
```bash
python -c "import torch; print(torch.cuda.is_available())"
```

如果返回 `False`：
1. 确认已安装 NVIDIA 驱动（版本 >= 525）
2. 确认安装的是 CUDA 版本的 PyTorch
3. 重新安装：`pip uninstall torch && pip install torch --index-url https://download.pytorch.org/whl/cu121`

### Q2: 后端启动报错 "Module not found"

确保在项目根目录下设置 PYTHONPATH：
```bash
export PYTHONPATH="${PYTHONPATH}:$(pwd)"
```

### Q3: 前端 npm install 失败

```bash
# 清除缓存重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q4: 端口被占用

```bash
# Linux/Mac：查找并杀死占用端口的进程
lsof -ti:8001 | xargs kill -9  # 后端端口
lsof -ti:6001 | xargs kill -9  # 前端端口

# Windows
netstat -ano | findstr :8001
taskkill /PID <进程ID> /F
```

### Q5: 摄像头打不开

- 确认摄像头未被其他程序占用
- 检查摄像头索引是否正确（一般是 0）
- Linux 需要权限：`sudo chmod 666 /dev/video0`
