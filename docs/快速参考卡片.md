```
1. 上传模型 → 2. 新建项目 → 3. 选模型 → 4. 配输入源 → 5. 开始检测
```

## 📍 页面导航速查

| 页面 | 路径 | 功能 |
|------|------|------|
| 检测中心 | `/monitor` | 实时检测、查看结果、统计数据 |
| 项目管理 | `/project` | 创建项目、配置逻辑、设置事件 |
| 模型仓库 | `/model` | 上传/删除 AI 模型 |
| 输入源 | `/source` | 设置摄像头/视频/图片 |
| 数据管理 | `/data` | 历史记录、数据导出 |
| 报警设置 | `/alarm` | 连接报警灯、配置触发 |
| 系统设置 | `/settings` | 显示设置、性能设置 |

---

## 🔧 检测中心控制按钮

| 按钮 | 作用 | 快捷说明 |
|------|------|---------|
| ✅ **开始** | 启动检测 | 需先选择项目 |
| ⏹️ **停止** | 暂停检测+画面 | 可恢复 |
| ⏸️ **待机** | 停止检测，画面继续 | 只停推理 |
| 🔄 **清零** | 重置所有计数器 | 归零统计 |

---

## 📊 三种检测模式对比

| 模式 | 适用场景 | 判定逻辑 |
|------|---------|---------|
| **顺序模式** | 装配线、工序流程 | 按顺序完成→OK，乱序→NG |
| **检测模式** | 质检、计数 | 检测到所有目标→OK |
| **自定义模式** | 复杂业务 | 自定义条件触发事件 |

---

## ⚙️ 步骤参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 置信度阈值 | AI识别可信度下限 | 50%-80% |
| 最短持续 | 检测时间下限 | 0.1-0.5s |
| 最大持续 | 检测时间上限 | 根据实际 |
| 去重间隔 | 防重复计数 | 1s |
| 最少帧数 | 连续帧数确认 | 1-5帧 |

---

## 📹 输入源设置

### 摄像头
```
分辨率推荐: 1280x720
帧率推荐: 10 FPS (匹配检测速度)
```

### 视频
```
格式支持: MP4, AVI, MOV, MKV
倍速: 0.5x ~ 8x
逐帧模式: 确保每帧都检测
```

## 🔔 报警灯常用协议

- 大部分四色灯: Modbus 4色灯协议
- 简单控制器: ASCII 文本
- 不确定: 逐个尝试

## 💡 性能优化技巧

| 问题 | 解决方案 |
|------|---------|
| 检测慢 | 使用GPU / 降低分辨率 / 提高阈值 |
| 画面卡 | 降低帧率 / 关闭视频录制 |
| 框抖动 | 开启卡尔曼滤波 / 调大R值 |
| 漏检 | 降低置信度阈值 / 减少最少帧数 |
| 误检 | 提高置信度 / 增加最少帧数 |

## 🆘 常见问题速查

| 问题 | 解决 |
|------|------|
| 摄像头不显示 | 刷新设备列表 / 检查USB连接 |
| 检测不开始 | 先选择项目 / 检查模型配置 |
| 报警灯不响应 | 检查串口 / 尝试不同协议 |
| 数据不记录 | 检查数据管理中的记录设置 |
