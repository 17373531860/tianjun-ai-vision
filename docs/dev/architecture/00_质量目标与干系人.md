## 系统是什么

天军 AI 视觉检测系统：部署在工厂工控机上的**桌面应用**，用摄像头 + 深度学习模型做装配/包装线视觉防错，把检测结果推送给客户 MES/中控，并持久化周期/步骤/工件记录供追溯与导出。

商业属性：**客户已在用**（非 demo）；单机工控机为主，部分场景多机集群；Electron 壳 + FastAPI 后端 + Vue3 前端 + SQLite（计划迁 PostgreSQL）。

## 前三大质量目标（按优先级）

| 序 | 质量目标 | 含义 | 架构落点 |
|---|---|---|---|
| 1 | **错误隔离** | 插件挂了、MES 慢了、外设断了——主程序检测节拍不能被拖垮 | 插件 hook 异常 swallow；MES Hook 队列满不阻塞（critical 落盘）；报警走共享灯柱合成器 |
| 2 | **升级无损** | 老客户已装版本升级，DB/配置/行为兼容 | 版本化迁移 `backend/db/migrations/`；Project 7 JSON 字段扩展不删键；废弃 API 410 而非静默删 |
| 3 | **现场可诊断** | 工控机无 F12，出问题能取证 | Electron 三层崩溃恢复 + 日志落盘；调试日志中心；集群/ MES 健康检查 |

## 已知约束（写架构时的硬边界）

- API 前缀统一 `/api/v1/`（不是 `/api/`）
- 主程序路由唯一登记处：`backend/api/router_manifest.py`
- 插件路由命名空间：`/api/v1/plugins/{customer_code}/...`
- 多 worktree 并行开发时，前端 baseURL 必须钉对本树后端（防 DB 污染）
- 出厂版 `ENABLE_DEV_MOCKS=0`；虚拟剧本端点仅 `RUNTIME_MODE=test` 挂载
