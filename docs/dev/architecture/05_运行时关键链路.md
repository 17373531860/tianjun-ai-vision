# 运行时关键链路

> **类型**：explanation（架构 · arc42 §6 运行时视图裁剪）
> **本文不讲**：每个函数的实现细节（→ [internals/](../internals/)）
> **与代码冲突时**：以代码为准。

只画客户现场真实会跑的三条链路。箭头 = 时间顺序。

## 链路 A：一个检测周期的一生（单机顺序模式）

```
操作员激活项目
  → POST /projects/{id}/activate → source.apply_project_config
  → 启动视频源 POST /source/start → 采集线程 _capture_loop
  → 每帧推理 → 步骤统计 mixin → 结算 mixin 判定周期结束
  → _handle_cycle_end (source) → commit DetectionCycle/StepRecord
  → mes_hooks.on_cycle_end (入队) → worker: 绑工件/缺陷/外推
  → 前端轮询 detection/results → Monitor 步骤卡/计数器更新
```

| 步骤 | 代码位置 |
|---|---|
| 激活项目 | `backend/api/projects.py` → `source_project_config_apply.py` |
| 帧循环 | `source_inference_loop_mixin.py` |
| 结算分发 | `source_settlement_mixin.py` `_settle_for_cross_cycle` / `_settle_*_cycle` |
| 周期落库 | `source_session_lifecycle_mixin.py` |
| MES 异步桥 | `backend/services/mes_hooks.py` `_handle_cycle_end` |
| 前端展示 | `frontend/src/views/Monitor/index.vue` |

## 链路 B：扫码 → 绑定 → MES 推送

```
扫码枪输入 → scanner service → mes_hooks.on_scan_received (critical 入队)
  → _handle_scan: 注册 Workpiece / scan_pair 窗口 / pending 队列
  → cycle_start: mark_inspecting + link_to_cycle → _inspecting_workpiece[ch]
  → cycle_end: set_result + gateway.dispatch(cycle_end)
  → （集群模式）cluster_collector 聚齐 → box_complete 推送
```

| 步骤 | 代码位置 |
|---|---|
| 扫码入口 | `backend/services/scanner.py` |
| 扫码处理 | `mes_hooks._handle_scan` L1171+ |
| 工件 inspecting 映射 | `mes_hooks._handle_cycle_start/end`（不变量 #14） |
| 外推 | `backend/services/mes_gateway.py` |
| 深潜全文 | [internals/mes-hook-pipeline.md](../internals/mes-hook-pipeline.md) |

## 链路 C：插件加载 → hook 生效 → 前端定制

```
后端冷启动 → PluginManager 读 DB active 清单
  → 验签 → import 插件 register_plugin(app, registry, host)
  → registry.hooks.register(...) + 可选 router 挂载
  → 前端 bootstrap: waitBackendReady → GET /plugins/active/manifest
  → usePluginLoader 三级兜底加载 ESM → themeStore / TjSlot 槽位
```

| 步骤 | 代码位置 |
|---|---|
| 后端加载 | `backend/plugin_system/` loader + `registry.py` |
| hook 触发 | `hook_dispatch.fire_plugin_hook` |
| 前端 bootstrap | `frontend/src/main.js` |
| 前端加载 | `frontend/src/composables/usePluginLoader.js` |
| 深潜全文 | [internals/plugin-loading-chain.md](../internals/plugin-loading-chain.md) |
