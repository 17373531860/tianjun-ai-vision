# 横切概念

> **类型**：explanation（架构 · arc42 §8）
> **本文不讲**：某一模块内部状态机（→ [internals/](../internals/)）
> **与代码冲突时**：以代码为准；不变量详见 AGENTS.md 第八节。

## 1. 错误隔离（插件 / MES / 外设）

| 场景 | 策略 | 代码位置 |
|---|---|---|
| 插件 hook 抛异常 | swallow + audit log，主流程继续 | `hook_dispatch.fire_plugin_hook` |
| 插件安装/加载失败 | 该插件 disable，主程序照常启动 | `backend/plugin_system/` loader |
| MES Hook 队列满 | critical 落盘回放；非 critical 丢弃；**绝不阻塞**检测热路径 | `mes_hooks._enqueue`（不变量 #15） |
| 外设串口失败 | 后台重试 + 日志；不阻塞 uvicorn 启动 | `external_device_pipeline` |

## 2. 线程与锁模型（简图）

```
[HTTP 请求线程] ──调用──► VideoSourceManager（每通道一个 mgr）
                              │
[采集线程 _capture_loop] ◄────┘  读写帧缓冲、触发推理
                              │
[mes-hook-worker 单线程] ◄── hook 入队（扫码/周期/会话）
                              │
[报警线程 / 外设读数 / 集群心跳] ◄── 各自独立
```

**写 docstring 时必须交代 Context**（见 [conventions/docstring军规.md](../conventions/docstring军规.md)）：在哪个线程被调、持什么锁、能否阻塞。

## 3. 配置写入权独占

| 配置文件 | 专属写入口 | 禁止 |
|---|---|---|
| `workstation_config.json` | channel_manager 分段 save 函数 | 任何代码 `json.dump` 整写（不变量 #17） |
| Project 7 JSON 字段 | `POST /projects` → ORM | 绕过 API 直接改 DB JSON |
| SystemConfig KV | 对应 service + PluginHost（插件键须 `plugin_<cc>_` 前缀） | 插件写主程序保留 key |

## 4. 鉴权（v3.10+）

- 登录 → JWT token → 端点权限目录校验
- M2M：API Key（SHA256 + scope）
- 开发默认鉴权可关；出厂按客户策略开
- 代码位置：`backend/api/auth.py`、`users.py`、`roles.py`、`api_keys.py`

## 5. 日志与调试

- 全局调试日志中心：`backend/api/debug.py` + `debug_center`
- Electron：`electron.log` / `backend.log` 滚动落盘（UTF-8）
- 客户机通常无 F12：插件前端错误经 `POST /api/v1/plugins/client-log` 回传

## 6. 报警合成（不变量 #16）

- 所有报警事件必须归入共享灯柱四类优先级：`ng` / `warn` / `ok` / `idle`
- **禁止**绕过合成器直写串口
- 代码位置：`backend/api/alarm.py` + `debug-alarm` skill 第六节

## 7. 多通道清理链（不变量 #4）

`channel_manager.set_channel_count` 减通道时必须同步清理：

1. `mes_hook.on_channel_removed`
2. `alarm_router.on_channel_removed`
3. channel-group 协调器
4. workpiece-flow 协调器

插件若维护 channel 维度状态，同样必须挂 `on_channel_removed`。

## 8. 版本与迁移

- Schema 变更：`backend/db/migrations/mXXXX_*.py` + `schema_migrations` 记账
- 老 `migrate_database()` 为断言桩，不再往里塞 ALTER
- 详见 `modify-model` skill
