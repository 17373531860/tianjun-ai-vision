# ADR-0001：端点文档门禁采用基线法

> **类型**：ADR
> **Status**：Accepted
> **日期**：2026-07-05
> **关联**：docs/dev/conventions/端点文档军规.md、`scripts/ci/check_doc_endpoints.py`

## Context

主程序 400+ 端点长期缺 summary/docstring，若一刀切 CI 全红会阻塞所有开发。
产品要求「每次更新都要完善开发文档」，需要在**纪律**与**可落地**之间折中。

## Decision

采用**基线法门禁**：

1. 存量欠账固化在 `doc_endpoint_baseline.json`（395 项，2026-07-05 快照），不报错。
2. 基线外的新端点 / 被改动端点缺 summary、response_model（或 204）、docstring → CI 红。
3. 基线只许缩不许涨：还清一项从基线删除（`--prune`）。
4. pytest `tests/test_doc_ci.py` 随每次回归自动执行。

## Consequences

- 正面：新代码强制带文档；存量可渐进还债；与 Stripe/微软「注释告警」思路一致。
- 负面：改存量端点行为时可能触发「基线外」判定——实为好事，逼顺手补文档。
- 后续：待存量还清后删除基线文件，改为全量 fail。
