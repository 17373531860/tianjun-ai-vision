# 现场纠偏清单 — 缸体判型（对照 2026-08-11 现场截图）

> 对象：缸体判型项目（擦拭缸体 / 装轴承座瓦 / 装轴承盖瓦 / 放置挺柱）
> 依据：《现场配置手册_缸体判型与触发中心》推荐值 vs 现场实配截图
> 用法：按顺序逐项改，每项改完点「保存配置」；全部改完重新开始检测再看效果。

---

## 一、必改项（当前配置会直接压低计数 / 打乱周期）

### 1. 置信度阈值 — 全部改成 35%

位置：项目管理 → 步骤设置 → 标签与检测属性 → 置信度阈值

| 标签 | 现在 | 改成 |
|---|---|---|
| 擦拭缸体 | 52% | **35%** |
| 装轴承座瓦 | 50% | **35%** |
| 装轴承盖瓦 | 50% | **35%** |
| 放置挺柱 | 44% | **35%** |

为什么：手册的所有时序参数都是按 35% 阈值联调出来的。阈值拉到 50% 以上，
瓦/挺柱在手部遮挡、侧视角下的低分检出会被整段滤掉——追踪引擎根本收不到框，
**这是"计数不涨"最直接的原因**。

### 2. 消失等待时间 — 擦拭缸体必须 4 秒

位置：项目管理 → 步骤设置 → 步骤行为参数 → 消失等待时间(秒)

| 标签 | 现在 | 改成 |
|---|---|---|
| 擦拭缸体 | 默认0秒 | **4.0** |
| 装轴承座瓦 | 默认0秒 | **0.35** |
| 装轴承盖瓦 | 默认0秒 | **0.35** |
| 放置挺柱 | 默认0秒 | **0.35** |

为什么：擦拭缸体是周期分界步骤。0 秒 = 检测框一闪断就算"消失"，
擦一次缸体会被拆成好几段，**周期边界乱掉、结算时机不对**。4 秒是按现场
动作节奏（擦拭中途手会短暂挡住缸体）联调的值。三个装配标签 0.35 秒用于
吸收单帧闪断。

### 3. 最少帧数 — 三个装配标签改成 2

位置：同上表 → 最少帧数

| 标签 | 现在 | 改成 |
|---|---|---|
| 擦拭缸体 | 默认1 | 1（不用改） |
| 装轴承座瓦 | 默认1 | **2** |
| 装轴承盖瓦 | 默认1 | **2** |
| 放置挺柱 | 默认1 | **2** |

为什么：过滤单帧误检进入步骤序列。

### 4. 位置追踪参数 — 三处改回手册值

位置：项目管理 → 逻辑设置 → 计数组合判定表 → 按位置去重 参数区

| 参数 | 现在 | 改成 | 为什么 |
|---|---|---|---|
| 同位置判定 IoU | 0.5 | **0.4** | 0.5 偏严：同一个瓦位的检测框抖一下就重叠不够，被当成"新位置"多计 |
| 新位置确认帧数 | 5 | **3** | 5 帧确认太慢，快节奏装配（装上后手立即离开遮挡）容易凑不满帧数漏计 |
| 候选保留节拍 | 5 | **10** | 保留 5 拍 + 确认要 5 帧，几乎没有容错；断 1 帧候选就作废重头数 |
| 位置平滑步长 | 0.6 | 0.6（不用改） | — |
| 单位置消失超时 | 0 | 0（不用改） | 0 = 锁定常驻到周期结算，正确 |
| 整类空闲重置 | 0 | 0（不用改） | — |

### 5. 机型标记 (tag) — 四行全是空的，填上

位置：项目管理 → 逻辑设置 → 计数组合判定表 → 机型行

现状：4 行判定 (5,5,0)/(5,5,4)/(7,7,0)/(7,7,6) 的 tag 全为空。
后果：命中了也没有机型名可显示——监控页、事件原因、导出、MES 全部拿不到机型。

| counts (座瓦,盖瓦,挺柱) | 建议 tag（按现场实际机型名改） |
|---|---|
| 5,5,0 | 如 `4缸-无挺柱` |
| 5,5,4 | 如 `4缸-含挺柱` |
| 7,7,0 | 如 `6缸-无挺柱` |
| 7,7,6 | 如 `6缸-含挺柱` |

## 二、请核对项（截图看不到，口头确认一下）

1. **结算时机**：手册要求以擦拭缸体（首步）作为周期分界——下一件开始擦拭时
   结算上一件。请在逻辑设置里核对结算模式与手册一致。
2. **软件版本**：锁定框可视化（青色常驻锁框 + 编号 + 信息条「判型计数」实时
   显示）和「监控画锁定框」开关是 2026-08-11 之后的构建才有。升级前画面上
   看不到锁框属正常，不代表计数没在跑；升级后监控页直接可见。

## 三、不用动的项（截图里这些是对的 / 无害）

- 计数口径 = 按位置去重 ✅（正确，就是要这个）
- 单次接受：三个装配标签开着 ✅（位置去重口径下计数走追踪引擎，此开关不影响
  计数，还能避免重复出现被误判 NG，保持现状即可）
- 静态触发 30.00 / 参与周期 开 ✅（默认值）
- NG 判定与处置：违规当场提示不结算 / 缺步骤直接判 NG ✅

## 四、改完后的现场自检（2 分钟）

1. 开始检测，装第 1 片座瓦 → （升级后）画面出现青色锁框 `装轴承座瓦 #1`，
   信息条「判型计数」座瓦变 1；
2. 手拿开再放回同一位置 → 计数**不变**（同位置不重计）；
3. 装第 2 片不同位置 → 锁框 #2，计数变 2；
4. 一件装完、擦拭下一件缸体 → 上一件结算，机型名上屏，锁框清空归零。
