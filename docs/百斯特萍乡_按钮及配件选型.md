# 萍乡百斯特项目 · 报警确认按钮及配件选型 v1.0

> 阅读对象：采购/实施。给客户的推荐清单，客户自购或我方代购皆可。
> 更新时间：2026-07-10

---

## 一、推荐方案：USB 可编程一键按钮（首选）

**原理**：本质是"只发一串固定字符 + 回车"的 USB HID 键盘。软件侧已把它做成扫码器设备的一种用途（「报警确认按钮」），按一下 = 解除本工位"需人工确认"的报警定格。**免驱、免串口、免额外开发**。

**采购硬指标**（问客服逐条确认）：

| 指标 | 要求 | 为什么 |
|---|---|---|
| 接口类型 | USB HID 键盘（免驱） | 复用软件全局键盘捕获链路 |
| 可编程 | 支持自定义输出内容，且能以**回车结尾** | 软件靠回车判定一次输入结束 |
| 输出内容 | 建议烧录 `TJACK01`（工位1）、`TJACK02`（工位2）… | 每工位独立按钮独立码，好排查 |
| 按键形态 | 工业大按钮（直径 ≥ 40mm）优先 | 戴手套可拍 |
| 线长 | ≥ 1.5m 或选带延长线款 | 工控机到工位有距离 |

**参考搜索词**（京东/淘宝）：`USB 自定义快捷键按钮`、`USB 一键按钮 可编程`、`机械大按钮 USB 键盘`。价位约 **20–80 元/个**，每工位 1 个。

**配置步骤**（对应配置指南第五节）：
1. 按钮厂家工具里烧录固定码（如 `TJACK01` + 回车）
2. 软件里 `MES 管理 → 扫码器 → 添加 USB 扫码枪`，用途选**「报警确认按钮」**，选对应工位
3. 弹窗里有测试框：按一下按钮应显示"报警已确认 / 当前无待确认报警"

**注意**：按钮插在运行本软件的工控机上即可，页面无需焦点在特定输入框（全局捕获）。

## 二、备选方案

| 方案 | 成本 | 适用 | 说明 |
|---|---|---|---|
| **A. 确认二维码卡片** | ≈0 元 | 现场已有 USB 扫码枪 | 打印固定码卡片贴工位，用枪扫一下=确认。同一把枪可与拉单/绑件用途并存（再建一个"报警确认"用途的枪设备即可） |
| **B. 界面确认按钮** | 0 元 | 过渡期/硬件未到 | 监控页自带，管理员密码提权确认也可用（软件默认能力） |
| **C. 串口/IO 物理按钮** | 100+ 元 | 客户坚持接 PLC 级按钮 | 走外设框架二期接入，本期不做，不建议 |

## 三、连带配件清单（本项目一次配齐）

| 物品 | 数量 | 要求 |
|---|---|---|
| USB 确认按钮 | 每工位 1 | 见第一节硬指标 |
| 电子秤 | 每工位 1 | 支持 RS232 **指令应答模式**（含远程去皮 T / 置零 Z 指令），协议见已确认的 CHS-D+R / ETC-D+R 说明书；参数 9600/8/N/1 |
| RS232-USB 转接线 | 每秤 1 | FTDI / CH340 芯片均可，线长按现场量 |
| 相机 | 每工位 1 | ≥1080p，固定机位支架（**机位不能动**，动了防错区域要重画） |
| USB HUB（带外供电） | 视工位数 | 按钮 + 秤转接 + 相机可能占满工控机 USB 口 |

## 四、达梦驱动（软件侧配套，实施注意）

数据库直写用的达梦官方 Python 驱动 `dmPython` 不在标准安装包里，实施时任选其一：
1. 客户机装达梦客户端（自带驱动）
2. 现场 `pip install dmPython`（可走热补丁 bat 脚本，参照既有清华源装包模板）

未装驱动时软件不会崩：测试推送直接报"达梦驱动未安装: 请安装 dmPython"，装完即通。
