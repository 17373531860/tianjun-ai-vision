# 投影光引导 · 现场部署手册

> 适用版本：v3.57+（投影光引导 P1~P3）
> 读者：现场实施工程师
> 功能定位：投影仪把装配引导直接打在工作台上——当前步骤安装位辉光、取料流向箭头、OK/NG 即时反馈、NG 悬停确认、投影仪被撞自动重标。

---

## 一、硬件要求与架设

### 1.1 硬件清单

| 硬件 | 要求 | 说明 |
|---|---|---|
| 投影仪 | ≥3500 ANSI 流明、1080p、短焦（投射比 ≤1.0） | 流明看 ANSI/ISO 标称，光源流明虚标可差 3 倍；车间环境光强，亮度不够引导看不清 |
| 相机 | 工位现有检测相机复用 | **必须能看到整个投影区域**，这是标定的前提 |
| 支架 | 吊装横臂/龙门架，**刚性** | 支架晃动会频繁触发漂移自检重标 |
| 台面 | 哑光浅色（浅灰/白桌垫） | 深色台面吃投影亮度；反光台面干扰悬停确认的亮度采样 |
| 显示线 | HDMI ≥10m 用光纤 HDMI | 投影仪接工控机第二个显示输出口 |

### 1.2 架设几何

```
        [投影仪]  ← 吊装, 俯投
         /  |
        /   |      投影区: 覆盖整个作业台面
       /    |      相机: 俯视, 视野 ≥ 投影区 (留边 10%+)
  [相机]    |
      \     |
       \    ▼
  ┌─────────────────┐
  │    工作台面      │  ← 哑光浅色
  └─────────────────┘
```

要点：
- **相机视野必须完整覆盖投影区并留边**——标定图案任何一角出视野，识别标记数不足会拒绝标定
- 投影仪与相机都固定死。相机动了 = 标定作废（会被自愈发现并自动重标，但频繁重标说明安装有问题）
- 避免阳光/强灯直射台面（投影对比度下降、相机过曝都影响标记识别）

## 二、软件配置流程

### 2.1 接投影仪自动上引导（推荐，桌面版）

1. 投影仪接工控机 → Windows 显示设置里确认为**扩展模式**（不是复制）
2. 软件「工位与输入源 → 多屏工位显示」：
   - 该工位映射选择投影仪对应的显示器
   - **窗口内容选「投影光引导」**
   - 保存并应用 → 投影仪上自动弹出全屏引导窗
3. 首次使用：投影窗处于未标定菜单 → 按 **C** 自动标定（详见 2.3）

### 2.2 浏览器手动打开（开发/临时）

「工位与输入源 → 多屏工位显示 → 投影光引导卡」点「打开投影窗」，把窗口拖到投影仪屏后双击全屏。

### 2.3 自动标定

前置：工位视频源已启动（相机有画面）、投影窗全屏在投影仪上。

1. 投影窗按 **C** → 全屏打出 ArUco 标记阵
2. 系统自动等曝光稳定（默认 1.5s，可调）→ 相机识别标记 → 求解相机↔投影映射
3. 成功：显示「识别 N/12 标记 · 重投影误差 X px」→ 自动进入引导
4. 失败常见原因：
   - 「仅识别到 0/12 个标记」→ 相机看不到投影区/严重过曝/对焦糊
   - 识别数不足 4 → 投影图案部分出了相机视野，调相机或缩小投影
   - 误差 >5px → 台面不平整或投影仪梯形校正过度，先做投影仪自身梯形校正

标定按工位持久化，重启不丢。换投影仪/挪相机后在设置卡「清除标定」重标。

### 2.4 引导参数（工位与输入源 → 投影光引导卡）

| 参数 | 默认 | 现场调法 |
|---|---|---|
| 悬停确认时长 | 1200ms | 操作员反映"要按很久"调短；误触发调长 |
| 悬停亮度偏移阈值 | 14 | 深色手套反射率低 → 调低（8~10）；台面反光误触发 → 调高 |
| 漂移自检周期 | 20s | 产线震动大可放宽到 60s+ 减少无谓校验 |
| 漂移重标阈值 | 6px | 支架不稳频繁重标 → 先修支架，实在不行调大到 10~15 |
| 漂移后自动重标 | 开 | 关闭后只投影提示不自动重标（要求人工按 C） |
| 引导画面亮度 | 1.0 | 夜班嫌刺眼可降到 0.6~0.8（锚点/确认按钮不受影响） |
| 标定曝光稳定等待 | 1500ms | 相机自动曝光慢（如夜间）调大到 2500+ |
| 流向引导路径 | 开 | 工位小、目标就在手边时可关 |

参数全局一份，投影窗**重进引导后生效**（Esc 回菜单再 Enter 即可）。

## 三、运行机制速查（排障用）

| 现象 | 机制 | 排查 |
|---|---|---|
| 四角一直有小方块 | 自愈锚点，相机持续盯它们做漂移校验 | 正常，勿遮挡全部四角（遮 1~2 个无碍，≥3 个才判定） |
| 投影仪被撞后自动打出标记阵 | 漂移超阈值自动重标 | 正常自愈；频繁发生查支架刚性 |
| NG 后台面弹黄色按钮 | 事件配了 require_ack，手悬停按钮=确认 | 手悬停无反应：查相机是否能看到按钮投影区、调低亮度阈值 |
| 引导窗黑屏只有呼吸弧环 | 检测未启动（待机态） | 到监控页启动检测 |
| 「当前步骤未配置 ROI 且暂未检出目标」 | 步骤没画 ROI 且实时没检出该零件 | 项目配置里给步骤画 ROI（推荐，引导更稳） |

## 四、无硬件演示模式

不接投影仪/相机也能给客户演示完整故事线（合格引导→NG 拦截悬停放行→撞歪自愈）：

```bash
# 1. 起后端 (test 模式) 和前端
# 2. 一条命令:
~/miniconda3/envs/tianjun/bin/python tests/uat/demo_lightguide.py
```

真投影仪演示时不跑脚本：直接开投影窗按 C 真标定，悬停用真手，撞歪直接用手推投影仪。
