# 现场验收清单（人工引导版）

> 适合工程师上门部署时打勾。每一项都给出"如何验"和"通过标准"。

## 怎么用

1. 确认软件已经安装到客户机。
2. 启动 backend / frontend / electron 桌面壳。
3. 按下表逐项操作并勾选；任何一项不通过，记录现象 + 截图。

---

## 7 大验收项

### 1. 系统启动正常

- 怎么验：双击桌面图标，打开 Splash → 看到主窗口 Monitor 页
- 通过标准：
  - [ ] Splash 出现且 < 10s 内消失
  - [ ] 主窗口加载 Monitor 页，左侧菜单可见
  - [ ] 浏览器控制台无致命错误（红色字）

### 2. 视频源连接

- 怎么验：进入 Source 页，按现场实际情况选源类型（USB/RTSP/视频文件/图片）
- 通过标准：
  - [ ] 选择对应源类型后能看到画面或预览
  - [ ] FPS 数值合理（USB ≥ 15、RTSP ≥ 10）
  - [ ] 切换通道（如多工位）画面相互独立

### 3. 项目激活生效

- 怎么验：Project 页选一个已配好的项目 → 点"激活"
- 通过标准：
  - [ ] 激活成功，无报错弹窗
  - [ ] 回到 Monitor 看到步骤列表与当前项目匹配

### 4. 检测启动 + OK/NG 判定

- 怎么验：现场放真实工件，让检测跑一个完整周期
- 通过标准：
  - [ ] OK 周期 → Monitor 显示绿色合格 + 计数器 +1
  - [ ] 故意造一个 NG 工件 → 显示红色不合格 + NG 计数 +1
  - [ ] PT/CT 数值显示合理（与设置项对得上）

### 5. 数据写入与查看

- 怎么验：跑完几个周期 → 进入 Data 页
- 通过标准：
  - [ ] 看到刚才的 session 与 cycle 记录
  - [ ] 点开 cycle 详情能看到步骤明细
  - [ ] 录像文件存在，能播放

### 6. 报告导出

- 怎么验：在 Data 页选导出格式（CSV/Excel/PDF/Word）
- 通过标准：
  - [ ] 导出文件成功生成，能打开
  - [ ] 导出内容包含品牌/工厂/操作员等系统字段
  - [ ] 实时规则若已配，对应文件按时生成

### 7. 报警/外设动作

- 怎么验：触发一个报警事件（NG / 工件超期 / 步骤缺失）
- 通过标准：
  - [ ] 灯塔/蜂鸣器响应（若现场有）
  - [ ] Toast 与语音播报有反应
  - [ ] events_log 里有对应事件记录

## 离开现场前再确认

- [ ] 所有客户机的开机自启已设置（Electron 桌面图标）
- [ ] 把 `data/sql_app.db` 备份一份到外置 U 盘
- [ ] 给客户负责人留下 hotfix 路径与联系方式
- [ ] 让客户操作员独立完成一次完整周期，确认能上手

## 半自动模式（可选）

设置 `RUNTIME_MODE=test` 重启 backend，可以用 synthetic 剧本做"无工件"快速验收：

```bash
cd /path/to/tianjun
RUN_SAT=1 SAT_API_URL=http://localhost:8001 pytest tests/sat -v
```

`tests/sat/test_sat_api.py` 里 7 项 API 级验证会跑通；其他 UI 项仍需人工目视。
